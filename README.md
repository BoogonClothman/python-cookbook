# Python Cookbook 教案

面向教学的 Python 系统化教案，以"肘后备急"为核心理念——即查即用、一针见血。注重底层原理、最佳实践和实战练习。

## 章节

| 章节 | 内容 |
|------|------|
| 第1章 环境搭建 | 编程语言分类、Python 发展史、设计哲学、安装部署、pip/venv/uv、PEP 8 |
| 第2章 基础语法 | 语句/表达式、缩进/代码块、注释/docstring、标识符/关键字/命名、变量/对象/引用语义、赋值全解（解包/增强/海象）、运算符/短路/比较链、print/input/assert |
| 第3章 标准数据类型 | 数字（int/float/complex/bool）、字符串、序列（list/tuple/range/bytes）、映射与集合（dict/set/frozenset） |
| 附录A Python 3 版本演进宝典 | 3.0→3.14 逐个版本深入：核心 PEP、f-string/match/async/自由线程/JIT、CPython 实现揭秘 |

## 特点

- **深入底层**：不仅讲 API，更解释 CPython 实现细节（如哈希表、内存布局、字节码）
- **避开陷阱**：标注常见坑点（浮点精度、列表浅拷贝、`sort()` 返回 None 等）
- **配套练习**：每章末尾附验证/编程练习
- **版本跟进**：更新至 Python 3.14
