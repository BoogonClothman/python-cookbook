## 0.1 记号与约定：机器学习公式的读法

机器学习文献的公式之所以难读，一半是数学本身，一半是**记号约定**。ds-00 在 0.1.1 讲过上标的两种含义：

> **⚠️ 陷阱**：$x^2$ 是平方；但 $x^{(i)}$ 这种带上标括号的写法表示"第 $i$ 个样本"，不是 $i$ 次方。

ds-00 当时的口径是"本卷只使用幂的含义"。从本章起，**括号上标的样本记号正式启用**——它就是机器学习公式的第一个语法。

### 0.1.1 样本记号与 $X$ 的形状契约

一个**样本**（sample）是关于同一个对象的一组测量值，写成一个 $d$ 维向量：

$$x^{(i)} = \begin{bmatrix} x^{(i)}_1 \\ x^{(i)}_2 \\ \vdots \\ x^{(i)}_d \end{bmatrix} \in \mathbb{R}^d$$

下标是特征编号（第几个测量），上标括号是样本编号（第几个对象）。$d$ 叫**特征数**（feature），$n$ 叫**样本量**。数据集是 $n$ 个样本的集合，按**一行一个样本**堆成矩阵 $X$：

$$X = \begin{bmatrix} —\, x^{(1)}\, — \\ —\, x^{(2)}\, — \\ \vdots \\ —\, x^{(n)}\, — \end{bmatrix} \in \mathbb{R}^{n \times d}$$

这套"行=样本、列=特征"的约定是真金白银的工程契约：ds-01 的数组形状语言、ds-02 的 DataFrame"行=观测、列=变量"、以及 ml-01 起 sklearn 的全部输入接口，三家共用同一个形状契约。**`X.shape[0]` 永远是样本数，`X.shape[1]` 永远是特征数**，看见 `(4, 3)` 就是 4 个样本、每个 3 个特征：

```python
>>> import numpy as np
>>> rng = np.random.default_rng(2026)
>>> X = rng.normal(size=(4, 3))
>>> X.shape
(4, 3)
>>> X[2]                       # 第 3 个样本 x^(3)，一行 d=3 个特征
array([-0.31194933,  0.30383537, -0.2676603 ])
>>> w = np.array([1.0, -2.0, 0.5])
>>> X @ w                      # 每个样本算一个标量 → n 个标量
array([-2.22242822, -0.02684151, -1.05345021, -1.4086919 ])
```

标签 $y$ 通常是长度为 $n$ 的一维数组，$y^{(i)}$ 是第 $i$ 个样本的答案。回归问题里 $y^{(i)} \in \mathbb{R}$；二分类问题里 $y^{(i)} \in \{0, 1\}$。

| 对象 | 形状 | 约定 |
|------|------|------|
| 单个样本 $x^{(i)}$ | `(d,)` | 一行一个样本，取数用 `X[i]` |
| 数据矩阵 $X$ | `(n, d)` | 行=样本，列=特征；sklearn 的唯一合法输入格式 |
| 权重向量 $w$ | `(d,)` | 与特征一一对应 |
| 标签 $y$ | `(n,)` | 一维；回归是实数，分类是整数或布尔 |
| 预测 $\hat{y}$ | `(n,)` | `X @ w` 的形状由 $\text{(n,d)}@\text{(d,)} \to \text{(n,)}$ 决定 |

> **⚠️ 陷阱**：`X @ w` 得到的是 `(n,)` 一维数组，不是 `(n, 1)` 列向量。需要列形状时显式 `reshape(-1, 1)`；反过来 `w.reshape(-1, 1)` 前先想清楚 `X` 的行列含义。ds-00 讲过的"一维数组无行列之分"（0.2.6）在这里再次出现——**形状不是小事，它是本卷所有公式的类型系统**。

### 0.1.2 假设函数与参数：模型就是一个带旋钮的函数

机器学习模型本质是一个**函数族**：函数形状由人选定，函数的具体形态由一组**参数** $\theta$ 决定。训练就是调旋钮：

$$\hat{y} = f_\theta(x)$$

- 线性回归：$f_{w,b}(x) = w \cdot x + b$
- 逻辑回归：$f_{w,b}(x) = \sigma(w \cdot x + b)$，其中 $\sigma(z) = \dfrac{1}{1+e^{-z}}$

$\sigma$ 叫 **sigmoid**（挤压函数），把任意实数压进 $(0, 1)$，正好可以读作"概率"：

```python
>>> def sigmoid(z):
...     return 1.0 / (1.0 + np.exp(-z))
>>> sigmoid(np.array([-2.0, -0.5, 0.0, 0.5, 2.0])).round(4)
array([0.1192, 0.3775, 0.5   , 0.6225, 0.8808])
```

必须分清两类旋钮：

| 概念 | 谁定的 | 例子 | 怎么定 |
|------|--------|------|--------|
| **参数**（parameter）$\theta$ | 训练**算**出来的 | $w$、$b$ | 梯度下降（0.4 节） |
| **超参数**（hyperparameter） | 人**事先选**好的 | 学习率 $\eta$、正则强度、树的深度 | `ml-08` 的网格/随机搜索 |

> **⚠️ 陷阱**：超参数不能"学"出来——它是**你**的决策，你的决策当然要为结果负责。把调超参数叫"训练"是常见口误；它是**模型选择**，训练只是给定超参数后的参数估计。两者的混淆会导致用验证集选出来的超参数被当成"模型在自己的测试集上表现很好"，这是 0.5.6 的主题。

### 0.1.3 损失函数：把"学得好不好"变成一个数

要调旋钮，先得有一个**指标**告诉当前这组参数有多差。**单样本损失** $\ell(f_\theta(x^{(i)}), y^{(i)})$ 度量一个样本上的误差；整批数据的**经验损失**（empirical loss）是平均：

$$L(\theta) = \frac{1}{n}\sum_{i=1}^{n} \ell\big(f_\theta(x^{(i)}),\, y^{(i)}\big)$$

"经验"二字的意思是：我们不知道真实分布，只能拿手上的 $n$ 个样本**当经验**。ds-00 0.4.1 的大数定律保证 $n$ 越大，经验损失越接近真实风险——这也是模型的训练目标只看训练集、而好不好要用另一份数据评估（0.5.6）的根源。

两个最常用的单样本损失：

- **平方损失**（回归）：$\ell = (f(x) - y)^2$
- **0-1 损失**（分类）：预测对就是 0、错就是 1

```python
>>> pred = np.array([2.5, 0.0, 3.9, 1.2])
>>> true = np.array([2.0, 0.5, 4.0, 1.0])
>>> (pred - true) ** 2                    # 逐样本平方损失
array([0.25, 0.25, 0.01, 0.04])
>>> float(np.mean((pred - true) ** 2))     # 经验损失 L
0.1375
>>> y_true, y_pred = np.array([1, 0, 1, 1]), np.array([1, 0, 0, 1])
>>> (y_true != y_pred).astype(int)        # 0-1 损失
array([0, 0, 1, 0])
```

0-1 损失是最诚实的分类指标（错就是错），但它**不可导**——梯度下降吃不了它，所以训练时必须换成可导的**代理损失**（交叉熵，见 0.5.4）。这是"训练目标 ≠ 评估口径"的第一个伏笔。

> **⚠️ 陷阱**：报损失值时必须同时说明损失函数。$L=0.14$ 在平方损失下是"预测和真值平均差 0.37"，在对数损失下含义完全不同。**没有损失函数名的损失数字是废话**。

### 0.1.4 可复现训练：种子三分

ds-01 1.13.2 的 `SeedSequence.spawn` 是本卷的种子管理基础。训练流程里至少有三个互不相干的随机来源，混用同一个 rng 会让"换个数据集"连参数初始化都变了：

| 随机来源 | 用途 | 建议 |
|----------|------|------|
| 数据生成/打乱 | 造模拟数据、切分训练/验证 | 独立种子 |
| 参数初始化 | $w$ 的初始点 | 独立种子 |

正规做法是派生子种子、一次 spawn 存下来、各用各的：

```python
>>> from numpy.random import default_rng, SeedSequence
>>> ss = SeedSequence(2026)
>>> rng_data, rng_param = map(default_rng, ss.spawn(2))
>>> rng_data.permutation(8)               # 数据打乱
array([7, 4, 1, 6, 0, 3, 2, 5])
>>> rng_param.normal(size=3).round(4)     # 参数初始化
array([ 0.544 ,  0.1155, -1.0814])
```

重跑一次，两个结果分毫不差——可复现性是训练实验的底线（`ml-05` 的交叉验证报告必须可复现）：

```python
>>> rng_data, rng_param = map(default_rng, SeedSequence(2026).spawn(2))
>>> rng_data.permutation(8)
array([7, 4, 1, 6, 0, 3, 2, 5])
>>> rng_param.normal(size=3).round(4)
array([ 0.544 ,  0.1155, -1.0814])
```

## 0.2 链式法则：复合函数的求导流水线

ds-00 0.2.11 教了梯度（往哪走）和雅可比（小扰动怎么传播）。机器学习的损失几乎总是**复合函数**——样本过模型、模型过损失函数套了好几层——求梯度必须先学会拆复合。

### 0.2.1 一元链式法则：先求内层，再乘外层

$$\frac{d}{dx} g(f(x)) = g'(f(x)) \cdot f'(x)$$

直觉是**增量放大器的级联**：$x$ 动一点，先被 $f$ 放大成 $f'(x)$ 倍，再被 $g$ 在 $f(x)$ 处放大成 $g'$ 倍，总倍数相乘。以 $h(x) = \sin(x^2)$ 为例，外层是 $\sin(\cdot)$、内层是 $x^2$，解析导数是 $h'(x) = 2x\cos(x^2)$。用 ds-00 0.2.11 的中心差分当场核对：

```python
>>> h = lambda x: np.sin(x ** 2)
>>> h_prime = lambda x: 2 * x * np.cos(x ** 2)
>>> eps = 1e-6
>>> round(float((h(1 + eps) - h(1 - eps)) / (2 * eps)), 7)      # 中心差分
1.0806046
>>> round(float(h_prime(1.0)), 7)                               # 解析值 2*cos(1)
1.0806046
```

差分与解析值在小数点后七位完全一致——ds-00 给出的 $h \approx 10^{-6}$ 甜区仍然成立。

> **实战建议**：任何手写导数，先拆"外层/内层"，写出两段导数，再乘起来。这是后面所有反向传播推导的唯一心法：**没有新数学，只有一道流水线**。

### 0.2.2 多元链式法则：雅可比相乘

把 ds-00 0.2.11 的雅可比矩阵当成"局部导数表"，复合函数的总导数就是**沿途雅可比相乘**。最实用的例子——线性回归的梯度，它将在 `ml-03` 原样出现。

设数据 $X \in \mathbb{R}^{n\times d}$、标签 $y$，模型 $\hat y = Xw$，损失 $L(w) = \frac{1}{n}\sum_i (\hat y^{(i)} - y^{(i)})^2$。求 $\partial L/\partial w$。

先拆复合：$w \xrightarrow{f_1} z = Xw - y \xrightarrow{f_2} \ell = z^2 \xrightarrow{f_3} L = \mathrm{mean}(\ell)$。

- $f_1$ 的雅可比是 $X$（$\partial z/\partial w = X^\top$ 按列看）
- $f_2$ 的雅可比是对角阵 $\mathrm{diag}(2z)$
- $f_3$ 的雅可比是全 $\frac{1}{n}$

三段相乘、合并成向量形式（省略推导细节）：

$$\boxed{\;\frac{\partial L}{\partial w} = \frac{2}{n}\, X^{\top}(Xw - y)\;}$$

注意 $\frac{2}{n}$ 来自"平方的 2"与"平均的 $1/n$"。用 $d=3$ 的实际数据核对解析与数值两种算法：

```python
>>> rng = np.random.default_rng(7)
>>> X = rng.normal(size=(5, 3))
>>> w_true = np.array([1.5, -2.0, 0.3])
>>> y = X @ w_true
>>> n = len(y)
>>> loss_w = lambda w: np.mean((X @ w - y) ** 2)
>>> grad_w = lambda w: (2.0 / n) * X.T @ (X @ w - y)
>>> w0 = np.zeros(3)
>>> grad_w(w0)                       # 解析梯度
array([-0.72406325,  2.51860422, -0.61961513])
```

数值版本（对每个分量单独做中心差分）：

```python
>>> def num_grad(f, w, eps=1e-6):
...     w = np.asarray(w, dtype=float)
...     g = np.zeros_like(w)
...     for i in range(len(w)):
...         e = np.zeros_like(w); e[i] = eps
...         g[i] = (f(w + e) - f(w - e)) / (2 * eps)
...     return g
>>> num_grad(loss_w, w0)
array([-0.72406325,  2.51860422, -0.61961513])
```

逐分量吻合，最大相对误差 $2\times 10^{-10}$。**这个式子是 ml-03 的地基**：线性回归、岭回归、Lasso 的梯度都是它的变体；卷 4 的全连接网络只不过把它嵌套了多层。

> **⚠️ 陷阱**：每个分量都做一次差分，代价是 $O(d)$ 次函数求值——对 $d$ 很大的模型，梯度核对只用于开发期，训练时关掉（0.3.3 节末尾再讲）。

### 0.2.3 计算图：把链式法则画出来

链式法则写成代码很容易丢失结构感。**计算图**（computational graph）把每个操作画成一个节点、数据沿边流动。一个逻辑回归的损失可画成：

```
x, w, b ──→ [z = x·w + b] ──→ [a = σ(z)] ──→ [L = -[y ln a + (1-y) ln(1-a)]]
                                              └────────── y, a
```

前向计算时每一步显式留痕：

```python
>>> x = np.array([1.0, 0.5]); w = np.array([2.0, -1.0]); b = 0.3; y = 1.0
>>> z = x @ w + b
>>> a = sigmoid(z)
>>> L = -(y * np.log(a) + (1 - y) * np.log(1 - a))
>>> float(z), round(float(a), 6), round(float(L), 6)
(1.8, 0.858149, 0.152978)
```

反向求导时，**每个节点只需要两样东西**：自己的局部导数，和上游传回来的导数。两者一乘，就是本节点的输出对总损失的偏导——节点之间互相不需要知道对方的内部细节。这就是整个深度学习工程化的哲学基础：卷 4 的 autograd 不是魔法，而是把这张图的每个节点自动接好上游梯度而已。

## 0.3 反向传播：链式法则的批量执行

"反向传播"（backpropagation）听起来玄，定义却朴素：**对整批样本，把链式法则按计算图反向批量执行一遍**。好用就好用在，它会把前向已经算过的量**复用**一遍——反向不是重来，而是结账。

### 0.3.1 前向传播：形状一路传

取一个最小的两层分类网络（隐藏层激活用 $\tanh$，输出用 softmax）。权重形状的约定是本节的重点：

- $W_1 \in \mathbb{R}^{d \times h}$：输入层到隐藏层，$h$ 是隐藏单元数
- $W_2 \in \mathbb{R}^{h \times k}$：隐藏层到输出层，$k$ 是类别数

```python
>>> rng = np.random.default_rng(11)
>>> n, d, hid, k = 6, 4, 5, 2
>>> X = rng.normal(size=(n, d))
>>> y = np.array([0, 1, 1, 0, 1, 0])
>>> W1 = rng.normal(size=(d, hid)); b1 = np.zeros(hid)
>>> W2 = rng.normal(size=(hid, k)); b2 = np.zeros(k)
>>> z1 = X @ W1 + b1          # (n, d) @ (d, hid) → (n, hid)
>>> a1 = np.tanh(z1)
>>> z2 = a1 @ W2 + b2         # (n, hid) @ (hid, k) → (n, k)
```

形状追踪表（背下来，卷 4 天天用）：

| 步骤 | 表达式 | 形状 |
|------|--------|------|
| 输入 | $X$ | `(n, d)` |
| 线性 | $z_1 = XW_1 + b_1$ | `(n, hid)` |
| 激活 | $a_1 = \tanh(z_1)$ | `(n, hid)` |
| 线性 | $z_2 = a_1 W_2 + b_2$ | `(n, k)` |
| 概率 | $p = \mathrm{softmax}(z_2)$ | `(n, k)` |

softmax 把 $k$ 个 logits 归一成一组概率（和为 1），数值稳定版本先减去每行最大值：

```python
>>> def softmax(z):
...     z = z - z.max(axis=1, keepdims=True)      # 防溢出
...     e = np.exp(z)
...     return e / e.sum(axis=1, keepdims=True)
>>> p = softmax(z2)
>>> L = -np.log(p[np.arange(n), y]).mean()        # 交叉熵损失
>>> round(float(L), 6)
1.342789
```

`p[np.arange(n), y]` 是"取出每个样本被预测为其真实类别的概率"——交叉熵就是它的平均负对数（0.5.4 节细讲）。

### 0.3.2 反向传播：梯度一路回流

标量损失 $L$ 对每个参数的梯度怎么求？**沿着计算图反向，一段一段乘局部导数**。四条结果（推导用 0.2 的技巧，逐段拆开）：

| 目标 | 求导路径 | 结果 |
|------|----------|------|
| $\partial L/\partial z_2$ | softmax+交叉熵的合并导数 | $\delta_2 = \dfrac{1}{n}(p - \mathrm{onehot}(y))$ |
| $\partial L/\partial W_2$ | 上游 $\delta_2$ × 局部 $a_1^\top$ | $a_1^\top \delta_2$ |
| $\partial L/\partial W_1$ | 上游 × $\tanh'$ 再 × 局部 $X^\top$ | $X^\top \left[(\delta_2 W_2^\top) \odot (1-a_1^2)\right]$ |

注意两句"行话"的背后含义：

- **"合并 softmax 与交叉熵"**：单独看 softmax 的雅可比和交叉熵的雅可比都很绕，但两者复合后恰好化简成 $p - \mathrm{onehot}(y)$——**一行干净的代码**，这就是 ml-04 分类损失的地基。
- **"$\tanh$ 的导数是 $1 - \tanh^2$"**：激活函数自己带导数的信息，前向时把 $a_1$ 存下来，反向时就能算出 $1-a_1^2$，不必重算 $\tanh$。

```python
>>> dz2 = p.copy()
>>> dz2[np.arange(n), y] -= 1.0
>>> dz2 /= n                                   # (n, k)：softmax+交叉熵合并
>>> dW2 = a1.T @ dz2                           # (hid, k)
>>> db2 = dz2.sum(axis=0)
>>> da1 = dz2 @ W2.T                           # (n, hid)：先搬到隐藏层
>>> dz1 = da1 * (1.0 - a1 ** 2)                # 再乘 tanh 的局部导数
>>> dW1 = X.T @ dz1                            # (d, hid)
>>> db1 = dz1.sum(axis=0)
```

校对一下形状：`dW2` 是 `(hid, k)`、`dW1` 是 `(d, hid)`——**与 $W_2$、$W_1$ 的形状一一对应**。任何反向传播代码写完，先扫一眼梯度形状表，错配当场现形。

跑一遍真实数值（只展示梯度矩阵的一角）：

```python
>>> dW2[0].round(5)
array([-0.02402,  0.02402])
>>> db2.round(4)
array([ 0.177, -0.177])
>>> db1.round(4)
array([ 0.0306, -0.0524,  0.0908, -0.0213,  0.0191])
```

"反向"的效率秘密在 `dW2 = a1.T @ dz2` 这一句：`a1` 是前向已经算好的量，反向时直接取用。**前向算一遍，反向结一遍账，没有第三遍**——这正是工程上反向传播比数值差分快几个数量级的原因（0.3.3 节量化对比）。

### 0.3.3 梯度核对：数值 vs 解析

手写反向传播，第一道防线是**梯度核对**（gradient check）：逐参数用中心差分算数值梯度，与解析梯度比对。ds-00 0.2.11 的 `scipy.optimize.check_grad` 是这个思路的一元版本；多维版本就是 for 循环逐分量扰动：

```python
>>> shapes = [a.shape for a in (W1, b1, W2, b2)]
>>> sizes = [a.size for a in (W1, b1, W2, b2)]
>>> vec = np.concatenate([np.ravel(a) for a in (W1, b1, W2, b2)])   # 摊平
>>> def unflat(v):                   # 摊平向量的逆操作：重建四个参数
...     out, start = [], 0
...     for s, sz in zip(shapes, sizes):
...         out.append(v[start:start+sz].reshape(s)); start += sz
...     return out
>>> def loss_of(v):                  # 拿任意参数向量前向一次，返回标量损失
...     W1f, b1f, W2f, b2f = unflat(v)
...     a1 = np.tanh(X @ W1f + b1f)
...     p = softmax(a1 @ W2f + b2f)
...     return -np.log(p[np.arange(n), y]).mean()
>>> num = np.zeros_like(vec)
>>> eps = 1e-6
>>> for i in range(len(vec)):        # 逐分量扰动：74 次完整前向
...     vp, vm = vec.copy(), vec.copy()
...     vp[i] += eps; vm[i] -= eps
...     num[i] = (loss_of(vp) - loss_of(vm)) / (2 * eps)
```

对全部 37 个参数逐项核对（$4\times5 + 5 + 5\times2 + 2$）——解析一侧是 0.3.2 反向传播的产物：

```python
>>> ana = np.concatenate([dW1.ravel(), db1, dW2.ravel(), db2])
>>> rel = np.abs(num - ana) / (np.abs(num) + np.abs(ana) + 1e-12)
>>> print(f"最大相对误差 {rel.max():.2e}")
最大相对误差 5.08e-08
```

最大相对误差 $5\times 10^{-8}$——解析反向传播实现正确。再来一次"结账"验证：沿梯度走一步，损失必须下降：

```python
>>> lr = 0.5
>>> W1 -= lr * dW1; b1 -= lr * db1; W2 -= lr * dW2; b2 -= lr * db2
>>> p_new = softmax(np.tanh(X @ W1 + b1) @ W2 + b2)
>>> round(float(L), 6), round(float(-np.log(p_new[np.arange(n), y]).mean()), 6)
(1.342789, 0.923423)
```

> **实战建议**：**任何手写梯度，先核对再训练**。梯度错的表现极其隐蔽——损失照样下降，只是慢、或收敛到奇怪的地方，你只会怀疑学习率。差异在哪？数值法求 37 个参数要算 74 次完整损失；解析反向传播**一次**就给出全部 37 个。规模放大到百万参数（卷 4），这个差距就是"可训练"与"不可训练"的区别——这也是为什么数值差分只留在开发期当质检，训练一律用解析法。

## 0.4 梯度下降：沿着梯度往下走

ds-00 留下的欠条在这里兑现后半张："知道梯度指向哪，不等于知道怎么沿着它走到底"。梯度指向**上升最快**的方向，那往**反**方向走就是最速下降——**梯度下降**（gradient descent）的全部内容就是这句更新规则：

$$\theta \leftarrow \theta - \eta\, \nabla L(\theta)$$

$\eta$ 是**学习率**（learning rate），即步长。

### 0.4.1 更新规则：一维抛物线

从最简单的 $f(x) = x^2$（梯度 $\nabla f = 2x$）起步，$\eta=0.1$，从 $x_0=3$ 出发：

```python
>>> x = 3.0
>>> x = x - 0.1 * (2 * x); x      # 第 1 步
2.4
>>> x = x - 0.1 * (2 * x); x      # 第 2 步
1.92
```

连续 8 步的轨迹：

| 步数 | $x$ | $f(x)$ |
|------|-----|--------|
| 1 | 2.400000 | 5.760000 |
| 2 | 1.920000 | 3.686400 |
| 3 | 1.536000 | 2.359296 |
| 4 | 1.228800 | 1.509949 |
| 5 | 0.983040 | 0.966368 |
| 6 | 0.786432 | 0.618475 |
| 7 | 0.629146 | 0.395824 |
| 8 | 0.503316 | 0.253327 |

每一步都乘以 $(1-2\eta)=0.8$——线性收敛。这个"每步乘常数"的性质只在二次函数上成立，但它给出一条可迁移的直觉：**梯度下降不是一步到位的最小化，而是一串不断减小步长的收缩**。

### 0.4.2 学习率：步子的三种命运

把 $\eta$ 从 0.01 调到 1.5，同样从 $x_0=3$ 跑 30 步：

```python
for eta in (0.01, 0.1, 0.5, 0.9, 1.05, 1.5):
    x = 3.0
    for _ in range(30):
        x = x - eta * (2 * x)
    print(f"eta={eta:<5} 30步后 x = {x:>14.6f}")
# eta=0.01  30步后 x =        1.636453
# eta=0.1   30步后 x =        0.003714
# eta=0.5   30步后 x =        0.000000
# eta=0.9   30步后 x =        0.003714
# eta=1.05  30步后 x =       52.348207
# eta=1.5   30步后 x = 3221225472.000000
```

整理成表（"乘子"即每步的 $x$ 缩放因子 $1-2\eta$）：

| $\eta$ | 30 步后 $x$ | $x$ 的乘子 $(1-2\eta)$ | 命运 |
|--------|------------|--------|------|
| 0.01 | 1.636453 | 0.980 | 太小：纹丝不动 |
| 0.1 | 0.003714 | 0.800 | 稳健收敛 |
| 0.5 | 0.000000 | 0.000 | 一步到底（此例的最优 $\eta$） |
| 0.9 | 0.003714 | −0.800 | 来回横跳但收敛 |
| 1.05 | 52.348207 | −1.100 | 横跳且越跳越远 |
| 1.5 | 3221225472.0 | −2.000 | 发散到溢出 |

$\eta$ 越大收敛越快（0.01 时 30 步只走了一半），但越过 0.5 就开始横跳，超过 1 直接发散。**收缩的判据是 $|1-2\eta| < 1$**——步子跨过谷底swing到了对面。

各方向曲率不同时更麻烦。碗 $f(x, y) = \frac{1}{2}(x^2 + 20y^2)$（$\nabla = (x,\, 20y)$）从 $(1, 1)$ 出发：

```python
for eta in (0.05, 0.10, 0.15):
    px, py = 1.0, 1.0
    for _ in range(30):
        gx, gy = px, 20 * py
        px, py = px - eta * gx, py - eta * gy
    print(f"eta={eta:.2f}  |x|={abs(px):>13.6f}  |y|={abs(py):>13.6f}")
# eta=0.05  |x|=     0.214639  |y|=     0.000000
# eta=0.10  |x|=     0.042391  |y|=     1.000000
# eta=0.15  |x|=     0.007631  |y|=1073741824.000000
```

对应的现象：

| $\eta$ | 30 步后 $\lvert x\rvert$ | $\lvert y\rvert$ | 现象 |
|--------|------------|------------|------|
| 0.05 | 0.2146 | 0.0000 | 两个方向都收敛 |
| 0.10 | 0.0424 | 1.0000 | $x$ 收敛更快，$y$ 永远横跳（$\lvert1-20\eta\rvert=1$） |
| 0.15 | 0.0076 | 1073741824.0 | $y$ 横跳且发散 |

单一学习率被**最陡的方向**卡住上限：$\eta$ 只能小于 $1/\text{最大曲率}$。在 $y$ 方向安全的前提下，$x$ 方向只能以 $\eta=0.05$ 的速度慢爬——这就是为什么真实损失面又窄又长时，朴素梯度下降慢得像爬行，也是自适应优化器（Adam 等）存在的理由（`ml-03` 的 solver 选型还会再撞见这个问题）。

> **⚠️ 陷阱**：**学习率不是"越小越安全"**。太小则永远走不到谷底、看起来像"收敛"了；太大则直接发散。判据不是损失曲线平了没有（平台期可能是缓慢下降中的假象），而是**梯度范数 < tol**——sklearn 的 `tol` 参数就是这个口径。
>
> **实战建议**：新任务先用小学习率跑通（确认代码无误），再逐档放大观察损失曲线；黑屏阶段的"无穷震荡"几乎总是 $\eta$ 超了上限。

### 0.4.3 BGD / SGD / mini-batch：噪声从敌人变朋友

$L$ 通常是 $n$ 个样本的平均，"用多少样本算一次梯度"分成三档：

| 变体 | 每步用的样本 | 每轮（epoch）更新次数 | 每步成本 |
|------|-------------|----------------|----------|
| 批量 BGD | 全部 $n$ | 1 | 高，但方向准 |
| 小批量 mini-batch | $B$ 个（如 32） | $n/B$ | 中 |
| 随机 SGD | 1 个 | $n$ | 低，但方向噪声大 |

在 200 个样本的回归问题上，三种方法同样跑 30 轮（同一起点、同一 $\eta=0.05$）。先备好公共数据与批梯度函数（批内取平均，让三种方法的 $\eta$ 口径可比）：

```python
rng = np.random.default_rng(2026)
n, d = 200, 3
X = rng.normal(size=(n, d))
w_true = np.array([1.5, -2.0, 0.3])
y = X @ w_true + rng.normal(scale=0.5, size=n)
w0 = np.zeros(d)

def batch_grad(w, idx):
    Xb, yb = X[idx], y[idx]
    return (2.0 / len(idx)) * Xb.T @ (Xb @ w - yb)

def run(method, lr=0.05, epochs=30, batch=20):
    rng_run = np.random.default_rng(20260)      # 训练内部的打乱种子，单独一个
    w = w0.copy()
    marks = {}
    for epoch in range(1, epochs + 1):
        if method == "bgd":
            w = w - lr * batch_grad(w, np.arange(n))
        else:
            perm = rng_run.permutation(n)
            bs = 1 if method == "sgd" else batch
            for start in range(0, n, bs):
                w = w - lr * batch_grad(w, perm[start:start + bs])
        marks[epoch] = np.mean((X @ w - y) ** 2)
    return marks

for m in ("bgd", "minibatch", "sgd"):
    marks = run(m)
    trail = "  ".join(f"第{e:>2}轮={marks[e]:.5f}" for e in (1, 2, 5, 10, 30))
    print(f"{m:<10} {trail}")
# bgd       第 1轮=5.16731  第 2轮=4.28769  第 5轮=2.48502  第10轮=1.07933  第30轮=0.24432
# minibatch 第 1轮=1.05980  第 2轮=0.35165  第 5轮=0.22717  第10轮=0.22705  第30轮=0.22643
# sgd       第 1轮=0.24436  第 2轮=0.23576  第 5轮=0.27185  第10轮=0.35718  第30轮=0.27159
```

整理成表（"参数更新次数"由轮数与批量决定）：

| 方法 | 参数更新次数 | 第 1 轮 | 第 2 轮 | 第 5 轮 | 第 10 轮 | 第 30 轮 |
|------|--------|---------|---------|---------|----------|----------|
| BGD | 30 | 5.16731 | 4.28769 | 2.48502 | 1.07933 | 0.24432 |
| mini-batch(20) | 300 | 1.05980 | 0.35165 | 0.22717 | 0.22705 | 0.22643 |
| SGD | 6000 | 0.24436 | 0.23576 | 0.27185 | 0.35718 | 0.27159 |

三条信息：**小批量比纯批量快得多**（第 1 轮就到了 BGD 第 30 轮的水平，因为它一轮做了 10 次更新）；**SGD 早期也快但后期抖**（第 30 轮反而回到 0.27，因为它在最优点附近被噪声推来推去）；**小批量最后贴着噪声地板**（0.2264 接近噪声本身的方差 0.25，`w_true` 处就是它）。

噪声有多大？在 $w = w^\star$ 处抽 200 批梯度，测各分量的标准差：

```python
for bs in (1, 10, 50, 200):
    gs = [batch_grad(w_true, rng.integers(0, n, size=bs)) for _ in range(200)]
    std = np.array(gs).std(axis=0).mean()
    print(f"batch={bs:>4}  分量标准差均值={std:.5f}   ×√{bs} → {std*np.sqrt(bs):.3f}")
# batch=   1  分量标准差均值=1.07591   ×√1 → 1.076
# batch=  10  分量标准差均值=0.32391   ×√10 → 1.024
# batch=  50  分量标准差均值=0.15116   ×√50 → 1.069
# batch= 200  分量标准差均值=0.07580   ×√200 → 1.072
```

| 批量 $B$ | 梯度分量标准差（均值） | × $\sqrt{B}$ |
|----------|----------------------|--------------|
| 1 | 1.07591 | 1.076 |
| 10 | 0.32391 | 1.024 |
| 50 | 0.15116 | 1.069 |
| 200 | 0.07580 | 1.072 |

最后一列几乎恒定——**梯度方差 $\propto 1/\sqrt{B}$**，这是平均的标准差 scaling 在梯度上的直接体现（ds-00 0.4.2 的标准误同一件事）。

> **为什么 SGD 有时反而更好？** 一维抛物线只有一个谷，真实损失面有大量平台与鞍点（0.4.4）。SGD 的噪声刚好能把参数"踹"出这些不是极小值的停点；代价是末段需要逐步减小学习率（退火）。工业实践的标准选择几乎总是 mini-batch——**在"方向准"与"走得快"之间取 $B \in [16, 256]$ 的折中**。

### 0.4.4 收敛判据与鞍点

**何时停止训练**，三个工程判据（`ml-03`/`ml-08` 会看到它们的参数化形态）：

1. 梯度范数 $\lVert \nabla L \rVert < \text{tol}$——真的"无路可下"；
2. 达到最大迭代数——预算用完；
3. 验证损失连续若干轮不再下降——提前停止（early stopping，`ml-05` 的正题之一）。

判据一有个经典反例。ds-00 0.2.10 的那个鞍点函数 $f(x,y) = x^2 + 3xy + y^2$，Hessian 特征值 $[-1, 5]$，原点是**鞍点**——梯度在那里恰好为零：

```python
>>> grad2 = lambda p: np.array([2*p[0] + 3*p[1], 3*p[0] + 2*p[1]])
>>> p = np.array([1e-9, 1e-9])        # 几乎就在鞍点
>>> for _ in range(8): p = p - 0.1 * grad2(p)
>>> p.round(4), round(float(p[0]**2 + 3*p[0]*p[1] + p[1]**2), 6)
(array([0., 0.]), 0.0)                 # 梯度为零，一步不动
>>> p = np.array([0.1, 0.0])           # 离鞍点一点点
>>> for _ in range(8): p = p - 0.1 * grad2(p)
>>> p.round(4), round(float(p[0]**2 + 3*p[0]*p[1] + p[1]**2), 6)
(array([ 0.1074, -0.107 ]), -0.011487)  # 沿下坡方向滑走，f 变负
```

> **⚠️ 陷阱**：**梯度为零 ≠ 极小值**。它可能是极大值、可能是鞍点、可能是一片平台。高维问题里**鞍点比局部极小值常见得多**——要让所有方向都同步变成"凹"才能困住优化器，维度越高越难。这就是 0.4.3 "噪声是朋友"的定量理由，也是"没收敛"和"收敛到鞍点"必须靠 0.5.5 的训练/测试两条曲线区分的原因。

**一阶方法的边界**：梯度下降只用一阶信息，完全不看曲率（Hessian）。它不知道当前方向是"深谷"还是"缓坡"，只能把学习率当成对所有方向曲率的**最保守估计**。ml-03 会看到 L-BFGS 这类准牛顿法如何用二阶近似补齐这块短板，卷 4 会看到 Adam 如何用梯度的一阶/二阶矩做自适应。

## 0.5 模型评估的数学口径

ds-04 开头那张表里有一行写着"区间报告模板（点估计 + 区间 + 方法 + $n$）→ 卷 3 的模型评估"。统计推断为参数给口径，模型评估要**为"一个预测函数有多好"另立一套口径**。本节是 ml-05 的数学前置。

### 0.5.1 训练目标与评估口径：两样东西

一个模型的生命里有两种数，混淆它们是 ml-05 之前最常见的错误：

| | 训练目标 | 评估口径 |
|---|----------|----------|
| 作用对象 | 优化器（算法吃它） | 人（决策看它） |
| 要求 | 可导、好优化 | 可解释、贴近业务 |
| 例子 | 对数损失、平方损失 | Accuracy、$R^2$ |

0.1.3 已经见过最极端的对照：**0-1 损失是最好的评估口径、最差的训练目标**（不可导）。训练用什么损失是算法问题，评估用什么指标是业务问题——**两者经常不是同一个函数**。

### 0.5.2 回归口径：MSE / RMSE / MAE / $R^2$

前三个是"误差有多大致命"的三种量刑，看的是同一批残差 $e^{(i)} = f(x^{(i)}) - y^{(i)}$：

- $\mathrm{MSE} = \frac{1}{n}\sum (e^{(i)})^2$：训练目标惯用，大误差被平方放大
- $\mathrm{RMSE} = \sqrt{\mathrm{MSE}}$：与 $y$ 同量纲，可直接读"平均差几个单位"
- $\mathrm{MAE} = \frac{1}{n}\sum \lvert e^{(i)}\rvert$：中位数气质，对离群点稳健

第四个是"比基准好多少"：

$$R^2 = 1 - \frac{\mathrm{SS}_{res}}{\mathrm{SS}_{tot}} = 1 - \frac{\sum_i (y^{(i)} - f(x^{(i)}))^2}{\sum_i (y^{(i)} - \bar y)^2}$$

$\mathrm{SS}_{tot}$ 是"永远报均值"这个基准模型的总平方误差，$R^2$ 因此读作"把基准模型的误差挤掉了百分之多少"。ds-04 `linregress` 返回的 `rvalue` 的平方就是它（单变量线性回归时）。

同一份真值（带噪声正弦），三种预测器的四指标对比：

```python
rng = np.random.default_rng(3)
x = np.linspace(0, 2 * np.pi, 60)
y_true = np.sin(x) + rng.normal(scale=0.15, size=60)
pred_good = np.sin(x)                                    # 抓住信号
pred_mean = np.full_like(y_true, y_true.mean())           # 永远报均值
pred_bad = np.sin(x + 2.5)                               # 结构性错相位

def metrics(y, p):
    mse = np.mean((y - p) ** 2)
    ss_res = np.sum((y - p) ** 2)
    ss_tot = np.sum((y - y.mean()) ** 2)
    return mse, np.sqrt(mse), np.mean(np.abs(y - p)), 1 - ss_res / ss_tot

for name, p in (("好预测", pred_good), ("永远报均值", pred_mean), ("错相位", pred_bad)):
    print(f"{name:<8} " + "  ".join(f"{v:.4f}" for v in metrics(y_true, p)))
# 好预测      0.0258  0.1607  0.1186  0.9508
# 永远报均值  0.5245  0.7242  0.6483  0.0000
# 错相位      1.8292  1.3525  1.2105  -2.4872
```

| 预测器 | MSE | RMSE | MAE | $R^2$ |
|--------|-----|------|-----|-------|
| 好预测 | 0.0258 | 0.1607 | 0.1186 | 0.9508 |
| 永远报均值 | 0.5245 | 0.7242 | 0.6483 | 0.0000 |
| 错相位 | 1.8292 | 1.3525 | 1.2105 | −2.4872 |

中间那行是基准模型自己——$R^2=0$ 证明前面的定义自洽；最下面那行是结构性错误（相位错半圈），$R^2$ 直接为负：**$R^2 < 0$ 表示模型比"无脑报均值"还差**，是完全合法的取值。

离群点对 MSE 和 MAE 的杀伤力完全不同。在真值里插一个约 10 倍噪声的离群样本：

```python
y_out = y_true.copy()
y_out[30] += 5.0
p = np.sin(x)
i = np.r_[0:30, 31:60]                    # 排除下标 30 的离群样本
print(f"MSE 含={np.mean((y_out - p) ** 2):.3f} 删={np.mean((y_out[i] - p[i]) ** 2):.3f}")
print(f"MAE 含={np.mean(np.abs(y_out - p)):.3f} 删={np.mean(np.abs(y_out[i] - p[i])):.3f}")
# MSE 含=0.420 删=0.026
# MAE 含=0.198 删=0.118
```

| | MSE | MAE |
|---|-----|-----|
| 含离群 | 0.420 | 0.198 |
| 删离群 | 0.026 | 0.118 |

删掉单点后 MSE 缩小 **16 倍**、MAE 只缩小 1.7 倍——一个离群样本抢走了整个 MSE 的方向盘。**MSE 训练 + MAE 体检**是处理含离群数据的常见组合（`ml-03` 稳健回归的动机）。

> **⚠️ 陷阱**：$R^2$ 高不代表模型对。给线性趋势但异方差的数据加二次项，$R^2$ 还会涨一点——拟合优度衡量的是方差解释了多少，不衡量"结构是否正确"。诊断要看残差图（ds-05 5.5 的残差四查）。

### 0.5.3 分类口径：混淆矩阵是一切指标的源

二分类的原始结果是四个计数——**混淆矩阵**（行=真值，列=预测）：

$$\begin{array}{c|cc} & \text{预测 0} & \text{预测 1} \\ \hline \text{真值 0} & \mathrm{TN} & \mathrm{FP} \\ \text{真值 1} & \mathrm{FN} & \mathrm{TP} \end{array}$$

全部常用指标都是这四个计数的四则运算：

| 指标 | 公式 | 读法 | 关心它的典型业务 |
|------|------|------|----------------|
| Accuracy | $\frac{\mathrm{TP+TN}}{\text{总数}}$ | 整体猜对的比例 | 均衡分类 |
| Precision（查准率） | $\frac{\mathrm{TP}}{\mathrm{TP+FP}}$ | 预测为 1 的里面有多少真的是 1 | 检索、广告 |
| Recall（查全率） | $\frac{\mathrm{TP}}{\mathrm{TP+FN}}$ | 真的是 1 的里面有多少被找到 | 医疗、欺诈 |
| F1 | $\frac{2\,\mathrm{PR}}{\mathrm{P+R}}$ | 两者的调和平均 | 折中 |

**99:1 的不平衡数据，一个永远预测多数类的分类器**。混淆矩阵就是四个计数，逐细胞手写：

```python
>>> def confusion_counts(y_true, y_pred):
...     tp = int(np.sum((y_true == 1) & (y_pred == 1)))
...     tn = int(np.sum((y_true == 0) & (y_pred == 0)))
...     fp = int(np.sum((y_true == 0) & (y_pred == 1)))
...     fn = int(np.sum((y_true == 1) & (y_pred == 0)))
...     return tn, fp, fn, tp
>>> y_true_c = np.array([0] * 990 + [1] * 10)
>>> y_pred_all0 = np.zeros(1000, dtype=int)          # 一律预测负类
>>> tn, fp, fn, tp = confusion_counts(y_true_c, y_pred_all0)
>>> print(f"      预测0  预测1\n真值0 {tn:>5} {fp:>5}\n真值1 {fn:>5} {tp:>5}")
      预测0  预测1
真值0   990     0
真值1    10     0
>>> acc = (tp + tn) / (tp + tn + fp + fn)
>>> prec = tp / (tp + fp) if tp + fp > 0 else 0.0    # 分母为 0 时的口径
>>> rec = tp / (tp + fn)
>>> f1 = 2 * prec * rec / (prec + rec) if prec + rec > 0 else 0.0
>>> f"accuracy={acc:.4f} precision={prec:.4f} recall={rec:.4f} F1={f1:.4f}"
'accuracy=0.9900 precision=0.0000 recall=0.0000 F1=0.0000'
```

**99% 准确率，正类一个没找到。** Accuracy 在这种分布下被多数类完全绑架。换一个"10 个正类找到 7 个、误报 5 个"的模型：

```python
>>> y_pred_c = np.zeros(1000, dtype=int)
>>> y_pred_c[990:997] = 1                             # 真值 1：找对 7 个
>>> y_pred_c[0:5] = 1                                 # 真值 0：误报 5 个
>>> tn, fp, fn, tp = confusion_counts(y_true_c, y_pred_c)
>>> print(f"      预测0  预测1\n真值0 {tn:>5} {fp:>5}\n真值1 {fn:>5} {tp:>5}")
      预测0  预测1
真值0   985     5
真值1     3     7
>>> acc = (tp + tn) / (tp + tn + fp + fn); prec = tp / (tp + fp); rec = tp / (tp + fn)
>>> f"accuracy={acc:.4f} precision={prec:.4f} recall={rec:.4f} F1={2*prec*rec/(prec+rec):.4f}"
'accuracy=0.9920 precision=0.5833 recall=0.7000 F1=0.6364'
```

注意准确率反而更高（0.992 vs 0.990）——**按 Accuracy 选模型会选中那个对少数类完全不作为的**。不平衡场景下，报告必须带类别比例，指标必须落到正类（或 macro 平均）上。

> **⚠️ 陷阱**：Precision 与 Recall 是一根跷跷板——阈值越激进，Recall 越高、Precision 越低。**单看一个数必然误导**；`ml-05` 会把这对指标展开成 PR 曲线与 ROC/AUC 的完整口径。

### 0.5.4 概率口径：交叉熵 = 最大似然的另一个写法

ds-04 讲过最大似然：选定参数使观测数据出现的概率最大。机器学习把这个原则搬了家——**参数从分布参数变成了模型参数**，最大化对象从样本概率变成了预测概率。

对二分类，模型对样本 $i$ 预测 $\hat y^{(i)} = p_\theta(y{=}1 \mid x^{(i)})$。似然函数（把所有样本的概率乘起来）：

$$\mathcal{L}(\theta) = \prod_i \left(\hat y^{(i)}\right)^{y^{(i)}} \left(1-\hat y^{(i)}\right)^{1-y^{(i)}}$$

乘积难优化，取对数变求和、再取负变最小化，代入 0.1.3 的经验损失框架，得到**二元交叉熵**：

$$L(\theta) = -\frac{1}{n}\sum_i \left[y^{(i)}\ln \hat y^{(i)} + (1-y^{(i)})\ln(1-\hat y^{(i)})\right]$$

同一个东西的三副面孔：**最大似然 ↔ 最小化交叉熵 ↔ 最小化负对数似然**。两种概率模型在同一批标签上的实测：

```python
>>> labels = np.array([1, 0, 1, 1, 0])
>>> p_good = np.array([0.9, 0.1, 0.8, 0.7, 0.2])     # 更懂行
>>> p_poor = np.array([0.6, 0.4, 0.55, 0.5, 0.45])
>>> ll = lambda p: np.mean(np.log(np.where(labels == 1, p, 1 - p)))
>>> f"好模型: 平均对数似然 {ll(p_good):+.4f}, 交叉熵 {-ll(p_good):.4f}"
'好模型: 平均对数似然 -0.2027, 交叉熵 0.2027'
>>> f"差模型: 平均对数似然 {ll(p_poor):+.4f}, 交叉熵 {-ll(p_poor):.4f}"
'差模型: 平均对数似然 -0.5821, 交叉熵 0.5821'
```

好模型的交叉熵只有差模型的三分之一。**注意这个口径的单位是"每样本 nat"**（自然对数），可与 `ml-05` 的对数损失直接互读。

> **⚠️ 陷阱**：$\hat y = 0$ 或 $1$ 时 $\ln \hat y = -\infty$。实战必须 `np.clip(p, 1e-12, 1-1e-12)`，或干脆对 logits 计算（log-sum-exp，0.3.1 的 softmax 稳定版就是这个思路）。** Sklearn 的 `LogisticRegression` 内部永远在 logit 空间算，这就是它不会报 `log(0)` 的原因。**

**为什么分类不用 MSE？** 把 $\hat y = \sigma(z)$ 代入平方损失求导，链条末尾会多乘一个 $\sigma'(z) = \sigma(z)(1-\sigma(z))$，而它在 $z$ 远离 0 时**指数衰减**。真值 $y=1$、模型给出 logits $z$：

```python
for z in (-6.0, -2.0, 0.0):
    p = 1.0 / (1.0 + np.exp(-z))
    ce = abs(p - 1.0)
    mse = abs(2 * (p - 1.0) * p * (1 - p))
    print(f"z={z:>4.0f}  p={p:.5f}  CE={ce:.5f}  MSE={mse:.5f}")
# z=  -6  p=0.00247  CE=0.99753  MSE=0.00492
# z=  -2  p=0.11920  CE=0.88080  MSE=0.18496
# z=   0  p=0.50000  CE=0.50000  MSE=0.25000
```

| $z$ | $p=\sigma(z)$ | $\lvert$CE 梯度$\rvert = \lvert p-y\rvert$ | $\lvert$MSE 梯度$\rvert = 2\lvert p-y\rvert p(1-p)$ |
|-----|------|------|------|
| −6 | 0.00247 | 0.99753 | 0.00492 |
| −2 | 0.11920 | 0.88080 | 0.18496 |
| 0 | 0.50000 | 0.50000 | 0.25000 |

**预测错得越自信（$z=-6$），MSE 的梯度反而越小**（0.005，比 CE 小 200 倍）——模型在最需要纠正的地方几乎收不到信号，这就是经典的**梯度消失**。交叉熵与 softmax 的合并导数恰好把 $\sigma'$ 抵消掉（0.3.2 的 $\delta_2 = p - \mathrm{onehot}(y)$），梯度恒为 $p - y$，错得越自信信号越强。**分类问题配交叉熵，是数学选择的必然，不是潮流。**

### 0.5.5 偏差-方差分解：过拟合的数学本体

"过拟合"的定量版本。对测试点 $(x, y)$，$y = f(x) + \varepsilon$（噪声 $\varepsilon$ 方差 $\sigma^2$），模型预测 $\hat f(x)$，可以证明（用同一训练集重复采样）：

$$E\left[(y - \hat f(x))^2\right] = \underbrace{\big(E[\hat f] - f\big)^2}_{\text{偏差}^2} + \underbrace{\mathrm{Var}(\hat f)}_{\text{方差}} + \sigma^2$$

三项各有读法：**偏差**是"学错了"（模型太简单），**方差**是"学飘了"（对训练集太敏感），**噪声**是天花板。经典实验：真值 $\sin(2\pi x)$、噪声 $\sigma=0.3$、25 个训练样本，多项式 1–12 阶逐阶拟合（用 ds-00 0.2.11 前见过的最小二乘思路——多项式拟合的基函数是范德蒙德矩阵）：

```python
rng_tr = np.random.default_rng(2026)
x_tr = rng_tr.uniform(0, 1, 25)
y_tr = np.sin(2 * np.pi * x_tr) + rng_tr.normal(scale=0.3, size=25)
x_te = np.linspace(0, 1, 200)
y_te = np.sin(2 * np.pi * x_te) + np.random.default_rng(999).normal(scale=0.3, size=200)

for deg in range(1, 13):
    coef = np.polyfit(x_tr, y_tr, deg)
    mse_tr = np.mean((y_tr - np.polyval(coef, x_tr)) ** 2)
    mse_te = np.mean((y_te - np.polyval(coef, x_te)) ** 2)
    print(f"{deg:>2}  {mse_tr:>10.4f}  {mse_te:>10.4f}")
#  1     0.2818     0.3728
#  2     0.2734     0.4117
#  3     0.1102     0.1597
#  4     0.1001     0.1600
#  5     0.0988     0.1431
#  6     0.0844     0.2312
#  7     0.0816     0.3396
#  8     0.0775     0.1577
#  9     0.0739     0.7722
# 10     0.0720     4.9315
# 11     0.0545    78.3155
# 12     0.0544    54.4488
```

**训练 MSE 单调下降，测试 MSE 在第 5 阶触底后暴涨**——这就是 U 曲线：

- 1–2 阶：训练误差本身就高 → **欠拟合（高偏差）**，模型装不下 $\sin$ 的弯
- 5 阶附近：测试误差最小 → 复杂度恰好
- 9 阶以上：训练误差继续变小、测试误差爆炸到 78 → **过拟合（高方差）**，高阶多项式在训练点之间剧烈摆动

诊断动作表（ml-05/06 的日常）：

| 症状 | 训练误差 | 验证误差 | 病名 | 处方 |
|------|----------|----------|------|------|
| 都高 | 高 | 高 | 欠拟合 | 换更复杂模型 / 加特征 |
| 训练低、验证高 | 低 | 高 | 过拟合 | 加正则 / 加数据 / 降复杂度 |
| 差距合理 | 低 | 略高 | 正常 | 收工 |

注意 8 阶那次测试 MSE 回落到 0.1577 的抖动——真实数据的 U 曲线不是教科书那么光滑，**结论要看总体趋势，不看单一抖动**；想定量就要 0.5.6 的多次划分。

### 0.5.6 三分天下：训练/验证/测试的数学含义

为什么不能一份(data)打天下？因为**评估本身是抽样**。验证集误差不是"模型的属性"，而是"模型 + 这一份验证集"的属性——换一份就变。把 0.5.5 的三阶模型放到 50 个样本上，跑 20 次不同的训练/验证划分（数据固定，只有划分在变）：

```python
rng50 = np.random.default_rng(2026)
x50 = rng50.uniform(0, 1, 50)
y50 = np.sin(2 * np.pi * x50) + rng50.normal(scale=0.3, size=50)
scores = []
for seed in range(20):
    idx = np.random.default_rng(seed).permutation(50)
    tr_i, val_i = idx[20:], idx[:20]              # 50 个里验证 20 个
    coef = np.polyfit(x50[tr_i], y50[tr_i], 3)
    scores.append(np.mean((y50[val_i] - np.polyval(coef, x50[val_i])) ** 2))
scores = np.array(scores)
print(f"均值 {scores.mean():.4f} ± {scores.std(ddof=1):.4f}   最小 {scores.min():.4f} 最大 {scores.max():.4f}")
# 均值 0.1194 ± 0.0447   最小 0.0539 最大 0.2223
```

同一模型的验证 MSE 在 $0.12 \pm 0.04$ 之间浮动——**最大值是最小值的 4 倍**。这正是 ds-00 0.4.2 的抽样分布在评估上的投影：验证集误差本身是一个随机变量，单点报告的精度是假的。

工程结论三条：

1. **训练集**调参数（梯度下降看它）；**验证集**选模型/超参数；**测试集**只在最后一次用。测试集碰第二次，它就变成了第二个验证集。
2. 报告模型得分必须给**分布**：交叉验证的多个折、或多次随机划分的均值±标准差——这正是 `ml-05` 的全部动机，折的种子用 ds-01 的 `SeedSequence.spawn` 派生。
3. 在验证集上调过超参数后，测试集分数仍然偏乐观（超参数是"看"着验证集选出来的）；严谨的做法是嵌套交叉验证（`ml-05` 深水）。

> **⚠️ 陷阱**：**"测试集只能用一次"是纪律，不是技术**。它没有软件强制，一旦把测试结果拿回来调参，泄漏就发生了，且 lossless 看不出来——只能靠流程保证（`ml-08` 的流水线会把这条纪律落成代码）。

## 0.6 综合实战：从零训一个逻辑回归

把全章串成一条流水线：**造数据 → 划分 → 初始化 → 前向 → 反向 → 梯度核对 → mini-batch 训练 → 验证集评估**。全程只用 NumPy——下一章 ml-01 会告诉你哪些行被 sklearn 一行取代。

**第 1 步：造数据与种子三分**（0.1.4）。两个互相重叠的高斯团，数据/划分/初始化三个 rng 互不污染：

```python
import numpy as np
from numpy.random import default_rng, SeedSequence

def make_blobs(rng, n_per_class=100):
    X0 = rng.normal(loc=[2.0, 2.0], scale=1.4, size=(n_per_class, 2))
    X1 = rng.normal(loc=[-2.0, -2.0], scale=1.4, size=(n_per_class, 2))
    X = np.vstack([X0, X1])
    y = np.r_[np.zeros(n_per_class), np.ones(n_per_class)].astype(int)
    return X, y

ss = SeedSequence(2026)
rng_data, rng_split, rng_init = map(default_rng, ss.spawn(3))
X, y = make_blobs(rng_data)

perm = rng_split.permutation(len(y))
n_val = 60
val_idx, tr_idx = perm[:n_val], perm[n_val:]
X_tr, y_tr = X[tr_idx], y[tr_idx]
X_val, y_val = X[val_idx], y[val_idx]
```

划分结果：训练集 140 样本，验证集 60 样本。

**第 2 步：模型与损失**（0.1.2、0.5.4）。$\hat y = \sigma(Xw+b)$，交叉熵损失，`np.clip` 防 $\log 0$：

```python
def sigmoid(z): return 1.0 / (1.0 + np.exp(-z))
def predict(X, w, b): return sigmoid(X @ w + b)
def loss(X, y, w, b):
    p = np.clip(predict(X, w, b), 1e-12, 1 - 1e-12)
    return -np.mean(y * np.log(p) + (1 - y) * np.log(1 - p))
```

**第 3 步：梯度**（0.2.2、0.3.2）。softmax 换成 sigmoid 后，$\delta = p - y$ 形式不变（0.5.4 末尾的合并导数），得到全章最短的两条公式：

$$\frac{\partial L}{\partial w} = \frac{1}{n}X^\top(p-y), \qquad \frac{\partial L}{\partial b} = \mathrm{mean}(p-y)$$

```python
def grad(X, y, w, b):
    p = predict(X, w, b)
    return X.T @ (p - y) / len(y), np.mean(p - y)
```

**第 4 步：梯度核对**（0.3.3）。在写训练循环**之前**做——对 $w$、$b$ 各做一次中心差分扰动：

```python
w = rng_init.normal(scale=0.1, size=2)            # 用初始化那个 rng
b = 0.0
eps = 1e-6
dw_n = np.zeros_like(w)
for i in range(2):
    wp, wm = w.copy(), w.copy()
    wp[i] += eps; wm[i] -= eps
    dw_n[i] = (loss(X_tr, y_tr, wp, b) - loss(X_tr, y_tr, wm, b)) / (2 * eps)
db_n = (loss(X_tr, y_tr, w, b + eps) - loss(X_tr, y_tr, w, b - eps)) / (2 * eps)
dw_a, db_a = grad(X_tr, y_tr, w, b)
rel_w = np.abs(dw_a - dw_n) / (np.abs(dw_n) + 1e-12)
print(f"dw 最大相对误差 {rel_w.max():.2e}   db 相对误差 {abs(db_a - db_n) / (abs(db_n) + 1e-12):.2e}")
# dw 最大相对误差 8.24e-11   db 相对误差 6.15e-09
```

合格。**第 5 步：mini-batch 训练**（0.4.3），batch=32、200 轮，并扫描学习率（0.4.2）：

```python
def train(lr, epochs=200, batch=32, seed=2026):
    rng_run = default_rng(seed)                   # 训练内部的打乱种子
    w_t = rng_init.normal(scale=0.1, size=2).copy()
    b_t = 0.0
    marks = {}
    for epoch in range(1, epochs + 1):
        perm = rng_run.permutation(len(y_tr))
        for start in range(0, len(y_tr), batch):
            idx = perm[start:start + batch]
            dw, db = grad(X_tr[idx], y_tr[idx], w_t, b_t)
            w_t, b_t = w_t - lr * dw, b_t - lr * db
        if epoch in (1, 25, 50, 100, 200):
            marks[epoch] = loss(X_tr, y_tr, w_t, b_t)
    return w_t, b_t, marks

for lr in (0.05, 0.5, 5.0):
    w_t, b_t, marks = train(lr)
    val_loss = loss(X_val, y_val, w_t, b_t)
    acc = np.mean((predict(X_val, w_t, b_t) >= 0.5).astype(int) == y_val)
    trail = "  ".join(f"{marks[e]:.4f}" for e in (1, 25, 50, 100, 200))
    print(f"lr={lr:<5} {trail}  验证损失={val_loss:.4f}  验证acc={acc:.4f}")
# lr=0.05  0.4038  0.0549  0.0356  0.0230  0.0146  验证损失=0.0880  验证acc=0.9667
# lr=0.50  0.0755  0.0124  0.0076  0.0045  0.0026  验证损失=0.1040  验证acc=0.9667
# lr=5.00  0.0015  0.0006  0.0005  0.0003  0.0002  验证损失=0.1554  验证acc=0.9667
```

| lr | 第 1 轮 | 第 25 轮 | 第 50 轮 | 第 100 轮 | 第 200 轮 | 验证损失 | 验证 acc |
|----|---------|----------|----------|-----------|-----------|----------|----------|
| 0.05 | 0.4038 | 0.0549 | 0.0356 | 0.0230 | 0.0146 | 0.0880 | 0.9667 |
| 0.50 | 0.0755 | 0.0124 | 0.0076 | 0.0045 | 0.0026 | 0.1040 | 0.9667 |
| 5.00 | 0.0015 | 0.0006 | 0.0005 | 0.0003 | 0.0002 | 0.1554 | 0.9667 |

三个学习率最终验证 Accuracy 都是 96.67%，但**验证损失揭示了分歧**：lr=5.00 训练损失压到 0.0002，验证损失却是三者最差（0.1554）——训练目标降得快不代表泛化好，这正是 0.5.1"两个口径"与 0.5.5"过拟合"在本实验里的现身。选 lr=0.5。

**第 6 步：验证集评估**（0.5.3）。用 0.5.3 的四个计数（正类=类别 1）：

```python
w_t, b_t, _ = train(0.5)
p_val = predict(X_val, w_t, b_t)
y_pred = (p_val >= 0.5).astype(int)
tp = int(np.sum((y_val == 1) & (y_pred == 1)))
tn = int(np.sum((y_val == 0) & (y_pred == 0)))
fp = int(np.sum((y_val == 0) & (y_pred == 1)))
fn = int(np.sum((y_val == 1) & (y_pred == 0)))
prec, rec = tp / (tp + fp), tp / (tp + fn)
print(f"      预测0  预测1\n真值0 {tn:>5} {fp:>5}\n真值1 {fn:>5} {tp:>5}")
print(f"accuracy={(tp+tn)/len(y_val):.4f} precision={prec:.4f} recall={rec:.4f} F1={2*prec*rec/(prec+rec):.4f}")
print(f"最终权重 w = {np.round(w_t, 4)}，b = {b_t:.4f}")
#       预测0  预测1
# 真值0    30     1
# 真值1     1    28
# accuracy=0.9667 precision=0.9655 recall=0.9655 F1=0.9655
# 最终权重 w = [-3.7944 -2.5727]，b = -0.0546
```

学到的权重指向两团中心连线的法方向（$[-3.79, -2.57]$ 与 $[2,2]\to[-2,-2]$ 的连线垂直），几何上完全正确。

**第 7 步：给分数加误差棒**（0.5.6）。整套流程（重划分 + 重训练）跑 20 遍：

```python
accs = []
for seed in range(20):
    idx = default_rng(seed).permutation(len(y))
    vi, ti = idx[:n_val], idx[n_val:]
    w_s, b_s, _ = train(0.5, seed=seed)
    pred = (predict(X[vi], w_s, b_s) >= 0.5).astype(int)
    accs.append(np.mean(pred == y[vi]))
accs = np.array(accs)
print(f"20 次划分的验证 accuracy：{accs.mean():.4f} ± {accs.std(ddof=1):.4f}")
# 20 次划分的验证 accuracy：0.9942 ± 0.0082
```

第一次划分的 0.9667 落在均值之下两个标准差外——**单次划分的分数确实可能系统性偏低**。这就是交叉验证存在的理由。

## 本章小结

| 主题 | 核心要点 |
|------|---------|
| 样本记号 | $x^{(i)}$ 上标括号是编号不是幂；$X$ 行=样本、列=特征（`(n, d)` 契约三家共用） |
| 假设与参数 | 模型是带旋钮的函数 $f_\theta$；**参数**靠训练、**超参数**靠选择，混淆即泄漏 |
| 损失 | 单样本损失平均成经验损失；报损失必须说损失函数；0-1 损失是评估口径、不是训练目标 |
| 种子三分 | 数据/初始化/分折各派生子 rng；`spawn` 一次存好，重复调用即不可复现 |
| 一元链式法则 | $(g \circ f)' = g'(f)\cdot f'$；先拆内外，再乘 |
| 多元链式法则 | 局部雅可比相乘；线性回归 $\partial L/\partial w = \frac{2}{n}X^\top(Xw-y)$ |
| 计算图 | 节点=操作；反向=每个节点用"局部×上游"，卷 4 autograd 的地基 |
| 前向传播 | 形状一路传：$(n,d)\to(n,h)\to(n,k)$；权重形状 $(d,h)$、$(h,k)$ |
| 反向传播 | softmax+交叉熵合并为 $p-\mathrm{onehot}$；$\tanh' = 1-\tanh^2$；先写形状表 |
| 梯度核对 | 数值 vs 解析；相对误差 $<10^{-6}$ 才放心；生产期关闭 |
| 更新规则 | $\theta \leftarrow \theta - \eta\nabla L$；一维是"每步乘 $(1-2\eta)$" |
| 学习率 | 判据 $|1-2\eta|<1$；太慢像假收敛，太快横跳或发散；全方向共用 $\eta$ 被最陡方向卡住 |
| 批量三档 | BGD 准、SGD 快、mini-batch 兼顾；梯度方差 $\propto 1/\sqrt B$；噪声能踹出鞍点 |
| 收敛 | 判据是**梯度范数 < tol**，不是损失曲线变平；梯度为零≠极小（鞍点随维度变常见） |
| 评估口径 | 训练目标（可导）≠ 评估指标（可解释）；两者经常不是同一函数 |
| 回归四指标 | MSE 放大离群、MAE 稳健、RMSE 同量纲；$R^2$ 是"挤出基准多少误差"，可为负 |
| 分类四指标 | 全部由混淆矩阵四个计数派生；不平衡下 Accuracy 被多数类绑架；P/R 是跷跷板 |
| 交叉熵 | 最大似然 = 最小化交叉熵 = 负对数似然；$\log 0$ 必须 clip 或走 logit 空间 |
| 不用 MSE 做分类 | 自信且错时 MSE 梯度 $\propto \sigma'$ 消失；CE+softmax 合并把 $\sigma'$ 抵消，梯度恒为 $p-y$ |
| 偏差-方差 | 误差 = 偏差² + 方差 + 噪声；训练↓测试↑ 的 U 曲线即过拟合本体 |
| 三分天下 | 训练调参、验证选型、测试一次；验证误差本身是随机变量，报告必须给分布 |
