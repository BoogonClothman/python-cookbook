## S1 浮点数的物理：误差从哪来

主章 5.2.3 给了结论——"残差小不等于误差小"。本节给出这个结论的**数学来源**，以及误差在浮点运算里最初的诞生地。

### S1.1 机器精度与有效位数

双精度浮点数按 IEEE 754 有 53 位有效二进制位，于是

```python
>>> eps = np.finfo(float).eps
>>> eps, 1/eps, np.finfo(float).precision
(2.220446049250313e-16, 4503599627370496.0, 15)
```

`eps` 的定义是"1 与下一个可表示的浮点数之间的距离"，等于 $2^{-52} = 2.22\times10^{-16}$。三个必须记住的数：

| 量 | 值 | 含义 |
|----|-----|------|
| $\epsilon$ | $2.22\times10^{-16}$ | 1 附近的最小间隔 |
| $1/\epsilon$ | $4.50\times10^{15}$ | 条件数的"危险阈值"（主章 5.2.3 的 `LinAlgWarning` 就卡在这里） |
| `precision` | 15 | 十进制有效位数 |

**关键点：$\epsilon$ 是相对量，不是绝对量。** $10^{8}$ 附近的浮点数间隔是 $10^8 \times \epsilon \approx 2.2\times10^{-8}$——大数附近更稀疏。这直接导致了下一小节的灾难。

### S1.2 灾难性抵消：方差公式的崩塌

方差有两条数学上等价的公式：

$$\mathrm{Var}(x) = \mathbb{E}[x^2] - (\mathbb{E}[x])^2 \qquad\text{（"朴素"式）}$$
$$\mathrm{Var}(x) = \mathbb{E}\bigl[(x - \mathbb{E}[x])^2\bigr] \qquad\text{（平移式）}$$

它们数值上**完全不等价**。取 $x = c + \mathcal{N}(0,1)$（真方差 1），$n = 10^5$：

```python
>>> x = c + rng.normal(0, 1, 100_000)
>>> v_naive   = (x**2).mean() - x.mean()**2
>>> v_shifted = ((x - x.mean())**2).mean()
```

| $c$ | 朴素式 | 平移式 | 朴素式相对误差 |
|-----|--------|--------|--------------|
| $1$ | 1.000257 | 1.000257 | 2.6e-04 |
| $10^{4}$ | 1.004543 | 1.004543 | 4.5e-03 |
| $10^{8}$ | **0.000000** | 1.001878 | **1.00（100% 错）** |

$c = 10^{8}$ 时朴素式给出 **0.000000**——不是"精度差一点"，而是**一位有效数字都不剩**。

**机制**：$\mathbb{E}[x^2] \approx 10^{16}$，$(\mathbb{E}[x])^2 \approx 10^{16}$，两者相减得到 1。两个 $10^{16}$ 量级的数各带 $10^{16}\epsilon \approx 2.2$ 的绝对误差，相减后这个误差原封不动地留在结果里，而结果本身只有 1——**相对误差 220%**。

> **机制洞察**：浮点误差的绝对大小由**操作数的量级**决定，与结果的量级无关。所以"两个大数相减得到小数"是把绝对误差变成相对误差的放大器。这条机制的名字叫**灾难性抵消**（catastrophic cancellation），它是所有数值事故里最常见的一个源头。
>
> **识别方法**：看到 `a - b` 而 $a \approx b$，就该警觉。**修法不是提高精度，而是改公式**——把 $a - b$ 改写成不需要相减的形式（本例就是先把数据中心化）。提高精度只是把崩塌点往后推（单精度在 $c = 10^{4}$ 就崩了），改公式才是根治。

另一个经典例子是二次方程求根 $x = \frac{-b \pm \sqrt{b^2 - 4ac}}{2a}$：当 $b^2 \gg 4ac$ 时，$b$ 与 $\sqrt{b^2-4ac}$ 几乎相等，其中一个根会失去全部有效位。稳定的写法是利用 $x_1 x_2 = c/a$，先用"加法版"算大的那个根，再用乘积算小的那个。

### S1.3 前向误差与后向误差：两笔不同的账

数值分析把误差分成两个量，混用它们是绝大多数"解不准"争论的根源：

| 量 | 定义 | 在解 $Ax=b$ 里 | 谁关心 |
|----|------|--------------|--------|
| **前向误差** | 算出的解离真解多远 | $\lVert \hat{x} - x \rVert$ | 用户 |
| **后向误差 / 残差** | 算出的解满足原方程到什么程度 | $\lVert b - A\hat{x} \rVert$ | 算法 |

**稳定算法的定义就是"后向误差小"**：带选主元的 LU 保证 $\hat{x}$ 是某个扰动矩阵 $(A + \Delta A)$ 的精确解，且 $\lVert \Delta A \rVert \lesssim n\epsilon\lVert A \rVert$。至于前向误差有多大，取决于问题本身——这正是条件数的角色。

用 Hilbert 矩阵实测两者的关系（真解取全 1，$b = H\mathbf{1}$）：

| $n$ | $\mathrm{cond}(H)$ | 后向误差（残差） | 前向误差 | 前向/后向 |
|-----|------------------|--------------|---------|----------|
| 4 | 1.55e+04 | 1.11e-16 | 4.23e-13 | 3.81e+03 |
| 6 | 1.50e+07 | 2.22e-16 | 3.10e-10 | 1.39e+06 |
| 8 | 1.53e+10 | 2.22e-16 | 5.44e-07 | 2.45e+09 |
| 10 | 1.60e+13 | 4.44e-16 | 4.53e-04 | 1.02e+12 |
| 12 | 1.81e+16 | 4.44e-16 | 3.87e-01 | 8.71e+14 |

**后向误差始终停在 $\epsilon$ 量级**（$10^{-16}$，这就是"算法稳定"的含义），而前向误差从 $10^{-13}$ 涨到 $10^{-1}$。最后一列的比值与 $\mathrm{cond}(H)$ 逐行同量级——这不是巧合。

### S1.4 残差小 ≠ 误差小：不等式的证明骨架

设 $x$ 是真解、$\hat{x}$ 是计算解，记残差 $r = b - A\hat{x}$。由 $Ax = b$ 得

$$A(\hat{x} - x) = -r \quad\Longrightarrow\quad \hat{x} - x = -A^{-1}r$$

取范数并放缩：

$$\lVert \hat{x} - x \rVert \le \lVert A^{-1} \rVert \cdot \lVert r \rVert = \lVert A^{-1} \rVert \lVert A \rVert \cdot \frac{\lVert r \rVert}{\lVert A \rVert}
= \mathrm{cond}(A) \cdot \frac{\lVert r \rVert}{\lVert A \rVert}$$

两边除以 $\lVert x \rVert$，并用 $\lVert x \rVert \ge \lVert b \rVert / \lVert A \rVert$：

$$\boxed{\ \frac{\lVert \hat{x} - x \rVert}{\lVert x \rVert} \;\le\; \mathrm{cond}(A)\cdot \frac{\lVert r \rVert}{\lVert b \rVert}\ }$$

**左边是相对前向误差，右边第一个因子是条件数、第二个是相对残差。** 主章 5.2.3 表格里"误差/残差 ≈ cond"就是这条不等式的经验版本。

三个推论，全部与主章的实测吻合：

1. **残差可以做到 $\epsilon$ 量级，前向误差不行**——因为后者还被 $\mathrm{cond}(A)$ 乘了一道。
2. **$\mathrm{cond}(A) \approx 1/\epsilon \approx 4.5\times10^{15}$ 是分界线**：此时误差上界达到 $O(1)$，一位有效数字都不剩。Hilbert $n = 12$ 的 $\mathrm{cond} = 1.8\times10^{16}$ 恰好在分界线之外，实测相对误差 0.39。
3. **$\mathrm{cond}(A)$ 在 $10^{6}$–$10^{14}$ 之间时，误差上界从 $10^{-10}$ 到 $10^{-2}$**——这就是主章说的"静默失准区"。求解器在这个区间里不会报警（它的判据是后向误差），而前向误差已经不可忽略。

> **实战建议**：报告一个线性方程组的解时，**后向误差（残差）与前向误差上界都要给**。只给残差等于隐藏了条件数这个关键信息；只给"解看起来对"则完全没有依据。主章 5.2.3 的 `solve_checked` 做的就是这件事。

## S2 分解的几何与算法

主章 5.2.4 列了四种分解"各答什么问题"。本节讲它们**内部怎么做**，以及为什么同一个数学分解有不同的数值表现。

### S2.1 LU 与选主元：增长因子

高斯消元把 $A$ 变成 $A = LU$。第 $k$ 步的主元是 $a_{kk}^{(k)}$，乘数是 $m_{ik} = a_{ik}^{(k)}/a_{kk}^{(k)}$。不选主元时，$|m_{ik}|$ 可以任意大：

```python
>>> B = np.array([[1e-20, 1.0],
...               [1.0,   1.0]])
>>> np.linalg.cond(B)
2.6180339887498953
```

$\mathrm{cond}(B) = 2.6$，问题本身完全良态。但不选主元的高斯消元第一步算出的乘数是 $m_{21} = 1/10^{-20} = 10^{20}$，于是

$$a_{22}^{(2)} = 1 - 10^{20} \approx -10^{20}$$

**原始信息 $a_{22} = 1$ 被彻底吃掉了**。这就是主章 5.2.2 里不选主元给出 `[0, 1]`（真解 `[1, 1]`）的原因。

数值分析用**增长因子**度量这件事：

$$\rho = \frac{\max_{i,j,k} \lvert a_{ij}^{(k)} \rvert}{\max_{i,j} \lvert a_{ij} \rvert}$$

选主元（部分选主元：在第 $k$ 列剩下的行里挑绝对值最大的当主元）把 $\rho$ 压到 $O(n)$ 的期望范围内，代价只是 $O(n^2)$ 次比较——相对于 $O(n^3)$ 的分解成本可以忽略。

> **机制洞察**：**选主元解决的不是"问题难"，而是"算法自己造误差"。**$\mathrm{cond}(B) = 2.6$ 说明问题一点不难，误差完全来自算法。数值分析因此把两件事分开记账：**问题的敏感度**用条件数，**算法的稳定性**用后向误差与增长因子。主章 5.2.2 那个 $\mathrm{cond} = 2.6$ 却算出错误解的例子，就是"算法不稳定"的极端形态。

`scipy.linalg.lu` 总是选主元，所以它给出的 $P$ 一般不是单位阵：

```python
>>> from scipy import linalg as la
>>> P, L, U = la.lu(B)
>>> P
array([[0., 1.],
       [1., 0.]])
>>> np.allclose(P @ L @ U, B)
True
```

**不做主元的 LU 在 scipy 里没有入口**——这是有意的。要用"不选主元"的分解只能自己写，而那正是出错的地方。

### S2.2 QR 的两种做法：Householder 与 Gram-Schmidt

把 $A$ 正交三角化的思路有两条：

| 做法 | 思想 | 稳定性 |
|------|------|--------|
| **Householder** | 用一系列反射矩阵把 $A$ 逐列"打平" | **后向稳定**（$\lVert Q^{\top}Q - I\rVert \approx \epsilon$，与 $n$ 无关） |
| **Gram-Schmidt（MGS）** | 逐列正交化并不断修正 | 正交性损失随 $\mathrm{cond}(A)$ 增长 |

实测两者的正交性误差（随机 $n \times n$ 矩阵，$\mathrm{cond}$ 约 $O(n)$）：

| $n$ | Householder 的 $\lVert Q^{\top}Q - I \rVert_\infty$ | 改进 Gram-Schmidt | 比值 |
|-----|--------------------------------|------------------|------|
| 10 | 6.66e-16 | 2.08e-15 | 3× |
| 50 | 6.66e-16 | 1.54e-14 | 21× |
| 200 | 1.22e-15 | 2.14e-12 | **2000×** |

**Householder 的正交性误差始终贴在 $\epsilon$（$10^{-15}$）上，不随 $n$ 增长**；而 MGS 按 $n$ 线性恶化：$n = 200$ 时差了 2000 倍。

这正是 `scipy.linalg.qr` 默认用 Householder 的原因（LAPACK 的 `geqrf`）。MGS 只在"逐列到达"的流式场景（在线学习、无法回看全部数据）里才用，此时要靠**再正交化**（算两遍）来补救。

`mode="economic"` 只影响返回形状，不影响算法：$m \times n$（$m > n$）时完整 QR 返回 $m \times m$ 的 $Q$，经济型只返回前 $n$ 列——**省下的是完全没用的正交基**（主章 5.2.4）。

### S2.3 Cholesky 的存在性与代价

**定理**：实对称矩阵 $A$ 存在唯一的、对角元为正的下三角 $L$ 使 $A = LL^{\top}$，当且仅当 $A$ 正定。

这不只是一条判据，也是 Cholesky 比 LU 便宜一半的原因：**对称性让计算量从 $\tfrac{2}{3}n^3$ 降到 $\tfrac{1}{3}n^3$**，而且**不需要选主元**（正定性保证了主元始终为正，不会出现增长因子的问题）。

对 $4\times4$ 的三对角对称正定矩阵，Cholesky 是 $O(n)$ 的；对一般稠密阵是 $O(n^3/3)$。**结构 + 正定性是两个独立的加速来源**，主章 5.2.1 的"结构三问"（对称吗？正定吗？带形吗？）正对应这两条。

`cholesky` 的报错是**有价值的诊断信息**（主章 5.2.4）：

```python
>>> la.cholesky(np.array([[1., 2.], [2., 1.]]))
LinAlgError: Internal potrf return info = [2] for slices [0].
```

`potrf` 是 LAPACK 例程名，`info = [2]` 表示"第 2 个主元非正"。看到这个报错，该检查的是**模型是否满足正定前提**，而不是换求解器。

### S2.4 SVD 与四个基本子空间

SVD 给出 $A = U\Sigma V^{\top}$，其中 $U$（$m\times m$）、$V$（$n\times n$）正交，$\Sigma$ 对角且 $\sigma_1 \ge \cdots \ge 0$。它的威力在于**一次分解就给出四个基本子空间的正交基**：

| 子空间 | 基 | 维数 |
|--------|-----|------|
| 列空间 $\mathrm{range}(A)$ | $U$ 的前 $r$ 列 | $r$ |
| 左零空间 $\mathrm{null}(A^{\top})$ | $U$ 的后 $m - r$ 列 | $m - r$ |
| 行空间 $\mathrm{range}(A^{\top})$ | $V$ 的前 $r$ 列 | $r$ |
| 零空间 $\mathrm{null}(A)$ | $V$ 的后 $n - r$ 列 | $n - r$ |

验证（$6 \times 4$ 随机矩阵，满秩 4）：

```python
>>> U, s, Vt = la.svd(M, full_matrices=True)
>>> U.shape, Vt.shape, s.shape
((6, 6), (4, 4), (4,))
>>> np.abs(U.T @ U - np.eye(6)).max(), np.abs(Vt @ Vt.T - np.eye(4)).max()
(1.33e-15, 7.78e-16)
>>> np.round(np.linalg.norm(M @ Vt.T, axis=0), 6)     # 应等于奇异值
array([4.306373, 3.135627, 2.672244, 0.803314])
>>> np.round(s, 6)
array([4.306373, 3.135627, 2.672244, 0.803314])
```

$\lVert M v_i \rVert = \sigma_i$ 逐位吻合——这就是"奇异值是各方向放大倍数"（`ds-00` 0.2.9）的矩阵证据。

**SVD 的用途都可以从这四个子空间推出来**：最小二乘解 = 把 $b$ 投影到列空间；伪逆 = 在行空间上求逆、在零空间上取零；截断 SVD = 把小的 $\sigma_i$ 对应的子空间丢掉（主章 5.2.4 的"稳健性与拟合能力的交换"）。

### S2.5 秩的数值判定

**秩在浮点里不是良定义的整数**。数学上 $\mathrm{rank}(A)$ 是最大的线性无关列数；数值上"线性相关"是一个关于容差的判断题。LAPACK 与 NumPy 用的默认容差是

$$\tau = \max(m, n)\cdot \epsilon \cdot \sigma_1$$

主章 5.2.4 那个例子里，$\tau = 5.92\times10^{-14}$ 而 $\sigma_{\min} = 7.48\times10^{-14}$——**只差 26%，判定成了掷硬币**。

正确的做法是**显式给容差并说明理由**：$\sigma_i / \sigma_1$ 大于某个业务上可接受的相对精度就保留。这句话把"秩是几"从数学问题变成了建模决策——而这正是它应有的样子。

### S2.6 BLAS/LAPACK 分派

NumPy / SciPy 的线性代数最终都落到 **BLAS**（基础线性代数子程序，负责矩阵乘法之类）与 **LAPACK**（负责分解与求解）上。它们按**数据类型**分派到不同例程：

```python
>>> from scipy.linalg import get_blas_funcs, get_lapack_funcs, find_best_blas_type
>>> find_best_blas_type([np.zeros((3, 3))])[0]                    # float64
'd'
>>> find_best_blas_type([np.zeros((3, 3), dtype=np.float32)])[0]  # float32
's'
>>> find_best_blas_type([np.zeros((3, 3), dtype=complex)])[0]     # complex128
'z'
>>> get_blas_funcs("gemm", [np.zeros((3, 3))]).__name__
'dgemm'
>>> get_lapack_funcs("getrf", [np.zeros((3, 3))]).__name__
'dgetrf'
```

命名规则是 `<精度前缀><例程名>`：`d` = double、`s` = single、`z` = complex double、`c` = complex single。

**三条实用推论**：

1. **数据类型决定了走哪条代码路径**。传入 `float32` 数组会走 `sgemm`（单精度），精度立刻降到 7 位有效数字。这不是"稍微快一点"的优化，而是**换了一个数值问题**。
2. **矩阵乘法的性能取决于 BLAS 实现与硬件**。同一个 `@` 运算在不同机器上能差几倍，所以主章反复强调"计时只保证量级"。
3. **`scipy.linalg` 里没有 `cond`**（主章章首版本注意④）——因为条件数需要 SVD 或特征值，LAPACK 把它们放在不同的例程族里，NumPy 只在 `numpy.linalg.cond` 提供了一个统一封装。

> **实战建议**：需要控制精度时，**显式指定 dtype 并全程保持一致**。混用 `float32` 与 `float64` 会导致隐式提升、额外的内存拷贝，还会让"为什么结果变差了"变得难以追查。

## S3 稀疏与迭代法：填充与 Krylov 子空间

主章 5.3 给了三条实用结论——填充决定成本、`splu` 复用能省 29 倍、CG 在这类问题上比直接法慢几十倍。本节解释这三件事背后的机制。

### S3.1 CSR 的 `indptr` 语义

`csr_array` 用三个数组存一个矩阵，三个都要能读懂：

| 数组 | 长度 | 含义 |
|------|------|------|
| `data` | `nnz` | 按行优先排列的非零**值** |
| `indices` | `nnz` | 每个非零元所在的**列号** |
| `indptr` | $n + 1$ | 第 $i$ 行的非零元在 `data`/`indices` 里的**起止位置** |

```python
>>> from scipy.sparse import csr_array
>>> L = csr_array([[10., 0., 0., 2.],
...                [0., 0., 3., 0.],
...                [0., 1., 0., 0.],
...                [0., 0., 0., 5.]])
>>> L.data, L.indices, L.indptr
(array([10.,  2.,  3.,  1.,  5.]), array([0, 3, 2, 1, 3], dtype=int32), array([0, 2, 3, 4, 5], dtype=int32))
```

第 $i$ 行的非零元在 `indices[indptr[i] : indptr[i+1]]`：

```python
>>> [L.indices[L.indptr[i]:L.indptr[i+1]].tolist() for i in range(4)]
[[0, 3], [2], [1], [3]]
```

完全对上。**这套编码是 `csgraph` 能用稀疏矩阵表示图的原因**：行是起点、`indices` 是终点、`data` 是权。

三条推论：

1. **行访问是 $O(\text{nnz}_i)$，列访问是 $O(\text{nnz})$**——这才是 `csr` 与 `csc` 的分工（主章 5.3.2）。选错格式不会报错，只是慢。
2. **`indptr` 的单调性是许多算法的前提**（二分查找定位行、`csgraph` 的遍历）。所以**不要手工改 `indptr`**，用 `.tocsr()`、`.sum_duplicates()` 这些方法让 scipy 维护一致性。
3. **`nnz` 不包含显式存储的零**。`csr_array` 允许你塞进零值（浪费空间但语义正确），也允许你算出的"零"其实是 $10^{-18}$——这是稀疏矩阵上一类静默错误的来源。

### S3.2 填充是图的消元问题

把 $n \times n$ 的稀疏矩阵看作一张图：非零元 $a_{ij} \ne 0$（$i \ne j$）是一条边。高斯消元消掉第 $k$ 个变量时，**它的所有邻居之间会被连上新边**——这些新边就是填充。

用 $4 \times 4$ 的例子看最清楚。星形图（节点 1 连接 2、3、4）：

$$A = \begin{bmatrix} \times & \times & \times & \times \\ \times & \times & & \\ \times & & \times & \\ \times & & & \times \end{bmatrix}$$

消掉节点 1 时，2、3、4 两两之间要连边——填充从 0 变成 3 条。但如果**先消 2、3、4 再消 1**（重排！），每个叶子节点只连到 1，消掉时不需要连接任何别的节点——**零填充**。

同一个矩阵、同一个数学操作、同一次消元，只因为**顺序**不同，填充就能从 3 变成 0。这就是 `permc_spec` 起作用的地方，也是主章 5.3.3 那张表里"最好与最差差 2.88 倍"的来源。

常用的启发式：

| `permc_spec` | 策略 | 适用 |
|-------------|------|------|
| `NATURAL` | 不重排 | 只用于复现历史结果（几乎总是最差） |
| `MMD_ATA` | 最小度（在 $A^{\top}A$ 的结构上） | 一般 |
| `MMD_AT_PLUS_A` | 最小度（在 $A^{\top}+A$ 的结构上） | 对称结构，**本例最优** |
| `COLAMD` | 近似最小度列排序（**scipy 默认**） | 一般，非对称 |

> **机制洞察**：**填充是图论问题，不是代数问题。** 所以"两个矩阵的 `nnz` 相同，求解耗时可能差几个数量级"（主章 5.3.6 陷阱⑧）——因为决定填充的是**稀疏模式（图的结构）**，而不是非零元的个数。一维链上的消元几乎不产生填充，三维网格上则会产生大量填充，即使两者的 `nnz` 完全一样。

另有一条与教科书不完全一致的实测结论（主章 5.3.3）：**RCM（反向 Cuthill–McKee）重排优化的是带宽，不是填充**。在二维网格上手工套用 RCM 反而让填充比从 9.64 涨到 9.99——因为 `splu` 默认已经用了 COLAMD，而带宽小并不蕴含填充少。

### S3.3 Krylov 子空间：CG 在做什么

迭代法不分解矩阵，而是构造一串**越来越好的近似解**。Krylov 方法的核心思想是：第 $k$ 步的解限制在

$$x_k \in x_0 + \mathcal{K}_k(A, r_0), \qquad \mathcal{K}_k = \mathrm{span}\{r_0,\ Ar_0,\ A^2r_0,\ \dots,\ A^{k-1}r_0\}$$

这个 $k$ 维子空间里，**共轭梯度（CG）** 选的是让误差的 $A$-范数 $\lVert x_k - x \rVert_A = \sqrt{(x_k-x)^{\top}A(x_k-x)}$ 最小的那个 $x_k$。

**等价的"多项式视角"**（这是迭代次数估计的来源）：把残差写成 $r_k = p_k(A)r_0$，其中 $p_k$ 是满足 $p_k(0)=1$ 的 $k$ 次多项式。CG 自动选出使 $\lVert p_k(A)r_0\rVert_A$ 最小的那个多项式。于是收敛速度取决于"用一个 $k$ 次多项式去逼近 0 有多难"，而 $A$ 的特征值分布决定了这件事：

$$\lVert r_k \rVert_A \le 2\left(\frac{\sqrt{\kappa}-1}{\sqrt{\kappa}+1}\right)^k \lVert r_0 \rVert_A, \qquad \kappa = \mathrm{cond}(A)$$

把它解出 $k$，就得到经典的迭代次数估计

$$k \approx \tfrac{1}{2}\sqrt{\kappa}\,\ln\!\left(\frac{2}{\varepsilon}\right)$$

**迭代次数正比于 $\sqrt{\mathrm{cond}}$**——这是 CG 区别于其他迭代法的标志性结论，也是"$\sqrt{\kappa}$ 而不是 $\kappa$"这个说法的来源。

### S3.4 CG 的实测迭代次数

主章 5.3.4 测了一维 Laplacian 上 CG 的迭代次数（250 / 1000 / 4000，随 $N$ 线性增长）。这里补上它与 $\sqrt{\kappa}$ 的定量关系：

| $N$ | $\mathrm{cond} \approx 4N^2/\pi^2$ | $\sqrt{\kappa}$ | 实测迭代次数 | 实测 / $\sqrt{\kappa}$ | 上界 $0.5\sqrt{\kappa}\ln(2/\varepsilon)$ |
|-----|----------------------------------|---------------|------------|---------------------|-----------------------------------|
| 100 | 4.05e+03 | 63.7 | 50 | **0.785** | 755 |
| 400 | 6.49e+04 | 254.6 | 200 | **0.785** | 3020 |
| 1600 | 1.04e+06 | 1018.6 | 800 | **0.785** | 12080 |

两组数字都值得记：

1. **实测迭代次数恰好是 $0.785\sqrt{\kappa} \approx \frac{\pi}{4}\sqrt{\kappa}$**，三档完全一致。这比教科书的上界紧 15 倍——**上界是保守的**（它必须对所有右端项成立，而这里是固定 $b = \mathbf{1}$）。
2. **上界里的 $\ln(2/\varepsilon)$ 被严重高估**：$\varepsilon = 10^{-10}$ 时它是 23.7，而实际只需要 $\pi/4 \approx 0.785$ 倍 $\sqrt{\kappa}$。原因是那个上界对最坏的特征值分布成立，而一维 Laplacian 的特征值是**均匀分布**的——多项式逼近这种分布容易得多。

这一条对实践的意义是：**$\sqrt{\kappa}$ 的标度律可靠，系数不可靠。** 用它做"规模翻 4 倍，迭代次数翻 2 倍"的量级判断是对的；用它预测"需要 3020 次迭代"就错了。

### S3.5 预处理：把 $\kappa$ 压下来

既然迭代次数由 $\sqrt{\kappa}$ 决定，降低条件数就能直接减少迭代。**预处理**就是解等价的方程组

$$M^{-1}Ax = M^{-1}b$$

其中 $M$ 是 $A$ 的一个"容易求逆的近似"。$M^{-1}A$ 的特征值分布比 $A$ 更集中时，迭代次数就下降。

最简单的预处理是**对角（Jacobi）预处理** $M = \mathrm{diag}(A)$。实测（$N = 400$ 的一维 Laplacian，对角线加了一点扰动以体现效果）：

| | 迭代次数 | 条件数 |
|---|---|---|
| 无预处理 | 73 | 93.65 |
| Jacobi 预处理 | 60 | 63.39 |

**1.22 倍**的迭代次数下降，条件数从 93.65 降到 63.39（比值 1.48，开方后 1.22——与 $\sqrt{\kappa}$ 的标度律吻合）。

对于一维 Laplacian 这种本来就很"好"的矩阵，Jacobi 的收益有限。它的威力在**对角元素量级差异巨大**的问题上（不同物理量、不同单位的方程组混在一起）——那时对角缩放能把条件数降几个数量级。

更强的预处理（不完全 LU 分解 `spilu`、代数多重网格）能把 $\kappa$ 压到接近 1，但代价是构造与存储 $M$。**预处理的取舍就是"多花多少构造成本、换多少次迭代"**。

### S3.6 GMRES 与重启

非对称问题不能用 CG（CG 依赖 $A$ 对称正定才能保证递推是短的）。通用的选择是 **GMRES**：它在 $\mathcal{K}_k$ 里选让**残差 2-范数最小**的解，用 **Arnoldi 过程**构造子空间的正交基。

关键参数是 `restart`：

- 不重启的 GMRES 需要存 $k$ 个正交基向量，内存 $O(kn)$，$k$ 大时不可接受；
- `restart=m` 表示每 $m$ 步清空子空间重新开始，内存降到 $O(mn)$，但**收敛速度可能显著下降**（信息被丢掉）。

主章 5.12 的实测里 `restart=50` 在 $N = 500$ 的非对称三对角问题上 `info=0`（收敛），与直接法的解差 $6.4\times10^{-10}$。实践中的调法是：**先取 `restart=50`～`200`，不收敛再加大或改用其他方法（`bicgstab`、`lgmres`）**。

## S4 优化的内核

主章 5.4 给了"方法对照表"与"四道检查"。本节讲求解器**内部在做什么**，以及为什么"成功"这个词在优化里格外不可靠。

### S4.1 KKT 条件与乘子的符号

带不等式约束的问题 $\min f(x)$ s.t. $g(x) \ge 0$，其最优解必须满足 KKT 条件：

$$\nabla f(x^*) = \lambda\,\nabla g(x^*), \qquad \lambda \ge 0, \qquad \lambda\, g(x^*) = 0$$

三个条件的名字分别是**平稳性**、**对偶可行性**、**互补松弛**。用主章 5.4.3 的例子验证（$\min (x_1-2)^2 + (x_2-1)^2$ s.t. $x_1^2 + x_2 \le 1$）：

```python
>>> r = minimize(obj, [0.5, 0.5], jac=obj_g, constraints=cons, method="SLSQP")
>>> lam = float(np.atleast_1d(r.multipliers)[0])
>>> r.x, lam
(array([0.83512254, 0.30257059]), 1.39485868)
>>> obj_g(r.x)                             # ∇f
array([-2.32975492, -1.39485883])
>>> g1_g(r.x)                              # ∇g
array([-1.67024508, -1.        ])
>>> obj_g(r.x) - lam * g1_g(r.x)           # ∇f - λ∇g
array([ 9.35364e-07, -1.43938e-07])        # ≈ 0 ✓
>>> obj_g(r.x) + lam * g1_g(r.x)           # ∇f + λ∇g（常见的错误写法）
array([-4.65951077, -2.78971751])          # ≠ 0 ✗
```

**平稳性用 $\nabla f = \lambda\nabla g$ 验证，用加号会得到完全错误的结论。** 解析上 $\lambda = 2(1 - x_2) = 1.39485883$，与求解器给出的 1.39485868 一致到 7 位。

互补松弛也直接可算：$\lambda \cdot g(x^*) = 1.3949 \times (-2.4\times10^{-7}) \approx -3.4\times10^{-7} \approx 0$（约束在边界上起作用，$g \approx 0$）。**主章 5.4.6 的 `kkt_report` 检查的正是可行性与互补松弛这两件事。**

> **⚠️ 陷阱**：乘子的符号约定在不同实现之间不一致。`scipy.optimize.linprog` 的 `marginals` 官方文档明确说"符号约定与多数非线性求解器相反"（主章 5.5.2）。**验证 KKT 时不要照搬公式，先用一个已知答案的小问题把符号试出来。**

### S4.2 线搜索与信赖域

无约束优化的两类全局策略：

| 策略 | 每一步做什么 | 代表方法 | 特点 |
|------|------------|---------|------|
| **线搜索** | 先定方向 $p_k$，再找步长 $\alpha_k$ 使 $f(x_k + \alpha_k p_k)$ 充分下降 | BFGS、L-BFGS-B、CG、Newton-CG | 每次迭代便宜，可能走得慢 |
| **信赖域** | 在一个半径 $\Delta_k$ 的球内最小化二阶模型，再根据实际下降调整 $\Delta_k$ | dogleg、trust-ncg、trust-krylov、trust-constr | 每次迭代贵，但更稳健 |

Rosenbrock 上的实测（都有解析梯度，信赖域方法还给解析 Hessian）：

| 方法 | `nit` | `nfev` | `njev` | $f(x)$ |
|------|-------|--------|--------|--------|
| BFGS（线搜索） | 32 | **39** | 39 | 2.54e-15 |
| trust-ncg | 29 | **30** | 27 | 9.27e-14 |
| dogleg | **23** | **24** | 21 | 2.90e-12 |
| trust-constr | 44 | 44 | 30 | **1.50e-26** |

**信赖域方法用更少的函数调用达到更高精度**（dogleg 只要 24 次 vs BFGS 的 39 次），代价是要给 Hessian。当 Hessian 昂贵或不可得时，线搜索方法（BFGS 用割线方程近似 Hessian）更现实。

**注**：`trust-constr` 在主章 5.4.2 的实测里是最慢的（52 ms），这里却是最准的（1.5e-26）。两者不矛盾——它每次迭代做的线性代数最多。**"贵"和"准"在优化里往往是同一件事的两面。**

### S4.3 BFGS 的逆 Hessian 更新

BFGS 不计算 Hessian，而是**用梯度的变化量逐步修正一个 Hessian 的近似**。它的更新公式（对逆矩阵 $H_k \approx (\nabla^2 f)^{-1}$）：

$$H_{k+1} = \left(I - \rho_k s_k y_k^{\top}\right)H_k\left(I - \rho_k y_k s_k^{\top}\right) + \rho_k s_k s_k^{\top}$$

其中 $s_k = x_{k+1} - x_k$、$y_k = \nabla f_{k+1} - \nabla f_k$、$\rho_k = 1/(y_k^{\top}s_k)$。这个公式满足**割线方程** $H_{k+1}y_k = s_k$，并且保持对称与正定（只要 $y_k^{\top}s_k > 0$）。

它的近似质量可以实测。BFGS 收敛到 Rosenbrock 最优解后，返回的 `hess_inv` 与真 Hessian 的逆：

```python
>>> np.round(r.hess_inv, 6)
array([[0.50186 , 1.003153],
       [1.003153, 2.010275]])
>>> np.round(np.linalg.inv(rosen_hess(r.x)), 6)
array([[0.5     , 1.000001],
       [1.000001, 2.005002]])
```

最大相对误差 **0.003**——用 39 次函数求值（其中 39 次梯度）就得到一个误差 0.3% 的二阶信息近似。这就是拟牛顿法的价值：**不用算 Hessian，也能拿到接近二阶方法的收敛速度。**

`hess_inv` 不只是副产物，它还能直接用来估参数的协方差（主章 5.6.3 在非线性最小二乘里做过类似的事）。

### S4.4 单纯形、内点与 HiGHS

线性规划的两大算法族：

| 算法 | 思想 | 特点 |
|------|------|------|
| **单纯形法** | 沿可行域的顶点走，每次换一个基 | 实践中极快，但最坏情况是指数时间 |
| **内点法** | 从内部沿"中心路径"逼近最优面 | 多项式时间，大问题更稳，需要 crossover 才得到顶点解 |

`scipy.optimize.linprog` 在 1.18 里只剩 **HiGHS** 后端（主章章首版本注意⑥）：

| `method=` | 含义 |
|-----------|------|
| `"highs"` | 自动在对偶单纯形（`highs-ds`）与内点（`highs-ipm`）之间选 |
| `"highs-ds"` | 只用对偶修正单纯形 |
| `"highs-ipm"` | 只用内点法（带 crossover 保证顶点精度） |
| `"simplex"` / `"interior-point"` / `"revised simplex"` | **已弃用**，仍可调用但发 `DeprecationWarning` |

HiGHS 的两种方法有明确分工：**对偶单纯形在"热启动"（已有近似最优基）与重解问题上快；内点法在超大稀疏问题上稳**。`"highs"` 自动选择，多数情况下够用；要在报告里说清楚用了哪个算法时，就显式指定。

整数规划（`milp`）在 HiGHS 里走的是**分支定界 + 割平面**，`mip_gap` 就是"当前最好整数解与 LP 松弛下界之间的相对间隙"。主章 5.5.3 要求报告 `mip_gap`，原因是：**整数规划通常无法证明最优，求解器返回的往往是"可行解 + 一个保证"。**

### S4.5 收敛判据与"成功"的语义

优化器的终止条件有三类，缩写容易混：

| 判据 | 含义 | 什么时候是"假成功" |
|------|------|------------------|
| `gtol` | 梯度范数足够小 | 目标函数有平坦区域（尺度差、目标写错） |
| `ftol` | 函数值的相对变化足够小 | 步长太小但还没到驻点（病态、约束边界） |
| `xtol` | 参数的变化足够小 | 参数尺度差异大（未归一化） |

**三者任意一个满足就会停。**`success=True` 的含义是"某个判据满足了"，不是"找到了最优解"。主章 5.4.2 的实测里，默认 `tol` 下 BFGS 停在 $x = [0.99999997, 0.99999995]$（误差 $5\times10^{-8}$）——按 `gtol` 或 `ftol` 都算收敛，但如果你要的是参数值，这个精度可能不够（加 `tol=1e-12` 后 $x$ 精确到机器精度）。

**尺度问题是最常见的假成功来源**：如果一个参数的合理范围是 $10^{6}$、另一个是 $10^{-3}$，那么 `xtol` 对后者是"已经极准"、对前者是"完全没动"。修法是**先把变量归一化到同量级**（主章 5.1.5 第三条纪律）。

### S4.6 差分导数的 U 形误差

自适应差分（中心差分）的误差由两部分组成：

$$\text{截断误差} \approx \frac{h^2}{6}\lvert f'''\rvert, \qquad \text{舍入误差} \approx \frac{\epsilon \lvert f \rvert}{h}$$

前者随 $h$ 减小而下降（$\propto h^2$），后者随 $h$ 减小而**上升**（$\propto 1/h$）。最优的 $h$ 在两者相等处：

$$h^* \approx \left(\frac{3\epsilon\lvert f\rvert}{\lvert f'''\rvert}\right)^{1/3} \approx \epsilon^{1/3} \approx 6\times10^{-6}$$

实测 $f(x) = e^x\sin x$ 在 $x = 1$ 处的导数（真值 3.756049227095）：

| $h$ | 实测误差 | 理论截断项 $\frac{h^2}{6}\lvert f'''\rvert$ |
|-----|---------|--------------------------------|
| $10^{-2}$ | 2.73e-05 | 1.36e-05 |
| $10^{-4}$ | 2.73e-09 | 1.36e-09 |
| $10^{-6}$ | **1.05e-10** | 1.36e-13 |
| $10^{-8}$ | **1.05e-10** | 1.36e-17 |
| $10^{-10}$ | 4.22e-07 | 1.36e-21 |
| $10^{-12}$ | 5.73e-05 | 1.36e-25 |
| $10^{-14}$ | 1.87e-02 | 1.36e-29 |

**清晰的 U 形**：$h$ 从 $10^{-2}$ 缩到 $10^{-6}$ 时误差按 $h^2$ 下降（每缩 100 倍误差降 $10^4$ 倍），$h < 10^{-8}$ 后舍入误差接管、误差一路上升，$h = 10^{-14}$ 时已经错到 $10^{-2}$。

第三条列还暴露出一个细节：**$h \ge 10^{-4}$ 时实测误差比理论截断项大 2 倍**（2.73e-05 vs 1.36e-05），说明高阶项在起作用；$h \le 10^{-6}$ 后舍入误差已经超过截断误差，所以实测误差停在 $10^{-10}$ 不再下降。

**最优 $h \approx 10^{-6}$，正好是 $\epsilon^{1/3}$**（$2.22\times10^{-16}$ 的立方根是 $6.06\times10^{-6}$）。这条经验对**单侧差分也成立但常数不同**（$h^* \approx \epsilon^{1/2}$，因为单侧差分的截断误差是 $O(h)$ 而不是 $O(h^2)$，所以中心差分不仅更准，最优步长也更大）。

**这解释了主章 5.4.2 的实测**：给解析梯度让 `nfev` 从 117 降到 39，而精度从 $2.0\times10^{-11}$ 提到 $2.5\times10^{-15}$——**差分的精度天花板就在 $10^{-10}$ 量级**，想再往下只能解析求导。

`scipy.optimize.approx_fprime` 就是中心/单侧差分的封装，实测与解析梯度一致到 6 位小数：

```python
>>> approx_fprime([-1.2, 1.0], rosen)
array([-215.59999,  -87.999999])
>>> rosen_der([-1.2, 1.0])
array([-215.6, -88. ])
```

## S5 微分方程的稳定域

主章 5.9.2 测出"RK45 比 Radau 多 26 倍函数调用"，5.9.4 说"显式方法的步长被稳定性而非精度压死"。本节给出这两句话的定量来源。

### S5.1 显式方法的稳定域

把方法作用在标量测试方程 $y' = \lambda y$（$\mathrm{Re}\,\lambda < 0$）上，一步可以写成

$$y_{n+1} = R(z)\,y_n, \qquad z = h\lambda$$

$R(z)$ 是方法的**稳定性函数**。为了保证误差不被放大，必须有 $|R(z)| \le 1$——满足这个条件的 $z$ 的集合就是**绝对稳定域**。

几个常用方法在**负实轴**上的稳定区间 $z \in [-\beta, 0]$：

| 方法 | $R(z)$ | $\beta$（负实轴边界） |
|------|--------|-------------------|
| 显式 Euler | $1 + z$ | 2 |
| 二阶 RK | $1 + z + z^2/2$ | 2 |
| 经典 RK4 | $1 + z + z^2/2 + z^3/6 + z^4/24$ | **2.785** |
| 隐式 Euler | $1/(1-z)$ | $\infty$（A-稳定） |
| Radau IIA(3) | 有理函数 | $\infty$ |

**关键事实：显式方法的 $\beta$ 是有限的，隐式方法可以是无穷。** 这就是全部差别的来源。

### S5.2 步长被稳定性压死：一次逐位吻合的验证

用主章 5.9.2 的刚性方程 $y' = -1000(y - \cos t) - \sin t$（雅可比 $\lambda \approx -1000$），让 RK45 在 $t \in [0,1]$ 上以 `rtol=1e-6` 求解，观察它**实际走的步长**：

```python
>>> s = solve_ivp(stiff, [0, 1], [1.0], method="RK45", rtol=1e-6, atol=1e-9)
>>> dt = np.diff(s.t)
>>> len(s.t), np.median(dt), dt.min(), dt.max()
(360, 0.002802, 0.0001, 0.002917)
```

**步长中位数是 $2.802\times10^{-3}$，而经典 RK4 的稳定边界给出 $2.785/\lvert\lambda\rvert = 2.785\times10^{-3}$。** 两者差 0.6%——RK45 的每一步几乎都顶在稳定性边界上。

对照"精度允许的步长"：解是 $\cos t$，在一个振荡周期 $2\pi$ 内，要达到 $10^{-6}$ 的相对精度，用四阶方法只需要 $h \approx 10^{-1.5} \approx 0.03$——**比实际步长大 10 倍**。也就是说：

> **机制洞察**：显式方法在刚性问题上，**步长完全由稳定性决定，与精度无关**。系统越刚（$|\lambda|$ 越大），允许的步长就越小；而解本身的变化可能很慢，所以"算了一堆完全不必要的小步"。这就是主章 5.9.2 里 RK45 用 360 步、Radau 只用 11 步的原因。

四个方法的实际步长对照：

| 方法 | 步数 | 步长中位数 | 最大步长 |
|------|------|-----------|---------|
| `RK45` | 360 | 2.80e-03 | 2.92e-03 |
| `LSODA` | 59 | 1.15e-02 | 6.39e-02 |
| `Radau` | 11 | 2.60e-02 | **4.34e-01** |
| `BDF` | 25 | 3.21e-02 | 1.16e-01 |

`Radau` 的最大步长 0.434 已经接近整个求解区间的 43%——它**几乎没有被稳定性约束**。

### S5.3 刚性比：怎么判断"刚"

工程上最常用的定义是雅可比矩阵特征值的量级跨度：

$$\text{刚性比} = \frac{\max_i \lvert \mathrm{Re}\,\lambda_i \rvert}{\min_i \lvert \mathrm{Re}\,\lambda_i \rvert}$$

| $\max\lvert\lambda\rvert$ | $\min\lvert\lambda\rvert$ | 刚性比 | 显式方法的成本 |
|---|---|---|---|
| $10^{3}$ | 1.0 | $10^{3}$ | 步长被压到 $2.8\times10^{-3}$ |
| $10^{3}$ | $2\pi$ | $1.6\times10^{2}$ | 步长被压到 $2.8\times10^{-3}$（仍由 $\max$ 决定） |
| $10^{6}$ | 1.0 | $10^{6}$ | 步长被压到 $2.8\times10^{-6}$ |

两个要点容易搞错：

1. **决定显式方法成本的是 $\max|\lambda|$（绝对值），不是比值。** 刚性比用来说明"系统里同时存在快慢两种尺度"，而实际的步长限制只来自最快的那一个。
2. **刚性比大于 $10^{3}$ 就该上隐式方法**（主章 5.9.2 的经验规则）。这不是硬阈值——判断的真正依据是"显式方法的步长限制是否已经比精度要求严格得多"。

### S5.4 A-稳定不等于准确

隐式方法的稳定域覆盖整个左半平面（**A-稳定**），意味着**无论 $h$ 多大都不会发散**。但这不等于"结果准确"——用一个极快的衰减 $y' = -1000y$、$y(0) = 1$ 实测（真值 $y(0.1) = e^{-100} \approx 3.72\times10^{-44}$）：

| `max_step` | `RK45` 结果 | `Radau` 结果 |
|-----------|-----------|-------------|
| 0.001 | 4.13e-44 ✓ | 3.76e-44 ✓ |
| 0.010 | **1.93e-10** ✗ | 6.02e-22 ✗ |
| 0.100 | **1.93e-10** ✗ | **3.80e-15** ✗ |

（真值 $3.72\times10^{-44}$）

- 步长足够小（0.001）时两者都对。
- 步长放大 10 倍后，`RK45` 错到 $1.9\times10^{-10}$（**差了 33 个数量级**），`Radau` 错到 $6.0\times10^{-22}$（差 22 个数量级）。
- 步长再放大到 0.1，`Radau` 是 $3.8\times10^{-15}$——依然错得离谱。

**A-稳定保证的是"不发散"，不是"跟得上初始瞬态"。** 快速衰减的初始层必须被步长分辨出来，否则隐式方法给的是"稳定但错误"的答案。这解释了为什么 `solve_ivp` 在开始积分的几个步长里总是自动走得很小——**误差控制器在分辨初始层**。

> **实战建议**：刚性问题的正确用法是——① 用隐式方法（`Radau`/`BDF`/`LSODA`）保证稳定；② **不要手工设一个大的初始步长**（`first_step`）；③ 如果解在起点附近有快速变化而结果明显不对，先检查是不是瞬态没被分辨（把 `atol` 调小、用 `t_eval` 在起点附近加密）。

### S5.5 误差控制与自适应步长

自适应步长的机制是**局部误差估计 + 步长调整**：

1. 用一对嵌套的方法算两个解（如 RK45 用 5 阶与 4 阶），差值作为局部误差估计 $\mathrm{err}$；
2. 与容差比较：要求 $\mathrm{err} \le \mathrm{atol} + \mathrm{rtol}\cdot|y|$；
3. 按 $\mathrm{err}$ 的幂次调整下一步的步长：$h_{\text{new}} = h \cdot \min(\text{max\_factor}, \max(\text{min\_factor}, \text{safety}\cdot\mathrm{err}^{-1/(p+1)}))$。

`rtol` 与 `atol` 的分工是这里最容易被误用的一点：

$$\text{允许误差} = \texttt{atol} + \texttt{rtol}\cdot \lvert y \rvert$$

**`rtol` 是相对的、`atol` 是绝对的，取两者之和意味着"哪个更宽松就用哪个"。**当 $|y|$ 接近 0 时（振荡解过零、衰减到极小值），$\texttt{rtol}\cdot|y|$ 也接近 0，此时**误差完全由 `atol` 控制**。默认 `atol=1e-6` 对量级 $10^{-3}$ 以下的物理量会失效——这是主章 5.9.5 那条陷阱的机制。

### S5.6 事件检测：在连续解上求根

事件的实现分三步：

1. 每个成功的积分步之后，检查事件函数 $g(t, y(t))$ 的符号是否改变；
2. 变号时，在该步区间内**用求根算法**（Brent）定位 $g = 0$ 的精确时刻；
3. `terminal=True` 则终止积分，`direction` 用来过滤穿越方向。

这解释了主章 5.9.3 的一个实测现象：**单次穿越的事件时刻精度能到机器精度（抛体落地 4.4e-16），而多次穿越时误差随 `rtol` 变化（$10^{-3}$ 时 $4.0\times10^{-3}$、$10^{-8}$ 时 $2.8\times10^{-9}$）。**

原因是：求根本身是精确的，但**求根用的插值多项式来自积分器**。抛体问题是二次的，RK45 的稠密输出能精确表示它，所以求根拿到的是真根；振荡问题的轨迹是超越函数，稠密输出的多项式逼近误差就是事件时刻的误差——而那个误差由 `rtol` 决定。

## S6 插值与逼近的病态

主章 5.7.1 用实测展示了龙格现象（21 个等距点误差 59.8）。本节给出它的定量机制。

### S6.1 Vandermonde 矩阵的条件数

用单项式基 $1, x, x^2, \ldots$ 做插值，等价于解 Vandermonde 方程组 $Vc = y$。这个矩阵的条件数随阶数快速恶化（等距结点）：

| 结点数 $n$ | $\mathrm{cond}(V)$ |
|-----------|-------------------|
| 6 | 6.38e+01 |
| 10 | 4.63e+03 |
| 14 | 3.64e+05 |
| 18 | 2.98e+07 |

每加 4 个点条件数涨约 100 倍。$n = 18$ 时 $\mathrm{cond} = 3\times10^{7}$——按主章 5.2.3 的读法，**解只剩 8 位有效数字**。这就是"高次多项式插值不能碰"的第一个理由：**问题本身就是病态的**。

### S6.2 Lebesgue 常数：等距按 $2^n$ 增长

第二个理由更本质。插值误差可以写成

$$\lvert f(x) - p_n(x) \rvert \le \bigl(1 + \Lambda_n\bigr) \cdot \min_{q \in \mathcal{P}_n}\lvert f(x) - q(x) \rvert$$

右边第二项是**最佳逼近误差**（只取决于 $f$ 的光滑度，随 $n$ 下降），第一项里的 $\Lambda_n$ 是 **Lebesgue 常数**，只取决于**结点的选择**：

$$\Lambda_n = \max_{x \in [-1,1]} \sum_{i=0}^{n}\Bigl\lvert \prod_{j \ne i}\frac{x - x_j}{x_i - x_j}\Bigr\rvert$$

**当 $\Lambda_n$ 增长得比最佳逼近误差下降得快时，加密结点反而让误差变大。** 等距结点正是这种情况：

| $n$ | 等距结点的 $\Lambda_n$ | Chebyshev 结点的 $\Lambda_n$ | 比值 |
|-----|---------------------|--------------------------|------|
| 8 | 6.93 | 2.20 | 3.1× |
| 12 | 51.2 | 2.49 | 20.6× |
| 16 | 512.4 | 2.69 | 190.7× |
| 20 | **5890** | 2.84 | **2076×** |

两条曲线的性态完全不同：

- **等距**：**指数增长**。实测每加 4 个结点涨 7.4× / 10.0× / 11.5× / 12.4×（$n = 8 \to 24$），速率接近 $2^n$；$n = 20$ 时 $\Lambda_{20} \approx 5890$，意味着即使 $f$ 的最佳逼近误差是 0，插值误差也可能被放大近 6000 倍。
- **Chebyshev**：$\Lambda_n = \dfrac{2}{\pi}\ln n + O(1)$——**对数增长**。$n$ 从 8 涨到 20，$\Lambda_n$ 只从 2.20 涨到 2.84。

**这就是"换结点"的全部理由。** Chebyshev 结点 $x_k = \cos(k\pi/n)$ 在两端的密度是中间的 $\sqrt{n}$ 倍——正好抵消了多项式在端点附近摆动最剧烈的倾向。

> **机制洞察**：龙格现象**不是高次多项式的错，是等距结点的错**。同一个 $f$、同一个多项式的次数，只换结点，误差就从"随 $n$ 爆炸"变成"随 $n$ 收敛"。主章 5.7.1 的三次样条之所以没有龙格现象，是因为它把次数固定在 3（$\Lambda$ 有界）、用分段换取了结点密度的局部自适应——这是第三条出路。

### S6.3 样条：$C^2$ 与保形的取舍

主章 5.7.2 说 `CubicSpline` 会过冲而 `PchipInterpolator` 不会。差别在**连续性的阶**：

| 方法 | 连续性 | 结点处的约束 |
|------|--------|------------|
| `CubicSpline` | $C^2$ | 函数值、一阶导、**二阶导**都连续 |
| `PchipInterpolator` | $C^1$ | 函数值、一阶导连续，二阶导**跳变** |

用主章的阶梯数据直接测结点处的二阶导跳跃：

```python
>>> # 在 xd = [0,1,2,3,4,5]、yd = [0,1,1,1,0,0] 上的内部结点处测左右二阶导之差
>>> # CubicSpline : 最大跳跃 0.0007      （C² 成立）
>>> # PCHIP       : 最大跳跃 5.9999      （二阶导不连续）
```

`CubicSpline` 的跳跃 0.0007 来自差分近似误差，实际是 0；`PCHIP` 的跳跃 6.0 是真实的。

**为什么 $C^2$ 会导致过冲？** 因为"二阶导连续"是一条**全局**约束：把 6 个点连成一条 $C^2$ 曲线时，每个结点的二阶导都受所有其他结点影响（解一个三对角方程组）。在"平台—陡降"的转折处，为了让二阶导平滑过渡，曲线必须先在平台上方拱起、再在下降段冲到 0 以下——这就是过冲的来源。

`PCHIP` 逐个区间独立地选导数（用加权调和平均），并**主动限制导数使区间内单调**，代价是牺牲了 $C^2$。**这是一次典型的"局部保形 vs 全局光滑"取舍**：想知道数据会不会越界，用 PCHIP；只想让曲线好看，用 CubicSpline。

### S6.4 外推的代价

主章 5.7.4 说"插值器只在数据范围内有效"。把它量化（15 个点上拟合 $f(x) = \sin 3x$，区间 $[0,1]$）：

| 外推距离 | CubicSpline 误差 | PCHIP 误差 |
|---------|----------------|-----------|
| 区间内最大误差 | **2.11e-05** | — |
| +0.05 | 3.0e-04 | 4.8e-03 |
| +0.10 | 1.0e-03 | 1.7e-02 |
| +0.20 | 5.2e-03 | 7.2e-02 |
| +0.50 | **2.47e-02** | **6.54e-01** |

往外推 0.05（区间长度的 5%），`CubicSpline` 的误差就比区间内**大 14 倍**；推 0.5（区间长度的一半）时**大 1170 倍**。

这个增长不是线性的——它是多项式在区间外的自然发散行为。**没有"小心外推"这回事**：外推距离一旦超过数据间距的几倍，结果就不可用。

**正确的做法是把"没有数据"这件事做进接口**：让 `RegularGridInterpolator` 的 `bounds_error=True` 报错（主章 5.7.4），或者用 `fill_value=np.nan` 显式标记。**外推最危险的形式是 `fill_value=None`——它给出一个看起来合理的数字。**

## S7 积分与 FFT 的算法

### S7.1 Gauss–Kronrod 自适应

`quad` 用的 QUADPACK 的核心是 **Gauss–Kronrod 对**：同时用 $n$ 点 Gauss 求积与 $2n+1$ 点 Kronrod 求积，两者的差作为误差估计。常用的 $n = 7$（Gauss）与 15（Kronrod）组合：

- 若误差估计满足 `epsabs`/`epsrel`，接受这一段的积分值；
- 否则把区间二分，递归处理。

**收益是巨大的**：同一道 $\int_0^3 e^{-x^2}dx$（真值 0.886207348259521），自适应方法与固定阶 Gauss–Legendre 的对照：

| 方法 | 结果 | 实际误差 |
|------|------|---------|
| `quad`（自适应 7–15 点） | 0.886207348259521 | 0（与真值逐位相同） |
| `fixed_quad` n = 5 | 0.886529173751462 | 3.22e-04 |
| `fixed_quad` n = 7 | 0.886208222740351 | 8.74e-07 |
| `fixed_quad` n = 10 | 0.886207348745566 | 4.86e-10 |
| `fixed_quad` n = 15 | 0.886207348259521 | 2.22e-16 |
| `fixed_quad` n = 30 | 0.886207348259524 | 2.55e-15 |

自适应方法**用比 15 点更少的有效求值达到了 15 点的精度**（它在函数平坦的地方少放点、陡峭的地方多放点）。注意 $n \ge 15$ 后误差不再下降（停在 $10^{-15}$ 量级）——那是浮点的舍入下限（S1.1）。

### S7.2 奇点变换：为什么 `quad` 不怕 $x^{-1/2}$

$\int_0^1 x^{-1/2}dx = 2$，被积函数在左端点发散。QUADPACK 用**变量替换**处理：把 $x = u^2$ 之类把奇点"拉平"的变换与求积规则结合，使得变换后的被积函数光滑。

实测差距极大：

| 方法 | 结果 | 误差 |
|------|------|------|
| `quad` | 1.999999999999998 | 1.55e-15 |
| `fixed_quad` n = 10 | 1.917064 | 8.29e-02 |
| `fixed_quad` n = 50 | 1.982758 | 1.72e-02 |
| `fixed_quad` n = 200 | 1.995657 | **4.34e-03** |

固定阶 Gauss 求积对**端点奇点收敛极慢**——$n$ 从 10 加到 200（20 倍），误差只从 $8\times10^{-2}$ 降到 $4\times10^{-3}$（20 倍）。这个收敛率远低于光滑函数的谱收敛（$n = 15$ 就到机器精度）。

> **实战建议**：被积函数有奇点或无穷区间时，**不要试图用加密采样点解决**——应当换变量替换或换方法。`quad` 已经内置了这些变换，这也是"为什么不要手写辛普森"（主章 5.8.1）的真正理由：**手写的方法在光滑函数上尚可，遇到奇点会彻底失效而你不知道。**

### S7.3 Cooley–Tukey 与 $O(n\log n)$

朴素 DFT 计算 $n$ 个输出、每个需要 $n$ 次复数乘法——$O(n^2)$。**FFT**（Cooley–Tukey）利用 $W_n = e^{-2\pi i/n}$ 的周期性与对称性，把 $n$ 点变换拆成两个 $n/2$ 点变换：

$$X_k = E_k + W_n^k O_k, \qquad X_{k+n/2} = E_k - W_n^k O_k$$

递归下去得到 $O(n\log n)$。实测（与朴素 DFT 直接对照）：

| $n$ | FFT 耗时 | 朴素 DFT 耗时 | 加速比 |
|-----|---------|-------------|--------|
| $2^{10}$ | 1.84 ms | 17.6 ms | 10× |
| $2^{14}$ | 0.31 ms | 3839.0 ms | **12302×** |

$n$ 从 $2^{10}$ 涨到 $2^{14}$（16 倍），朴素 DFT 慢 218 倍（$16^2$，符合 $O(n^2)$），FFT 只花 0.31 ms——**加速比按 $n/\log n$ 增长**。

用 $t/(n\log_2 n)$ 检验 $O(n\log n)$：

| $n$ | $t/n$（ns） | $t/(n\log_2 n)$ |
|-----|------------|----------------|
| $2^{12}$ | 3.21 | 267.6 |
| $2^{14}$ | 3.04 | 217.1 |
| $2^{16}$ | 4.46 | 278.6 |
| $2^{18}$ | 4.96 | 275.7 |

**$t/(n\log_2 n)$ 基本恒定（$2^{14}$ 之后在 220–280 之间）**，这正是 $O(n\log n)$ 的标志。（$2^{10}$ 那一行的 501 是固定开销占比过大造成的。）

### S7.4 实序列的 `rfft` 优化

实数序列的 DFT 满足共轭对称 $X_{n-k} = \overline{X_k}$，所以**一半的输出是冗余的**。`rfft` 利用这一点，只算 $n/2 + 1$ 个点：

| $n$ | `fft` 耗时 | `rfft` 耗时 | 加速 | 输出长度 |
|-----|-----------|------------|------|---------|
| $2^{16}$ | 0.281 ms | 0.266 ms | 1.06× | 65536 vs 32769 |
| $2^{20}$ | 11.310 ms | 7.458 ms | **1.52×** | 1048576 vs 524289 |

**加速比随 $n$ 增大**（1.06× → 1.52×），因为 $n$ 小时固定开销占比大。理论上的上限是 2 倍（计算量减半），实测到 1.5 倍已经接近。

配套的 `rfftfreq(n, d)` 给出对应的频率轴（长度 $n/2+1$），**不要用 `fftfreq`** ——它的长度是 $n$ 且含负频率（主章 5.12.3）。

### S7.5 `next_fast_len` 与素数长度

FFT 的 $O(n\log n)$ 只在 $n$ 是**高度合数**时成立。$n$ 含大素因子时，Cooley–Tukey 的递归拆不开，退化成 $O(n^2)$ 或混合算法的慢路径。

实测一个素数长度：

```python
>>> n = 999983                       # 素数
>>> nf = fft.next_fast_len(n)        # 1000000
```

| 做法 | 耗时 |
|------|------|
| 直接对 $n = 999983$ 做 FFT | **123.062 ms** |
| 补零到 $n = 1000000$ 再做 FFT | **8.346 ms** |

**14.74 倍**的差距，而补零只多了 17 个点。作为对照，$n = 1000000$（本身是快长度）直接做是 7.473 ms，补零版本 6.765 ms——**没有差别**（补零无益也无害）。

> **实战建议**：做大批量或重复的 FFT 时，**先用 `next_fast_len` 把长度补齐**。补零会引入"频谱插值"效应（频率分辨率按补零后的长度算），但如果你本来就要零填充（例如做线性卷积），这个副作用不存在。判断规则很简单：**长度是我能选的吗？** 能选就用 `next_fast_len`；不能选（信号长度固定）且只做一次，直接算就行；要重复很多次（如 STFT 的每一帧），补齐的收益会累积。

## S8 低差异序列的构造

主章 5.10.1 展示了 Sobol 比朴素 MC 精确 396 倍。本节讲这些序列**怎么造出来**。

### S8.1 van der Corput：把数字反序

一维低差异序列的祖先是 **van der Corput 序列**：把 $n$ 写成 $b$ 进制，**把数字反序放到小数点后**：

$$\phi_b(n) = \sum_{k \ge 1} d_k\, b^{-k}, \qquad n = \sum_{k\ge 1} d_k\, b^{k-1}$$

代码只有五行：

```python
def vdc(n, base=2):
    """van der Corput：n 在 base 进制下的数字反序。"""
    out, denom = 0.0, 1.0
    while n > 0:
        n, rem = divmod(n, base)
        denom *= base
        out += rem / denom
    return out
```

```python
>>> [round(vdc(i), 4) for i in range(8)]
[0.0, 0.5, 0.25, 0.75, 0.125, 0.625, 0.375, 0.875]
```

读这个序列：先放 $1/2$，然后在两个半区间的**中点**放 $1/4$ 与 $3/4$，再在四个四分区间中点放 $1/8, 5/8, 3/8, 7/8$……**每一步都把"最空的区间"一分为二**。所以前 $2^k$ 个点恰好每个长度为 $2^{-k}$ 的子区间各有一个——这就是"低差异"的精确含义。

二进制下这个序列有一个漂亮的表达式：$\phi_2(n)$ 就是 $n$ 的二进制位反序后的小数值。

### S8.2 Halton：多个基

多维要每个维度各有一个低差异序列，而且**维度之间不能相关**。**Halton 序列**的做法是第 $j$ 维用第 $j$ 个素数作基：

$$\text{Halton}(n) = \bigl(\phi_2(n), \phi_3(n), \phi_5(n), \phi_7(n), \ldots\bigr)$$

```python
>>> [[round(vdc(i, b), 6) for b in (2, 3, 5)] for i in range(1, 6)]
[[0.5,     0.333333, 0.2   ],
 [0.25,    0.666667, 0.4   ],
 [0.75,    0.111111, 0.6   ],
 [0.125,   0.444444, 0.8   ],
 [0.625,   0.777778, 0.04  ]]
```

与 scipy 的 `qmc.Halton(3, scramble=False).random(5)` **逐位相同**（scipy 只是把 $n = 0$ 的点 $(0,0,0)$ 放在最前面）：

```
[[0.       0.       0.      ]
 [0.5      0.333333 0.2     ]
 [0.25     0.666667 0.4     ]
 ...
```

**用一个素数基就够了吗？** 不够。如果所有维度都用基 2，点会全部落在对角线上（因为每一维的序列完全一样）。**用不同的素数保证各维不相关**——但这个保证随维数衰减：高维时 Halton 会出现相关性（大素数基在小 $n$ 时几乎不"动"），所以 Halton 在维数 $> 10$ 时通常不如 Sobol。

### S8.3 Sobol：$\mathbb{F}_2$ 上的方向数

Sobol 序列不用数字反序，而是在**二元域 $\mathbb{F}_2$** 上用一组"方向数" $v_1, v_2, \ldots$（每个是 32 位的二进制小数）做异或：

$$x_n = d_1 v_1 \oplus d_2 v_2 \oplus \cdots, \qquad n = \sum_k d_k 2^{k-1}$$

方向数由本原多项式生成（Joe–Kuo 方向数表是标准来源）。它的性质：

- **每一维的 $2^k$ 个点都恰好落在一个 $(2^k)$-网格的一格中**——与 van der Corput 的"每次二分最空区间"是同一个性质的多维版本；
- **维数之间由不同的本原多项式保证不相关**，扩展性好于 Halton；
- **前 $2^k$ 个点的平衡性是内建的**，所以主章 5.10.1 强调"点数取 2 的幂"——不是 2 的幂时，最后一块不完整，平衡性被破坏。

不随机化的 Sobol 前 5 个点（$d = 3$）：

```
[[0.    0.    0.   ]
 [0.5   0.5   0.5  ]
 [0.75  0.25  0.25 ]
 [0.25  0.75  0.75 ]
 [0.375 0.375 0.625]]
```

看得出"分层"的痕迹：$n = 2$ 时每个维度的两个点恰好是 0 与 0.5；$n = 4$ 时四个点恰好覆盖 $\{0.25, 0.75\} \times \{0.25, 0.75\} \times \{0.25, 0.75\}$。

### S8.4 星差异与 Koksma–Hlawka

低差异的定量度量是**星差异**：

$$D^*_N(P) = \sup_{B \in \mathcal{B}} \left\lvert \frac{\#\{p_i \in B\}}{N} - \mathrm{vol}(B) \right\rvert$$

上确界取遍所有以原点为角的矩形 $B$。它衡量的是"点集与均匀分布的最大偏差"。

它与积分误差的关系是 **Koksma–Hlawka 不等式**：

$$\left\lvert \frac{1}{N}\sum_i f(p_i) - \int_{[0,1]^d} f \right\rvert \le V_{\mathrm{HK}}(f) \cdot D^*_N(P)$$

其中 $V_{\mathrm{HK}}$ 是 $f$ 的 Hardy–Krause 变差（一种多维的有界变差）。

**这条不等式的意义**：积分误差被分解成"函数有多难"（$V$）与"点集有多好"（$D^*$）两个因子。对低差异序列，$D^*_N \sim (\log N)^d / N$；对随机点，$D^*_N \sim \sqrt{\log\log N / N}$（LIL）。**前者比后者几乎快一个 $\sqrt{N}$ 的因子**——这就是 QMC 的优势来源，也解释了它为什么在 $d$ 大时优势消失：$(\log N)^d$ 里的指数 $d$。

实测的星差异下降（scipy 的 `qmc.discrepancy`）：

| $N$ | 朴素 MC | Sobol | Halton |
|-----|--------|-------|--------|
| 64 | 6.819e-03 | 1.56e-04 | 2.34e-04 |
| 256 | 3.126e-03 | 1.1e-05 | 3.4e-05 |
| 1024 | 2.23e-04 | 1e-06 | 2e-06 |
| 4096 | 5.9e-05 | <1e-06 | <1e-06 |

> **⚠️ 陷阱**：**`qmc.discrepancy` 的默认方法是"中心差异"（centered discrepancy），不是星差异。** 两者定义不同、数值也不同，所以**不能把它的返回值直接代进 Koksma–Hlawka 不等式做数值验证**（我试过：用二维函数的变差估计乘上它，得到的"上界"比实际误差还小）。
>
> 这件事本身是个好例子：**定理成立，但你要用对那个量。**`discrepancy(..., method="CD")` 适合比较两个点集的均匀性（主章 5.10.1 就是这么用的），用它去验证一个用 $D^*$ 表述的定理则不对。

### S8.5 随机化的作用与代价

未随机化的 Sobol 是**确定性**序列：同样的 $N$ 总是给同样的点，所以**无法估计误差**——重复一次结果完全一样，误差条无从谈起。

**随机化（scrambling）** 通过对方向数做随机置换来打散点集，同时保持低差异性质。scipy 用 `scramble=True` + `rng=` 开启：

```python
>>> pts = qmc.Sobol(d=8, scramble=True, rng=1).random(4096)
```

三件事要记住：

1. **随机化不破坏低差异**：实测 $d = 3$、512 点时，随机化与不随机化的差异分别是 $1.0\times10^{-5}$ 与 $1.2\times10^{-5}$——同一量级。
2. **随机化之后才能给出误差条**：跑 100 次不同 `rng`，可以算误差的分布。主章 5.10.1 的所有 QMC 数字都是"200 次重复取中位误差"，这只有在随机化后才可能。
3. **随机化有代价，但很小**：生成同样多的点，scramble 需要额外的异或运算。对 $N$ 很大的场合这个开销占比很低。

### S8.6 为什么 QMC 加速不适用于方差比估计量

主章 5.10.2 记录了一个反直觉的实测：**把 MC 点换成 Sobol 点后，Sobol 敏感性指数的方差反而从 0.015 涨到 0.48。**

原因是 **QMC 的加速定理只对"期望型"估计量成立**：

$$\mu = \mathbb{E}[f(U)] = \int_{[0,1]^d} f(u)\,du \quad\leftarrow\quad \text{Koksma–Hlawka 直接适用}$$

而 Sobol 一阶指数

$$S_i = \frac{\mathrm{Var}_{u_i}\bigl(\mathbb{E}[Y \mid u_i]\bigr)}{\mathrm{Var}(Y)}$$

是一个**方差比**，它的 Saltelli 估计量是形如 $\frac{1}{N}\sum Y_B (Y_{AB_i} - Y_A)$ 的二次型。这个估计量的误差**不是** $f$ 的积分误差，Koksma–Hlawka 不等式对它没有直接约束。

要让 QMC 在敏感性分析里真正起效，需要**为估计量本身重新设计**（例如改用 RBD-FAST、或用 QMC 友好的估计量重构），而不是简单地替换采样点。**"换个更好的点集"这条经验有适用范围，判断依据是"你要估的是不是一个期望"。**

## 本文件小结

| 主题 | 核心要点 |
|------|---------|
| 浮点物理 | $\epsilon = 2.22\times10^{-16}$ 是相对量；灾难性抵消把绝对误差变成相对误差，改公式才能根治 |
| 两笔误差账 | 后向误差（残差）由算法决定，停在 $\epsilon$；前向误差还要乘 $\mathrm{cond}(A)$ |
| 残差不等于误差 | $\frac{\lVert\hat{x}-x\rVert}{\lVert x\rVert} \le \mathrm{cond}(A)\cdot\frac{\lVert r\rVert}{\lVert b\rVert}$，这就是"静默失准区"的来源 |
| 选主元 | 防的不是"问题难"而是"算法造误差"；$\mathrm{cond} = 2.6$ 也能算出完全错误的解 |
| QR 的两种做法 | Householder 正交误差恒在 $\epsilon$；MGS 按 $n$ 恶化（$n=200$ 时差 2000 倍） |
| Cholesky | 对称 + 正定是两个独立的加速来源；报错 `potrf info` 指的是主元非正 |
| SVD | 一次分解给出四个基本子空间；$\lVert Av_i\rVert = \sigma_i$ 是"奇异值是放大倍数"的证据 |
| 秩 | 浮点里不是良定义的整数，默认容差会让判定变成掷硬币 |
| 填充 | 是图的消元顺序问题，不是代数问题；RCM 优化带宽不优化填充 |
| CG | 迭代次数 $\propto\sqrt{\kappa}$；实测恰为 $0.785\sqrt{\kappa}$，教科书上界松 15 倍 |
| KKT | scipy 的约定是 $\nabla f = \lambda\nabla g$，写成加号会得到完全错误的结论；本例 $\lambda = 2(1-x_2)$ |
| 线搜索 vs 信赖域 | 信赖域用更少的函数调用达到更高精度，代价是要 Hessian |
| BFGS | 39 次调用得到误差 0.3% 的逆 Hessian 近似 |
| 差分导数 | $h^* \approx \epsilon^{1/3} \approx 6\times10^{-6}$；误差呈 U 形，精度天花板 $10^{-10}$ |
| 稳定域 | 显式方法的步长被稳定性压死：RK45 实测步长中位数 2.802e-3 vs 理论 2.785/$\lvert\lambda\rvert$ |
| A-稳定 ≠ 准确 | 隐式方法不发散，但初始瞬态分辨不出来仍然错几十个数量级 |
| Lebesgue 常数 | 等距 $2^n/n$ vs Chebyshev 对数增长；$n=20$ 时差 2076 倍——龙格现象的真凶 |
| 样条取舍 | $C^2$ 全局光滑换来的是过冲；PCHIP 局部保形牺牲了 $C^2$ |
| 外推 | 推出区间长度的 5% 误差就涨 14 倍；没有"小心外推"这回事 |
| Gauss–Kronrod | 自适应用更少的求值达到固定阶的精度；奇点必须靠变换，加密采样点无效 |
| FFT | $O(n\log n)$；$n = 2^{14}$ 时比朴素 DFT 快 12302 倍；素数长度慢 14.7 倍，用 `next_fast_len` 补齐 |
| 低差异序列 | van der Corput 数字反序 → Halton 换基 → Sobol 用 $\mathbb{F}_2$ 上的方向数 |
| QMC 的边界 | 加速定理只对期望型估计量成立；方差比估计量要重新设计 |

**三条最重要的机制**：

1. **误差的绝对大小由操作数的量级决定，与结果的量级无关。** 灾难性抵消、残差与误差的分离、差分的 U 形曲线，都是这一条的不同面孔。
2. **"问题有多难"和"算法有多好"是两笔独立的账。** 条件数、Lebesgue 常数、刚性比描述问题；增长因子、后向稳定性、A-稳定描述算法。混用它们会导致错误的归因——最常见的错误是"结果不准就换求解器"。
3. **每个算法都有一条"什么时候它不适用"的边界，而边界通常能从它的构造里读出来。** 显式方法的 $|R(z)| \le 1$、等距插值的 $\Lambda_n \sim 2^n$、FFT 对合数长度的依赖、QMC 对期望型估计量的要求——**知道边界在哪，比会用 API 更重要。**
