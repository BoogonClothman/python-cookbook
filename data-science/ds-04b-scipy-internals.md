## S1 零分布从哪来：t、F、$\chi^2$ 的同一个祖先

主章 4.2.3 给了这四个分布的名字和用途。本节把它们**从正态样本里造出来**——造得出来，才谈得上知道什么时候不该用。

### S1.1 三兄弟的血统：正态样本的二次型

三个分布都来自同一台机器：**标准正态的平方和**。

| 分布 | 定义 | 在一元统计里的角色 |
|------|------|------------------|
| $\chi^2(k)$ | $Z_1^2 + \cdots + Z_k^2$，$Z_i \stackrel{iid}{\sim} \mathrm{N}(0,1)$ | 样本方差、列联表、拟合优度 |
| $t(\nu)$ | $Z / \sqrt{V/\nu}$，$V \sim \chi^2(\nu)$ 且独立 | 均值的检验与区间 |
| $F(d_1,d_2)$ | $(V_1/d_1) / (V_2/d_2)$ | 方差比、方差分析 |

本节全部实验都是**照着定义手搓一遍，再用 KS 检验确认搓对了**：

```python
>>> rng = np.random.default_rng(0)
>>> z = rng.normal(0, 1, size=(200_000, 4))
>>> v = (z**2).sum(axis=1)                      # 4 个标准正态的平方和
>>> stats.kstest(v, stats.chi2(4).cdf).pvalue   # 与理论 chi2(4) 比
0.372
>>> v.mean(), v.var(ddof=1)                     # 理论：k=4 -> 均值 4，方差 2k=8
(4.0043, 8.0190)
```

三个 $k$ 的实测对照（每个 20 万次）：

| $k$ | 模拟均值 | 理论 | 模拟方差 | 理论 $2k$ | KS p 值 |
|-----|---------|------|---------|----------|--------|
| 1 | 1.0024 | 1 | 2.0176 | 2 | 0.854 |
| 4 | 4.0043 | 4 | 8.0190 | 8 | 0.372 |
| 30 | 29.9775 | 30 | 59.9274 | 60 | 0.544 |

**均值 $=k$、方差 $=2k$** 这两个数就是 $\chi^2$ 的身份证：只要看到某个统计量"均值等于自由度、方差是自由度的两倍"，它多半就是卡方。

### S1.2 $t$ 分布：为什么小样本必须用它

$t$ 的定义是"标准正态 ÷ $\sqrt{\chi^2/\nu}$"。统计上它出现在这里：**用样本标准差 $s$ 代替未知的总体 $\sigma$ 时，多出来的不确定性正好是 $\sqrt{\chi^2/\nu}$**。

```python
>>> z = rng.normal(0, 1, 200_000)
>>> v = (rng.normal(0, 1, size=(200_000, 4))**2).sum(axis=1)
>>> t_sim = z / np.sqrt(v/4)                      # 按定义造 t(4)
>>> stats.kstest(t_sim, stats.t(4).cdf).pvalue
0.931
>>> t_sim.var(ddof=1), 4/(4-2)                    # t 的方差是 df/(df-2)，不是 1
(1.9972, 2.0)
```

**关键细节：$t$ 的方差不是 1**。$t(\nu)$ 的方差是 $\nu/(\nu-2)$（$\nu>2$），$\nu=4$ 时是 2.0，$\nu=29$ 时是 1.0741，$\nu=1$ 时不存在。所以"标准差比正态厚一点点"这个说法要量化成"方差大 $\nu/(\nu-2)$ 倍"。

从**样本**直接构造也成立（$n=5$，2 万次）：

```python
>>> xs = rng.normal(10, 2, size=(20000, 5))
>>> t_stat = (xs.mean(axis=1) - 10) / (xs.std(axis=1, ddof=1)/np.sqrt(5))
>>> t_stat.var(ddof=1), (5-1)/(5-3)               # 理论方差 df/(df-2) = 2
(1.9317, 2.0)
>>> stats.kstest(t_stat, stats.t(4).cdf).pvalue
0.974
```

**用 $z$ 临界值（1.96）代替 $t$ 的代价**是可以直接量化的——用 $t$ 统计量去比正态临界值，实际第一类错误会远超 5%：

| $n$ | 用 $z=1.96$ 的实际第一类错误 | 用 $t$ 临界值 |
|-----|---------------------------|--------------|
| 3 | **18.86%** | 5.07% |
| 5 | **12.31%** | 5.16% |
| 10 | **8.15%** | 4.98% |
| 30 | 5.85% | 4.90% |
| 100 | 5.36% | 5.06% |

$n=3$ 时名义 5% 实际接近 **19%**——这就是主章 4.4.1 说"小样本必须用 $t$"的定量版本。$n>100$ 之后差距才真正可以忽略。

### S1.3 $F$ 分布：方差比与 ANOVA 的共同来源

```python
>>> v1 = (rng.normal(0, 1, size=(200_000, 3))**2).sum(axis=1)
>>> v2 = (rng.normal(0, 1, size=(200_000, 20))**2).sum(axis=1)
>>> f_sim = (v1/3) / (v2/20)
>>> f_sim.mean(), stats.f(3, 20).mean()
(1.1108, 1.1111)
>>> stats.kstest(f_sim, stats.f(3, 20).cdf).pvalue
0.783
```

$F$ 的均值是 $d_2/(d_2-2)$（$d_2>2$），$F(3,20)$ 是 $20/18 = 1.1111$。**两个样本方差之比乘上总体方差比就是 $F$**，这就是方差齐性检验与方差分析的同一个根：

```python
>>> s1 = rng.normal(0, 1, 50); s2 = rng.normal(0, 1, 30)
>>> f_obs = s1.var(ddof=1) / s2.var(ddof=1)
>>> 2 * min(stats.f(49, 29).cdf(f_obs), stats.f(49, 29).sf(f_obs))
0.9268
```

主章 4.5.5 的 `f_oneway` 用到的就是这条链：组间变异 / 组内变异 = 两个 $\chi^2$/df 之比。

### S1.4 自由度到底在数什么

教科书常说"自由度是能自由变化的个数"，这句话在**二次型**的语境下可以被精确化：**自由度 = 二次型的秩 = 数据维数减去被约束掉的维数**。

| 统计量 | 二次型 | 自由度 | 被约束掉什么 |
|--------|--------|--------|-------------|
| $\sum_i Z_i^2$ | $k$ 个独立正态 | $k$ | 无 |
| $(n-1)s^2/\sigma^2$ | 离差平方和 | $n-1$ | 均值（1 个约束：$\sum (x_i - \bar x)=0$） |
| 回归残差平方和 | $(X\beta - y)$ 的投影 | $n-p$ | $p$ 个参数 |
| 列联表 $\chi^2$ | 观测−期望 | $(r-1)(c-1)$ | 行合计与列合计（$r+c-1$ 个约束） |

主章 4.6.2 里"斜率区间的自由度是 $n-2$"、4.3.2 里"$np.std$ 与 $np.std(ddof=1)$ 差一个自由度"，都在这一张表里。

> **机制洞察**：三个分布是**同一件事的三个视图**——正态平方和的分布（$\chi^2$）、用它标准化后的分布（$t$）、两个这样的分布之比（$F$）。所以一元统计里的检验之所以"有解析公式"，前提都是**数据（或它的均值）近似正态**。这也是为什么主章 4.5.3 的方差齐性、4.7 的正态性诊断那么重要：违背前提时，错的不是"p 值不准"，而是"零分布根本不是那个分布"。

> **⚠️ 陷阱**：$t$ 的方差是 $\nu/(\nu-2)$ 而**不是 1**，且 $\nu \le 2$ 时方差无穷。用"$t$ 近似正态"做样本量估算时，这个尾部厚度就是主章 S5.2 里"近似式偏小"的来源。

> **延伸阅读**：二次型的秩与 Cochran 定理见参考文献 [2] 第 7 章；三个分布与正态的关系见 [1] 第 5、7 章。

## S2 检验的构造：从统计量到 p 值

### S2.1 四件套的形式化

一次检验由四个零件构成，写成集合语言：

1. **统计量** $T(X_1,\dots,X_n)$：把 $n$ 维数据压成一个数；
2. **原假设** $H_0$：对总体分布的约束（如 $\mu_1 = \mu_2$）；
3. **零分布**：$H_0$ 成立时 $T$ 的分布（S1 的三兄弟）；
4. **拒绝域** $\mathcal{R}$：满足 $p(X) \le \alpha$ 的样本集合。

**p 值就是"在 $H_0$ 下，统计量落进比当前更极端区域的概率"**：

$$p(x) = \sup_{\theta \in \Theta_0} P_\theta\big(T(X) \text{ 比 } T(x) \text{ 更极端}\big)$$

### S2.2 p 值为什么均匀：概率积分变换

$H_0$ 下 p 值服从 $\mathrm{U}(0,1)$ 不是巧合，而是**概率积分变换（PIT）** 的直接推论：若 $X$ 的 CDF 是 $F$，则 $F(X) \sim \mathrm{U}(0,1)$。p 值就是 $1-F(T)$（或它的两倍），所以也均匀。

这条定理可以直接验证——把任意分布的样本喂进自己的 CDF：

```python
>>> for dist, sampler in (("指数(1)", rng.exponential), ("t(5)", ...), ("chi2(3)", ...)):
...     u = dist.cdf(sampler(200_000))
...     print(dist.name, stats.kstest(u, "uniform").pvalue)
```

| 分布 | CDF 值的 KS p 值 | 均值 |
|------|-----------------|------|
| 指数(1) | 0.188 | 0.4992 |
| $t(5)$ | 0.280 | 0.5005 |
| $\chi^2(3)$ | 0.302 | 0.4997 |
| 对数正态 | 0.793 | 0.4998 |

四个 KS 检验**都不显著**（都像均匀分布）。这条性质支撑了三件事：

1. 主章 4.5.1"$p<0.05$ 的比例是 5.05%"；
2. **p 值本身不是效应量**：它在 $H_0$ 下均匀，$p=0.02$ 与 $p=0.40$ 的出现概率都是"可能的"；
3. **多重比较的 FWER 公式** $1-(1-\alpha)^m$ 的推导（S4.1）。

### S2.3 单侧、双侧与非对称零分布

零分布对称时，**双侧 p 值 = 2 × 单侧 p 值**：

```python
>>> x = rng.normal(0, 1, 30) + 0.35
>>> stats.ttest_1samp(x, 0).pvalue                     # 双侧
0.004219
>>> stats.ttest_1samp(x, 0, alternative="greater").pvalue
0.002110
```

但这条关系**只对对称零分布成立**。卡方、$F$ 这类非对称分布本来就是单尾检验，硬乘 2 会得到大于 1 的"p 值"。所以 `ttest_ind` 能选 `alternative`，而 `chi2_contingency` 只能给单尾——这不是 API 不一致，而是分布形状决定的。

### S2.4 功效的解析式：非中心 $t$

$H_0$ 不成立时，$t$ 统计量服从**非中心 $t$ 分布**，非中心参数是 $\delta = d\sqrt{n/2}$（两组等样本量，$d$ = Cohen's $d$）：

$$\text{power} = P\big(|T'| > t_{1-\alpha/2,\;\nu}\big), \qquad T' \sim \mathrm{nct}(\nu, \delta),\quad \nu = 2n-2$$

```python
>>> def power_analytic(d, n, alpha=0.05):
...     df = 2*n - 2
...     crit = stats.t.ppf(1 - alpha/2, df)
...     nc = d * np.sqrt(n/2)
...     return stats.nct.sf(crit, df, nc) + stats.nct.cdf(-crit, df, nc)
```

解析值与 2 万次模拟的对照（$d=0.5$）：

| $n$/组 | 解析（非中心 $t$） | 模拟 | 偏差 |
|--------|------------------|------|------|
| 10 | 0.1851 | 0.1792 | −0.0058 |
| 30 | 0.4779 | 0.4808 | +0.0030 |
| 64 | 0.8015 | 0.8005 | −0.0010 |
| 100 | 0.9404 | 0.9392 | −0.0012 |

全部落在蒙特卡洛误差内。**这就是 `stats.power` 用模拟法想逼近的那个值**——主章 4.5.8 里"$n=64$ 时功效 0.795"与这里的解析值 0.8015 一致。

### S2.5 Welch 的小数自由度：Satterthwaite 近似

主章 4.5.3 说 Welch 的第一类错误稳。它的代价是一个**近似**：自由度不是整数，而是

$$\nu \approx \frac{(s_1^2/n_1 + s_2^2/n_2)^2}{\dfrac{(s_1^2/n_1)^2}{n_1-1} + \dfrac{(s_2^2/n_2)^2}{n_2-1}}$$

```python
>>> a = rng.normal(0, 1, 10); b = rng.normal(0.5, 3, 40)
>>> s1, s2 = a.var(ddof=1), b.var(ddof=1)
>>> v = (s1/10 + s2/40)**2 / ((s1/10)**2/9 + (s2/40)**2/39)
>>> round(v, 4), stats.ttest_ind(a, b, equal_var=False).df
(47.6155, 47.6155)                  # 手算 = scipy
```

上下界：$\min(n)-1 = 9$ 与 $n_1+n_2-2 = 48$。**方差/样本量越失衡，$\nu$ 越接近 $\min(n)-1$**——自由度被"打折"，临界值变大，这正是 Welch 保守的来源（也是它不膨胀的代价）。

### S2.6 效应量族：同一份数据的不同尺子

```
两组差 2.99 分，合并 SD 15.32（n=200/组）
Cohen's d = 0.1949 | t = -1.949, df = 398
点二列相关 r = 0.0972 | eta^2 = 0.0095
换算核对：d/sqrt(d^2+4) = 0.0970 ≈ r
```

| 效应量 | 公式 | 适用 | 经验尺子 |
|--------|------|------|---------|
| Cohen's $d$ | $(\bar x_2-\bar x_1)/s_{pooled}$ | 两组均值差 | 0.2 / 0.5 / 0.8 |
| Cohen's $h$ | $2\arcsin\sqrt{p_2} - 2\arcsin\sqrt{p_1}$ | 两比例 | 0.2 / 0.5 / 0.8 |
| 点二列 $r$ | $\sqrt{t^2/(t^2+df)}$ | 两组 + 连续 | 0.1 / 0.3 / 0.5 |
| $\eta^2$ | $SS_{组间}/SS_{总}$ | 多变 ANOVA | 0.01 / 0.06 / 0.14 |
| Cramér's $V$ | $\sqrt{\chi^2/(n\min(r-1,c-1))}$ | 列联表 | 与 $r$ 类似 |

```python
>>> tab = np.array([[40, 160], [65, 135]])
>>> chi2, p, dof, _ = stats.chi2_contingency(tab, correction=False)
>>> round(float(np.sqrt(chi2/(400*1))), 4), round(float(p), 4)
(0.1420, 0.0045)
```

同一份数据里，$r=0.097$、$\eta^2=0.0095$、$d=0.195$ 说的是同一件事——**换算关系要背下来，否则报告里同一个效应会因尺子不同而"看起来"差很多**。

> **机制洞察**：检验的骨架是"**统计量 ÷ 它的零分布**"，而零分布的形状由 S1 的血统决定。所以"换一个检验"本质上只换了三件事之一：统计量、零分布、或对数据分布的假设。理解了这一点，主章 4.5 那一堆函数名就不再需要死记。

> **⚠️ 陷阱**：`p = 2 × 单侧` 只对对称零分布成立；非对称分布（$\chi^2$、$F$）没有"两侧"，硬乘 2 会给出 $p>1$ 的荒谬值。

> **延伸阅读**：非中心分布族与功效函数见 [1] 第 11 章；Satterthwaite 近似的原始文献见参考文献 [4]。

**回到主章**：S1 → 4.2.3、4.4.1；S2 → 4.5.1–4.5.6。

## S3 重采样的内核：置换与 bootstrap

主章 4.8 给了三种重采样的用法。本节回答"它们有多准、什么时候不成立"。

### S3.1 置换分布：可穷举时是精确的

两组各 3 个观测、共 6 个数，全部 $\binom{6}{3}=20$ 种分配可以**穷举**——这时置换检验给出的是精确 p 值，没有任何模拟误差：

```python
>>> import itertools
>>> stat = lambda x, y: x.mean() - y.mean()
>>> obs = np.array([1., 2., 3., 10., 11., 12.])
>>> combos = list(itertools.combinations(range(6), 3))
>>> null = np.array([stat(obs[list(c)], obs[[i for i in range(6) if i not in c]]) for c in combos])
>>> (np.abs(null) >= abs(stat(obs[:3], obs[3:])) - 1e-12).mean()
0.1                                # = 2/20
```

* 精确置换 p = **0.1000**（$2/20$），分辨率 $1/20 = 0.05$；
* 随机抽 9999 次也得到 **0.1000**（逼近精确值），分辨率 $1/(B+1)$。

**置换检验的"精确性"只在你穷举时存在**；实用中永远是随机抽样，因此永远是**带蒙特卡洛误差的估计**。这一点必须写在报告里。

### S3.2 随机置换的误差：p 值的蒙特卡洛不确定度

同一份数据、只换置换种子（30 个种子）：

| 重排次数 $B$ | p 的均值 | p 的标准差 | 极差 | 理论 SE $\sqrt{p(1-p)/B}$ |
|-------------|---------|-----------|------|--------------------------|
| 999 | 0.0035 | 0.00250 | 0.01000 | 0.00188 |
| 9 999 | 0.0017 | 0.00064 | 0.00240 | 0.00042 |
| 99 999 | 0.0017 | 0.00018 | 0.00080 | 0.00013 |

两条结论：

1. **误差按 $1/\sqrt B$ 缩小**（标准差从 0.0025 → 0.00064 → 0.00018，每 10 倍 $B$ 缩小约 3 倍）；
2. **判定线附近必须报 $B$**。若 $p \approx 0.05$、$B=999$，则 SE $\approx 0.0069$，95% 波动范围约 ±0.014——"$p=0.048$ 显著"与"$p=0.052$ 不显著"完全可能是同一个真相的两次抽签。

> **实用规则**：$p$ 落在 $[0.01, 0.10]$ 且要做"显著/不显著"判断时，$B \ge 10^5$（本机 9999 次约 58 ms，$10^5$ 次不到 1 秒，代价可忽略）。

### S3.3 可交换性失效的定量机制

置换检验的成立条件是**可交换性**：$H_0$ 下，打乱标签不改变数据的联合分布。方差不齐 + 样本量不等时它不成立，而失效的**方向**可以用方差公式精确预测。

置换零分布（随机分配）下均值差的方差是：

$$\mathrm{Var}_{\text{perm}} = \left(\frac1{n_1}+\frac1{n_2}\right)\cdot\frac{SS_{\text{总}}}{n_1+n_2-1}$$

而真实的抽样方差是 $\mathrm{Var}_{\text{true}} = s_1^2/n_1 + s_2^2/n_2$。两者的比值决定方向：

| 配置 | 置换零分布方差 | 真实抽样方差 | 比值 | 后果 | 主章实测第一类错误 |
|------|--------------|------------|------|------|------------------|
| $n=(10,40)$，$sd=(1,4)$ | 1.6148 | 0.5000 | **3.23** | 零分布过宽 → 保守 | 0.00% |
| $n=(10,40)$，$sd=(4,1)$ | 0.4668 | 1.6250 | **0.29** | 零分布过窄 → 膨胀 | 24.47% |
| $n=(20,20)$，$sd=(1,4)$ | 0.8282 | 0.8500 | 0.97 | 几乎无偏 | 4.13% |

**"非参数检验不需要假设"是错觉**：它换了一组假设（可交换性），而新假设同样可以被违反，并且违反的后果可以大到 0% 或 24%。

### S3.4 bootstrap 的 plug-in 原理

bootstrap 的一句话原理：**用经验分布 $\hat F_n$ 代替真实分布 $F$**。因为 $\hat F_n$ 是 $F$ 的相合估计，所以"从 $\hat F_n$ 重抽得到的统计量分布"能近似"从 $F$ 抽样得到的抽样分布"。

$$\theta = T(F) \quad\Longrightarrow\quad \hat\theta = T(\hat F_n), \qquad \text{重抽} \to \hat\theta^* \sim \text{近似 } \hat\theta \text{ 的抽样分布}$$

这条原理有两个直接推论：**它不假设分布形状**（所以适用于中位数、相关系数、$R^2$），但**它假设样本本身代表性足够**（所以小样本、重尾、依赖数据时会失效——S3.6）。

### S3.5 BCa 的三步推导（手算复现 scipy）

主章 4.4.3 说"默认选 BCa"。它比 percentile 多做的三件事可以完全手算：

**第一步：偏差校正** $z_0 = \Phi^{-1}\!\left(\dfrac{\#\{\hat\theta^*_b < \hat\theta\}}{B}\right)$ ——衡量 bootstrap 分布的中位数偏了多少。

**第二步：加速度** $a = \dfrac{\sum_i (\bar\theta_{(\cdot)} - \hat\theta_{(i)})^3}{6\left[\sum_i (\bar\theta_{(\cdot)} - \hat\theta_{(i)})^2\right]^{3/2}}$ ——用 **刀切法（jackknife）** 衡量 $\hat\theta$ 对单个观测的敏感度（偏度的标准化版本）。

**第三步：调整分位点**，把 nominal 的 $\alpha/2$、$1-\alpha/2$ 映射到新位置：

$$\alpha_{\text{adj}} = \Phi\!\left(z_0 + \frac{z_0 + z_{\alpha/2}}{1 - a(z_0 + z_{\alpha/2})}\right)$$

实测（指数分布 $n=60$，$B=9999$）：

```python
>>> data = np.random.default_rng(42).exponential(3.0, 60)
>>> theta = data.mean()
>>> B = 9999
>>> idx = np.random.default_rng(1).integers(0, len(data), size=(B, len(data)))
>>> boot = data[idx].mean(axis=1)                       # B 个重抽样均值
>>> z0 = stats.norm.ppf((boot < theta).mean())           # 偏差校正
>>> jack = np.array([np.delete(data, i).mean() for i in range(len(data))])
>>> jmean = jack.mean()
>>> a = ((jmean - jack)**3).sum() / (6*((jmean - jack)**2).sum()**1.5)   # 加速度
>>> zlo, zhi = stats.norm.ppf(0.025), stats.norm.ppf(0.975)
>>> p_lo = stats.norm.cdf(z0 + (z0 + zlo)/(1 - a*(z0 + zlo)))
>>> p_hi = stats.norm.cdf(z0 + (z0 + zhi)/(1 - a*(z0 + zhi)))
>>> round(p_lo, 5), round(p_hi, 5)
(0.03667, 0.98444)
>>> (np.quantile(boot, p_lo), np.quantile(boot, p_hi))
(1.9448..., 3.1965...)
>>> sc = stats.bootstrap((data,), np.mean, n_resamples=9999, method="BCa", rng=np.random.default_rng(1))
>>> round(sc.confidence_interval.low, 4), round(sc.confidence_interval.high, 4)
(1.9448, 3.1965)
```

```
z0 = 0.02018（50.8% 的重抽样低于观测值）| a = 0.036703
调整后的分位点：0.03667 / 0.98444（原始 0.025 / 0.975）
手算区间 = (1.9448, 3.1965) | scipy BCa = (1.9448, 3.1965)   # 完全一致
```

**调整方向值得记住**：分位点从 $[0.025, 0.975]$ 变成 $[0.037, 0.984]$——右移到**更靠中心**的位置，区间因此比 percentile **更宽**（主章实测 percentile 1.9028–3.1205，BCa 1.9448–3.1965），补偿了 bootstrap 分布自身的偏斜。

### S3.6 bootstrap 的三个失效场景

**（a）重尾：方差不存在的分布。** $t(2)$ 分布均值存在但方差无穷，1000 次重复（每次 $n=40$、$B=999$）：

| 方法 | 95% 区间的覆盖率 |
|------|----------------|
| percentile | 92.9% |
| **BCa** | **88.1%** |
| $t$ 解析区间 | 96.2% |

**BCa 反而最差**——它的加速度校正依赖刀切法的三阶矩，而重尾分布的高阶矩估计极不稳定，"校正"变成了"放大噪声"。**重尾数据宁可退回 percentile，或直接报中位数与四分位。**

**（b）极值统计量：bootstrap 突破不了样本边界。** 均匀分布 $0..1$ 的样本最大值，800 次重复：

```
bootstrap 区间覆盖真上界 1.0 的比例 = 0.0%
平均 bootstrap 标准误 = 0.01929
```

**永远是 0%**：样本最大值必然小于总体上界，重抽样也只能在样本内部取值，区间上界永远够不着真值。凡"关注的量在数据边界上"（最大值、最小值、上确界），bootstrap 在原理上就失效。

**（c）依赖数据：iid 重抽破坏时间结构。** AR(1) 过程 $\phi=0.8$、$n=200$、600 次重复：

```
iid bootstrap 覆盖率 = 45.2%（名义 95%）| 平均区间宽度 = 0.4450
有效样本量约 n(1-φ)/(1+φ) = 22.2；真 SE 是 iid 假设下 SE 的 3.0 倍
```

**覆盖率 45%，不是 95%**——因为 iid 重抽把序列的相关结构洗掉了，做出一个"比真实更窄"的区间（宽度按 $n=200$ 算，而有效样本量只有 22）。时间序列要用 **block bootstrap**（按块重抽以保留局部结构）或对残差建模，`scipy.stats.bootstrap` **不含** block 模式。

### S3.7 四个重采样函数的取舍

| 函数 | 输出 | 有 `rng` | 适用 | 失效条件 |
|------|------|---------|------|---------|
| `permutation_test` | p 值 | ✅ | 可交换的检验、无解析公式的统计量 | 方差/样本量失衡、依赖数据 |
| `bootstrap` | 区间、SE、重抽样分布 | ✅ | 估计量的精度 | 重尾、极值、依赖数据、极小样本 |
| `monte_carlo_test` | p 值 | ❌（只能全局种子） | 自定义统计量的零分布 | 同上；且默认不可复现 |
| `power` | 功效、p 值数组 | 通过 `kwargs={"rng":...}` | 任意检验的功效模拟 | 与所模拟的检验同样的前提 |

> **机制洞察**：重采样把"分布未知"这件事外包给了**经验分布**或**可交换性**。两条路都不需要正态假设，但都需要**样本有代表性**：bootstrap 要求样本近似总体（否则 plug-in 偏差），置换要求 $H_0$ 下可交换（否则零分布错）。**"不用假设"从来不是免费选项，只是把假设换成了更容易忽略的那一种。**

> **⚠️ 陷阱**：报告 bootstrap 区间时必须写清三件事——**方法（percentile/basic/BCa）、$B$、重抽单位（行/块/簇）**。主章 4.4.4 的覆盖率实测就是例子：同样的数据，percentile 93.5%、BCa 93.8%、解析 95.5%，"95% 区间"这三个字的信息量远不如"哪种 95%"。

> **延伸阅读**：BCa 的原始推导见参考文献 [3] 第 14 章；block bootstrap 与依赖数据见 [3] 第 8 章。

## S4 多重比较：FWER 与 FDR 的账

### S4.1 FWER 的精确值，以及相关性如何改变它

$m$ 个**独立**检验、全部 $H_0$ 为真时，至少一次假阳性的概率（族错误率 FWER）是精确可算的：

$$\mathrm{FWER} = 1 - (1-\alpha)^m$$

$m=20$、$\alpha=0.05$ 时 $1-0.95^{20} = 64.15\%$，主章实测 64.42%（2 万次重复，误差在 $\pm 0.3$ 个百分点内）。

但**检验之间有相关性时这条公式不再适用**——而真实的多指标分析几乎总相关。用等相关结构模拟（$m=20$，2 万次重复）：

| 相关系数 $\rho$ | 不校正的 FWER | Bonferroni | Holm |
|----------------|--------------|-----------|------|
| 0.0 | 64.42% | 5.15% | 5.35% |
| 0.2 | 59.16% | 4.69% | 5.30% |
| 0.5 | 42.12% | 3.57% | 3.62% |
| 0.9 | **15.48%** | **1.35%** | 1.68% |

两个方向相反的结论：

- **相关性降低了"至少错一次"的概率**（64% → 15%），因为多个检验在"同错同对"；
- **但它让 Bonferroni/Holm 变得更保守**（5% → 1.35%）——校正公式假设独立，相关性越强，实际 FWER 越低于名义值，功效损失越大。

所以"相关性强时用 Bonferroni 太保守"不是感觉，是可以量化的：$\rho=0.9$ 时实际 FWER 只有名义值的四分之一。

### S4.2 Bonferroni 与 Holm

- **Bonferroni**：每个检验用 $\alpha/m$。由布尔不等式 $P(\cup A_i) \le \sum P(A_i)$，FWER 永远 $\le \alpha$，**不要求独立**（只要求每个检验本身有效）。代价是 $m$ 大时功效急剧下降。
- **Holm**（逐步下降）：把 p 值排序，第 $k$ 小的与 $\alpha/(m-k+1)$ 比，一旦不通过就停。它**均匀地优于 Bonferroni**（拒绝集总是更大），同样不要求独立。实测：$\rho=0$ 时 Holm 5.35% vs Bonferroni 5.15%，两者都守住，Holm 略松（因此功效略高）。

### S4.3 BH 与 FDR

**FDR（false discovery rate）= 被拒绝的假设里，假的那种的期望比例**。Benjamini-Hochberg 的做法是：把 p 值排序，找最大的 $k$ 使 $p_{(k)} \le \frac{k}{m}\alpha$，拒绝前 $k$ 个。

- BH 控制的是 FDR，**不是 FWER**：它允许"100 个发现里有 5 个是假的"，而不要求"一个都不错"；
- 独立或正相关（PRDS 条件）下 BH 都成立——实测（100 个检验、20 个真效应、2000 次重复）：

| $\rho$ | 方法 | 平均 FDP（假发现比例） | 平均真阳性率 |
|--------|------|----------------------|-------------|
| 0.0 | BH | 0.0397 | **0.508** |
| 0.0 | Bonferroni | 0.0062 | 0.250 |
| 0.5 | BH | 0.0340 | **0.479** |
| 0.5 | Bonferroni | 0.0145 | 0.245 |

**BH 在守住 FDR ≈ 4%（目标 5%）的同时，真阳性率是 Bonferroni 的两倍**。这是探索性分析里选 BH 的量化理由。

### S4.4 选择口诀

| 场景 | 选 | 控制的是 |
|------|----|---------|
| 确证性结论（上线决策、论文主结论） | Holm / Bonferroni / Tukey HSD / Dunnett | FWER（一次都不能错） |
| 探索性筛选（找候选特征、初筛指标） | BH（`false_discovery_control`） | FDR（错的比例可控） |
| 只跟一个对照比 | Dunnett | FWER |
| 两两全比 | Tukey HSD | FWER |

> **⚠️ 陷阱**：**FDR 与 FWER 不是"严不严"的关系，而是两个不同的目标函数**。$\alpha=0.05$ 的 BH 允许 100 个发现里 5 个是错的；如果这 5 个错误无法承受（例如要基于结论停产），就该用 FWER。反过来，用 Bonferroni 去筛候选特征会漏掉大量真信号（实测真阳性率 0.25 对 0.51）。**先问"错一个的代价"，再选方法。**

> **延伸阅读**：BH 的原始文献与 PRDS 条件见参考文献 [5]；Holm 见 [6]。

## S5 功效与样本量：公式的形状

### S5.1 非中心参数：功效的唯一自变量

两组等样本量的 $t$ 检验，功效只通过一个量依赖 $d$ 与 $n$：

$$\delta = d\sqrt{n/2}$$

所以"$d=0.5$、$n=64$"与"$d=0.25$、$n=256$"的**功效完全相同**（$\delta = 2.83$）。这条不变性解释了主章 4.5.8 的表：效应减半、样本量要翻四倍。

### S5.2 三档样本量公式的精度

| $d$ | 近似式 $\dfrac{2(z_{1-\alpha/2}+z_{1-\beta})^2}{d^2}$ | 精确解（非中心 $t$ 反解） | 模拟核对（4000 次） |
|-----|--------------------------------------------------|------------------------|-------------------|
| 0.2 | 392.44 | **394** | 0.800 |
| 0.5 | 62.79 | **64** | 0.801 |
| 0.8 | 24.53 | **26** | 0.804 |

（目标功效 80%，$\alpha=0.05$ 双侧。）

近似式**系统性偏小**（392 对 394、63 对 64、25 对 26），因为它在正态的世界里算，忽略了 $t$ 的厚尾——效应越小、$n$ 越大时偏差越小。**工程建议：用近似式得到初值，再用非中心 $t$ 或 `stats.power` 精算一遍**，多花不到一秒。

### S5.3 比例的样本量

基线 5%、想检出 20% 的相对提升（到 6%）：

| 方法 | 每组样本量 | 模拟实际功效 |
|------|-----------|-------------|
| Cohen's $h$ 近似式 | 8 143 | 0.799 |
| 两比例专用公式 | 8 158 | 0.801 |

两者在这个例子里几乎一致（差 0.2%），**极端比例（如 0.1% 或 50%）时才会明显分开**。两比例公式：$n = \dfrac{\left(z_{1-\alpha/2}\sqrt{2\bar p(1-\bar p)} + z_{1-\beta}\sqrt{p_1(1-p_1)+p_2(1-p_2)}\right)^2}{(p_2-p_1)^2}$。

注意这个量级：**为了检出 1 个百分点的绝对提升，需要每组约 8000 人**。这就是主章 4.9 那个 A/B 例子用 $n=10000$ 的原因。

### S5.4 多重比较下的功效折损

$n=100$/组、$d=0.4$、Bonferroni 校正：

| 检验数 $m$ | 单次功效（校正后） | 至少一个成功的概率 |
|-----------|------------------|------------------|
| 1 | 0.804 | 0.804 |
| 5 | 0.591 | 0.988 |
| 20 | 0.410 | 1.000 |
| 100 | **0.243** | 1.000 |

**单次功效从 0.80 掉到 0.24**，但"至少中一个"的概率接近 1。这正是多指标实验的两难：**想保住每个指标的检验力，样本量要乘以 $m$**；否则只能接受"总有几个能中，但说不清是哪个真的"。

### S5.5 事后功效为什么不提供信息

对同一份数据，用观测到的效应量反推"事后功效"：

| 观测 p 值 | 事后功效（同 p 的数据平均） |
|----------|--------------------------|
| ≈0.0 | 0.876 |
| ≈0.1 | 0.395 |
| ≈0.2 | 0.247 |
| ≈0.3 | 0.178 |
| ≈0.4 | 0.134 |
| ≈0.5 | 0.103 |

**事后功效是 p 值的单调函数**（给定 $n$ 几乎一一对应）——p 小则"功效高"，p 大则"功效低"。"我们的功效只有 0.4，所以没检出是样本量的问题"这句话，等价于"我们的 p 值是 0.20"，**不提供任何新信息**。

**功效只能在实验之前用**：给定 $\alpha$、目标功效、最小可检测效应（MDE），算所需样本量——这是设计，不是解释。

> **机制洞察**：功效分析的三个输入（效应量、样本量、$\alpha$）里，**只有效应量是"你希望检出多大"的承诺，其余两个是资源约束**。所以正确的问题从来不是"我的功效是多少"，而是"**我愿意花多少样本，去检出多大的效应**"。

> **⚠️ 陷阱**：`stats.power` 的默认 `significance=0.01`（版本注意②），不显式传 0.05 会得到偏低的功效，进而算出偏大的样本量。这条默认值是最容易被无声踩中的坑。

> **延伸阅读**：非中心分布与样本量公式见 [1] 第 11 章；事后功效的批评见参考文献 [7]。

## S6 分布拟合的数值问题

主章 4.7.4 说"`bounds` 不是可选的礼貌参数"。本节给它的数值理由与三个实用结论。

### S6.1 为什么目标函数是对数似然

极大似然要最大化 $\prod_i f(x_i;\theta)$。$n=300$ 时这个乘积已经在 double 的下溢边缘：

```
gamma 在 MLE 附近的 logpdf 样本均值 = -2.2632
联合对数似然 = -678.95        ->  联合似然 = 1.373e-295
```

`1.37e-295` 距离 double 的最小正规数（约 $2.2\times10^{-308}$）只剩两个数量级——$n$ 再大一点就直接变成 `0.0`，所有参数的对数似然都"等于"负无穷，优化器失去方向。**取对数不只是数学上的便利，更是数值上的必需**：$\log\prod = \sum\log$，把乘积变成和，量级从 $10^{-295}$ 回到 $-679$。

### S6.2 似然面的脊线：$a$ 与 scale 的纠缠

gamma 分布的形状参数 $a$ 与尺度参数 scale 在似然面上高度相关，表现为一条"脊线"（nllf 表，行 = $a$，列 = scale）：

```
          1.40      1.70      2.00      2.40
a= 1.8   777.9     721.2     695.9     687.6
a= 2.0   745.0     700.0     684.4     687.1
a= 2.2   719.8     686.5     680.7     694.3
a= 2.5   694.8     678.9     687.8     717.8
a= 2.8   683.1     684.7     708.2     754.5
```

**沿对角线方向 nllf 变化很小**——$(a{=}1.8,\text{scale}{=}2.4)$ 的 nllf 是 687.6，$(a{=}2.5,\text{scale}{=}1.7)$ 是 678.9，只差 9。这意味着"$a$ 的置信区间"不能单独读：$a$ 与 scale 的估计相关系数实测 **−0.93**，一个变大另一个必然变小。**报单参数区间而不报协方差，等于隐瞒了参数不可辨识的事实。**

### S6.3 `bounds` 不是可选的：三种不给法的三种下场

实测同一份数据、同一个 `stats.fit(stats.norm, data)`（真 MLE 是 `loc=4.2707, scale=2.6148, nllf=713.54`）：

| 写法 | 结果 | `success` |
|------|------|-----------|
| 不给 `bounds` | `loc=0.0, scale=1.0, nllf=4033.66` | **True** |
| 显式无限 bounds `{"loc": (-inf, inf), ...}` | `ValueError: ... is not finite. Please provide finite bounds` | — |
| 有限 bounds `{"loc": (-20, 20), "scale": (1e-3, 20)}` | `loc=4.2707, scale=2.6105, nllf=713.54` ✓ | True |
| 宽但有限 bounds（±1e6） | 同上，结果一致 | True |

三种下场分别是：

1. **不给 `bounds` → 静默返回初值**。`nllf` 是 4033.66，而真值只要 713.54——差了 5.7 倍，但 `success` 返回 `True`、`message` 返回 `Optimization terminated successfully.`。**这是最危险的一类 API 行为**：不看 `nllf` 就发现不了。
2. **显式给无限 bounds → 直接报错**。所以"给它 ±inf 让它自己找"这条退路也不通。
3. **有形状参数的分布（`gamma`、`t`、`beta`、`lognorm`……）连 `bounds=None` 都会报错**：

```python
>>> stats.fit(stats.gamma, data)
ValueError: The intersection of user-provided bounds for `a` and the domain of
the distribution is not finite. Please provide finite bounds for shape `a` ...
```

**唯一正确的写法是给"宽但有限"的 bounds**，并且**事后必须检查 `nllf()`**——它是唯一能识别静默失败的量。旧教程里"`stats.fit(dist, data)` 一把梭"的写法在 1.18 上要么报错、要么给你一个假的成功。

### S6.4 起点不重要，因为默认优化器是全局的

同一份数据、同一组 bounds，只改初始猜测：

```
guess a=1.0 scale=1.0 -> a=2.6879 loc=-0.0965 scale=1.6247 | nllf=678.820
guess a=9.0 scale=9.0 -> a=2.6879 loc=-0.0965 scale=1.6247 | nllf=678.820
```

**两者完全相同**。原因在主章 4.7.4 提过：`stats.fit` 的默认优化器是 `differential_evolution`（全局优化，见第 5 章）。代价是慢（每次 `fit` 要跑几十次局部优化），收益是不用担心初值——**这是"用时间换稳健"的典型取舍**。

### S6.5 渐近标准误偏乐观

用观测信息矩阵（Hessian）的逆算 SE，与"重复抽 400 次数据、每次重新拟合"的实测标准差对照：

| 量 | Hessian（渐近） | 400 次重复实测 |
|----|---------------|--------------|
| SE($a$) | 0.2350 | **0.3135** |
| SE(scale) | 0.1597 | **0.1939** |
| corr($a$, scale) | −0.9304 | −0.8821 |
| $a$ 的偏度 | — | 0.549 |

渐近 SE **低估了 25%–33%**。原因是 Fisher 信息的渐近理论要求 $n \to \infty$，而 $n=300$ 时似然面还是弯的（$a$ 的估计分布偏度 0.549 就是证据）。另外注意：Hessian 法的相关（−0.93）比真实相关（−0.88）**更极端**——它把脊线"看得更窄"。

**实践含义**：用 Hessian 报参数 SE 会显得比实际更精确。三种更稳的做法：

1. **参数自助**（S6.6 的同一套流程）：重抽 → 重拟合 → 取分位数，最稳但最慢；
2. **profile likelihood 区间**：对每个参数扫一条曲线找 $\Delta\text{nll} = \chi^2_1(0.95)/2 \approx 1.92$ 的位置，非对称且不依赖二次近似；
3. 至少**同时报协方差或相关系数**，别只报单参数 SE。

### S6.6 拟合优度必须模拟校准

主章 4.7.2 的 Lilliefors 陷阱在这里有了通用解法：**参数估过之后，用参数自助（parametric bootstrap）造零分布**。

```
朴素 KS:  D = 0.02836, p = 0.9637      <- 参数是估的，p 被严重高估
蒙特卡洛校准（2000 次参数自助）: p = 0.7990
零分布 D 的中位数 0.03437，95% 分位 0.05016
```

读数方式：**$p$ 的分子是"观测 D"，分母是"校准后的零分布"**。朴素 KS 把 0.02836 拿去比固定分布的临界值（约 0.079 对应 5%），于是 p 高达 0.96；正确的参照是"参数也重新估一遍时的 D 分布"——中位数就有 0.034，95% 分位 0.050。**同一个 D，校准前后从"完全没问题"变成 p = 0.80（仍然没问题，但不再是"好得可疑"）。**

```python
# 参数自助校准的通用骨架
D_obs = stats.kstest(data, fitted.cdf).statistic
D_null = [stats.kstest(sim, refit(sim).cdf).statistic
          for sim in (fitted.rvs(len(data), random_state=rng) for _ in range(2000))]
p_calibrated = (np.array(D_null) >= D_obs).mean()
```

### S6.7 矩估计 vs MLE

```
矩估计: a=2.6765 scale=1.5956
MLE:    a=2.6879 scale=1.6247
真值:   a=2.5    scale=1.7
```

$n=300$ 时两者几乎一样。取舍：

| 方法 | 优点 | 缺点 |
|------|------|------|
| 矩估计 | 一行代码、无需优化器、永远有解 | 小样本有偏（方差被低估 → $a$ 偏大）、对离群点敏感 |
| MLE | 渐近有效（方差最小）、有理论保障 | 需要优化、可能发散、依赖 `bounds` |
| 稳健（如 `stats.fit` 后用 `trim` 数据） | 抗离群 | 没有现成的渐近理论 |

> **机制洞察**：分布拟合的困难不在"选哪个分布"，而在**似然面的形状**——它常常是一条脊线（$a$ 与 scale 相关 −0.93），而不是一个尖峰。这带来三个连锁后果：优化需要全局方法、单参数 SE 会误导、拟合优度必须模拟校准。**凡是"参数之间有乘积关系"的分布（gamma、beta、lognorm、weibull）都有这个性质。**

> **⚠️ 陷阱**：`FitResult.nllf` 在 1.18 里是**方法不是属性**（`hasattr(r, "nllf")` 为真，但 `r.nllf` 是绑定方法，要写 `r.nllf()`）——这类"属性与方法同名"的 API 在数值格式化里会直接抛 `TypeError`。同类地，`r.success` 是属性、`r.message` 是属性、`r.params` 是 `FitParams` 具名元组（用 `._asdict()` 展开）。

> **延伸阅读**：MLE 的渐近理论与 Fisher 信息见 [2] 第 9 章；profile likelihood 见 [2] 第 9.5 节；参数自助的拟合优度检验见 [3] 第 4 章。

**回到主章**：S6 → 4.7.4、4.7.5、4.7.6。

## S7 何时离开 `scipy.stats`

`stats` 覆盖了"经典频率派推断"的绝大部分，但四类需求它做不了或做不好：

| 需求 | 该去的库 | 为什么 scipy 不够 |
|------|---------|------------------|
| 多元回归诊断（残差图、VIF、稳健 SE、交互项） | **statsmodels** | `linregress` 只有一元；`curve_fit` 不做推断诊断 |
| 时间序列（ARIMA、季节性分解、平稳性检验） | **statsmodels** | `stats` 只有基础自相关，没有模型族 |
| 混合效应 / 面板 / 广义线性模型 | **statsmodels**、`pymer4` | 超出 `stats` 的模型范围 |
| 交叉验证、重采样评估模型 | **scikit-learn**（`KFold`、`cross_val_score`） | `stats.bootstrap` 只重抽数据，不切分训练/验证 |
| 贝叶斯推断（后验、HMC、层次模型） | **PyMC**、`numpyro`、`stan` | `stats` 的 `beta`/`dirichlet` 只是分布对象，不做推断 |
| 生存分析（Kaplan-Meier、Cox） | **lifelines**、`statsmodels` | `stats.ecdf` 支持删失数据，但只有描述 |
| 效应量与功效的现成表 | **pingouin**、`statsmodels.stats.power` | `stats.power` 只给模拟，没有经典公式族 |
| 多重比较的现成报告（Tukey 表、字母标记） | **statsmodels**、**pingouin** | `tukey_hsd` 给矩阵，不给报告表 |

判断口诀与主章 4.1.1 一致：**能力范围内（分布、检验、区间、重采样、拟合）留在 `stats`；一旦需要"模型 + 诊断"或"先验 + 后验"，就该换库。** 换的时候注意一个衔接问题：`statsmodels` 的 `OLS` 结果对象提供 `.pvalues`、`.conf_int()`，与 `stats` 的 p 值/区间口径一致（都是频率派），所以两边的结论可以直接对照，不必换算。

> **机制洞察**：`scipy.stats` 的边界正好是"**单变量、频率派、无需模型设定**"这三个词的合取。越过任何一个——多变量、贝叶斯、或需要指定模型结构——都会撞到它的设计边界。知道边界在哪，就不会出现"用 `linregress` 硬解多元回归"这类事故（那是主章 4.6.5 结尾指向卷 3 的原因）。

**回到主章**：S7 → 4.1.1、4.6.5。

## 本文件小结

| 节 | 核心结论 |
|----|---------|
| S1 | $t$/$F$/$\chi^2$ 都是正态样本的二次型：$\chi^2$ 均值 $=k$ 方差 $=2k$、$t$ 方差 $=\nu/(\nu-2)$、$F$ 均值 $=d_2/(d_2-2)$，实测 KS p 值 0.37–0.93；**用 $z=1.96$ 代替 $t$：$n=3$ 时第一类错误 18.86%**；自由度 = 二次型的秩 |
| S2 | p 值均匀来自概率积分变换（四族分布实测 KS 均不显著）；$p=2\times$单侧只对对称零分布成立；功效的解析式是非中心 $t$（$nc = d\sqrt{n/2}$），与模拟一致到 0.006；Welch 的 df 是 Satterthwaite 小数（手算 = scipy）；效应量族可互换（$r = d/\sqrt{d^2+4}$） |
| S3 | 置换检验只在穷举时精确（$\binom63=20$ → 精确 p = 2/20）；随机置换的误差按 $1/\sqrt B$ 缩小（$B$ 从 999 到 99999，sd 从 0.0025 到 0.00018）；可交换性失效的方向由零分布方差比决定（3.23 → 保守 / 0.29 → 膨胀）；**BCa 三步手算完全复现 scipy（1.9448, 3.1965）**；三个失效场景：重尾（BCa 覆盖 88.1%）、极值（覆盖上界 0.0%）、依赖（覆盖 45.2%） |
| S4 | $\mathrm{FWER}=1-(1-\alpha)^m$（实测 64.42% 对理论 64.15%）；相关性同时降低不校正的 FWER（$\rho=0.9$ 时 15.48%）与抬高校正的保守度（Bonferroni 仅 1.35%）；BH 在 FDR 4% 下真阳性率 0.508，是 Bonferroni（0.250）的两倍 |
| S5 | 功效只通过 $\delta = d\sqrt{n/2}$ 依赖参数；近似样本量公式系统性偏小（392/63/25 对精确 394/64/26）；比例样本量两种公式在 5%→6% 时几乎一致（8143 / 8158）；多重比较下单次功效从 0.80 掉到 0.24；**事后功效是 p 值的复读机**（p≈0.1 → 0.395，p≈0.5 → 0.103） |
| S6 | 联合似然在 $n=300$ 已到 $10^{-295}$（必须用对数）；似然面是脊线（$a$ 与 scale 相关 −0.93）；**`stats.fit` 不给 `bounds` 会静默返回初值**（loc=0/scale=1、`nllf` 4033.66 对真值 713.54，而 `success` 仍是 `True`），显式无限 bounds 直接报错，有形状参数时必须给有限 bounds；默认全局优化使起点无影响；渐近 SE 低估真实离散 25–33%；拟合优度必须参数自助校准（朴素 p=0.96 → 校准 p=0.80）；`nllf` 是方法不是属性（要写 `r.nllf()`） |
| S7 | `stats` 的边界是"单变量 + 频率派 + 无需模型设定"；越界去 statsmodels / sklearn / PyMC / lifelines / pingouin |
