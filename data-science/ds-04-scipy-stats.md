# 第4章 SciPy 与统计推断：从数据到结论

> **学习目标**：把"数据 + 假设"变成"结论 + 不确定性"，并且能说清每一步的依据。
>
> - **会建模型**：把问题翻译成分布对象与假设（$H_0$/$H_1$），知道 `stats` 里每个零件的职责

> - **会收口**：把统计口径写成可执行断言，把结论写成"区间 + 效应量 + 前提"

本章是卷 2 的收口章。`ds-00` 给了概率与推断的数学地基（分布、期望、CLT、标准误、蒙特卡洛），`ds-01` 给了数组原语（1.13.4 的重抽样、1.13.5 的 bootstrap 区间），`ds-02` 给了表与分组，`ds-03` 给了图与验收。它们欠下的所有"到 `ds-04` 再讲"的账，都在这里结清：**置信区间、p 值、检验功效、多重比较、置换检验、bootstrap、分布拟合**。

## 4.1 scipy 定位与推断骨架

### 4.1.1 scipy 在四件套里的位置

卷 2 的四个库各有分工，越界使用是第一类错误的常见来源：

| 库 | 管什么 | 典型调用 | 什么时候**不要**用 |
|----|--------|---------|------------------|
| NumPy（`ds-01`） | 数组与线性代数原语 | `np.mean`、`np.linalg`、`rng` | 需要分布、检验、优化的地方 |
| pandas（`ds-02`） | 带标签的表、分组、时间序列 | `groupby`、`resample`、`merge` | 需要统计推断的"结论"时（它只给描述） |
| matplotlib（`ds-03`） | 图与验收 | `fig/ax`、`.savefig` | 需要算数的任何地方 |
| **SciPy（本章）** | **统计推断 + 数值算法** | `stats.*`、`optimize.*`、`linalg.*` | 需要建模与机器学习时（卷 3） |

`scipy.stats` 是本章的主角，它由四层构成，从下往上：

| 层 | 内容 | 数量级（本机 1.18.1 实测） |
|----|------|--------|
| 分布对象 | `norm`、`t`、`binom`……每个都是带统一接口的"机器" | 131（连续 110 + 离散 21） |
| 描述与估计 | `describe`、`sem`、`bootstrap`、`interval` | 十余个 |
| 假设检验 | `ttest_*`、`mannwhitneyu`、`chi2_contingency`、`f_oneway`…… | 约 40 个 |
| 重采样 | `permutation_test`、`bootstrap`、`monte_carlo_test`、`power` | 4 个 |

> **机制洞察**：`scipy.stats` 的设计哲学是 **"一个分布对象 + 一组检验函数"**，而不是"每个检验一套独立工具"。所以学会 4.2 的分布接口之后，剩下 60 多个检验函数只是"取哪个统计量、比哪条零分布"的变化——本章的主线就是这两件事。

### 4.1.2 统计推断的四步骨架

任何一次"从数据到结论"都走同一条路，缺一步结论就不可信：

| 步 | 做什么 | 本章对应节 | 漏掉的后果 |
|----|--------|-----------|-----------|
| 1 **建模型** | 明确总体、参数、$H_0$/$H_1$、显著性水平 $\alpha$ | 4.5.1 | 事后改假设 = p-hacking |
| 2 **给估计** | 点估计 + 不确定性（标准误或区间） | 4.3、4.4 | 只报"平均提高了 12%"而没有区间 |
| 3 **做检验** | 选统计量、算 p 值、看效应量 | 4.5、4.6、4.8 | 显著但效应微小，业务上无意义 |
| 4 **下决策** | 结合代价、前提、多重性给出行动 | 4.5.9、4.9 | 把 p<0.05 当成"必须上线" |

### 4.1.3 本章的三条纪律

1. **口径先定**：分析开始前写死指标定义、$\alpha$、最小可检测效应（MDE）、剔除规则。改口径要留痕，**事后调整口径等于重新抛硬币**。
2. **假设先写**：$H_0$ 是什么、备择是单侧还是双侧、独立性成不成立。4.8 会看到：假设错了，检验的"5%"根本不是 5%。
3. **区间优于点**：任何"提升了 X%"都必须带区间与 n。区间给的是**精度**信息，点估计给不了。

## 4.2 随机变量对象：分布是一台机器

### 4.2.1 一个接口，六种用法

`ds-00` 0.3.4 讲了 PMF/PDF/CDF 的数学定义。scipy 把它们做成了**同一个对象上的六个方法**：

```python
>>> from scipy import stats
>>> stats.norm.pdf(0)          # 密度：连续分布"在某点附近的浓度"
0.3989422804014327
>>> stats.norm.cdf(1.96)       # 左尾面积：P(X <= x)
0.9750021048517795
>>> stats.norm.ppf(0.975)      # CDF 的反函数：给概率要分位点
1.959963984540054
>>> stats.norm.sf(1.96)        # 右尾面积：P(X > x) = 1 - cdf
0.024997895148220435
>>> stats.norm.isf(0.025)      # sf 的反函数
1.959963984540054
>>> stats.norm.pdf(1.96)       # 与手写公式核对
0.058440944333451476
```

手写公式的对照（`ds-00` 0.3.4 给过连续型 PDF 的写法）：

```python
>>> import numpy as np
>>> np.exp(-1.96**2 / 2) / np.sqrt(2 * np.pi)
0.058440944333451476
```

六种用法里有两个必须刻进肌肉记忆：

- **`sf` 是 p 值的主力**。右尾概率用 `sf` 而不是 `1 - cdf`，因为当 p 小到 $10^{-16}$ 时 `1 - cdf` 会因浮点相减直接变成 `0.0`，而 `sf` 直接算右尾，能给出真实数量级。凡是写 p 值的地方，优先 `sf`。
- **`pdf` 不是概率**。`norm.pdf(0) = 0.399` 是密度，可以大于 1；要概率必须乘区间宽度或改用 `cdf` 相减。

```python
>>> stats.norm.pdf(0) * 0.01        # 0 附近 0.01 宽度内的近似概率
0.003989422804014327
>>> stats.norm.cdf(0.005) - stats.norm.cdf(-0.005)   # 精确值，与上一行同量级
0.003989422744842429
```

### 4.2.2 `loc` / `scale` 与冻结分布

多数连续分布是**位置-尺度族**：`loc` 移中心、`scale` 改宽度。把它写进对象（"冻结"）之后，接口不变但参数固定：

```python
>>> h = stats.norm(loc=170, scale=10)     # 身高分布：均值 170，标准差 10
>>> h.cdf(180)                             # 直接问"低于 180 的比例"
0.8413447460685429
>>> stats.norm.cdf((180 - 170) / 10)       # 等价写法：先标准化
0.8413447460685429
>>> h.ppf(0.975)                           # 95% 参考区间上界
189.59963984539995
>>> h.interval(0.95)                       # 一次给出双侧区间
(150.40036015460005, 189.59963984539995)
>>> h.rvs(3, random_state=np.random.default_rng(0))
array([171.2573 , 168.67895, 176.40423])
```

冻结分布的三个好处：**参数只写一次**、`interval()` 直接给区间、`rvs()` 自带相同参数。注意 `rvs` 的随机源用 `random_state=` 传入（写 `rng=` 也能用，但 `random_state` 是官方参数名）。

> **⚠️ 陷阱**：**`scale` 是标准差，不是方差**。`ds-00` 0.3.7 已经强调过 $N(\mu, \sigma^2)$ 的第二个参数是方差，而 API 里是 `scale=σ`。第二个高频陷阱是**指数分布的参数化**：`stats.expon(scale=2)` 的均值是 2（`scale = 1/λ`），而不是 $\lambda = 2$ 的那条分布——实测 `stats.expon(scale=2).mean() == 2.0`。第三类是 `lognorm`：它的形状参数是 `s`（对数标准差），不是均值也不是方差，用之前务必查 `stats.<dist>.shapes`。

### 4.2.3 分布总表：ds-00 认识的五个 + 本章要用的族

| 分布 | 调用 | 形状参数 | 用在哪 | ds-00/本章 |
|------|------|---------|--------|-----------|
| 均匀 | `stats.uniform` | — | 概率积分变换、随机基准 | ds-00 0.3.7 |
| 二项 | `stats.binom(n, p)` | `n, p` | 转化率、次品数、A/B 主指标 | ds-00 0.3.7 |
| 泊松 | `stats.poisson(mu)` | `mu` | 单位时间事件数 | ds-00 0.3.7 |
| 正态 | `stats.norm` | — | 均值、误差、CLT 的极限 | ds-00 0.3.7 |
| 伯努利 | 用 `binom(1, p)` | `n=1` | 单次成败 | ds-00 0.3.7 |
| 指数 | `stats.expon` | — | 等待时间、右偏数据的教具 | 本章 4.3 |
| $t$ | `stats.t(df)` | `df` | **均值的检验与区间（小样本）** | 本章 4.4 |
| $\chi^2$ | `stats.chi2(df)` | `df` | 方差、列联表、拟合优度 | 本章 4.5 |
| $F$ | `stats.f(dfn, dfd)` | `dfn, dfd` | 方差分析、方差比 | 本章 4.5 |
| 伽马 | `stats.gamma(a)` | `a` | 等待时间之和、寿命 | 本章 4.7 |
| 对数正态 | `stats.lognorm(s)` | `s` | 收入、停留时长（右偏） | 本章 4.6 |
| 贝塔 | `stats.beta(a, b)` | `a, b` | 比例的先验/分布建模 | 本章 4.7 |
| 超几何 | `stats.hypergeom(M, n, N)` | `M, n, N` | 不放回抽样 | 本章 4.2 |

四族检验分布的均值方差与 95% 分位（实测，注意 $t$ 的方差 $=\frac{df}{df-2}$、$\chi^2$ 的方差 $=2df$）：

```
t(29)      mean=0.0     var=1.0741   ppf(0.95)=1.6991
chi2(4)    mean=4.0     var=8.0      ppf(0.95)=9.4877
F(3,20)    mean=1.1111  var=1.0802   ppf(0.95)=3.0984
expon(2)   mean=2.0     var=4.0      ppf(0.95)=5.9915
gamma(2,1) mean=2.0     var=2.0      ppf(0.95)=4.7439
```

> **机制洞察**：这四个族的共同来源是**正态样本的二次型**——样本均值服从 $t$ 分布、样本方差服从 $\chi^2$ 分布、两方差之比服从 $F$ 分布。所以 4.5 的检验能力有一个统一的前提：**数据（或它的均值）近似正态**。违背它时不是"p 值不准"这么轻，而是"5% 的显著性水平根本不是 5%"（4.5.3 实测膨胀到 66%）。

### 4.2.4 逆变换：一把均匀随机数造出任意分布

`ds-00` 0.4.3 的蒙特卡洛三步配方，第一步是"设计随机试验单元"。造出任意分布的依据是**概率积分变换**：若 $U \sim \mathrm{U}(0,1)$，则 $F^{-1}(U)$ 服从分布 $F$。scipy 的 `ppf` 就是 $F^{-1}$：

```python
>>> rng = np.random.default_rng(7)
>>> u = rng.random(200_000)
>>> x = stats.expon(scale=2).ppf(u)                # 手工逆变换
>>> x.mean()                                       # 理论均值 2
1.99791
>>> stats.expon(scale=2).rvs(200_000, random_state=np.random.default_rng(7)).mean()
1.99932
>>> r = stats.kstest(x, stats.expon(scale=2).cdf)   # 与理论分布对比
>>> round(float(r.statistic), 5), round(float(r.pvalue), 5)
(0.00204, 0.37717)
```

两边均值都贴着 2，KS 检验不显著（p = 0.38）——**自造的分布与库里的分布统计上不可区分**。这条链路还解释了两件事：为什么"任意分布都能模拟"（只要有 `ppf`），以及为什么随机数的质量只取决于 $U$ 的质量（`ds-01` 1.13 的 `Generator` 就是那个 $U$ 的来源）。

### 4.2.5 离散分布：`pmf` 才是概率

连续分布用 `pdf`，离散分布用 `pmf`——**离散分布的 `pmf` 输出直接就是概率**：

```python
>>> stats.binom(10, 0.5).pmf(6)      # 10 次抛硬币恰好 6 次正面
0.205078125
>>> stats.binom(10, 0.5).cdf(6)      # 至多 6 次正面
0.828125
>>> stats.poisson(3).pmf(3)          # 每小时平均 3 通电话，恰好 3 通
0.22404180765538775
>>> stats.poisson(3).cdf(3)          # 至多 3 通
0.6472318887822313
```

### 4.2.6 `rv_histogram`：没有分布假设时，用数据自己当分布

当数据既不正态也不是任何熟面孔，可以**把直方图直接包成分布对象**，之后照常用 `cdf`/`ppf`/`rvs`：

```python
>>> data = rng.gamma(3, 2, 5000)
>>> h = stats.rv_histogram(np.histogram(data, bins=40, density=True))
>>> h.cdf(6), (data <= 6).mean()      # 与经验 CDF 对照
(0.5668, 0.5684)
```

这是"非参数"思路的原型：**不猜分布形状，让数据说话**。4.8 的重采样三件套都是这条思路的严格版本；`rv_histogram` 的代价是**无法外推**（直方图之外没有定义）。

> **⚠️ 陷阱**：`stats.<dist>` 是**对象**（`norm_gen` 实例），不是函数。写成 `stats.norm(0, 1)` 得到的不是"标准正态的密度"，而是**冻结分布对象**——这是个特性不是 bug，但把 `stats.norm(0,1)` 当密度用会得到一串难以理解的报错。判断手里的东西：`type(stats.norm).__name__` 是 `norm_gen`，`type(stats.norm(0,1)).__name__` 是 `rv_continuous_frozen`（仅取证）。

> **延伸阅读**：分布对象的完整方法表（`moment`、`entropy`、`logpdf`、`fit`）见 [scipy.stats 连续分布](https://docs.scipy.org/doc/scipy/reference/stats.html)；概率积分变换与逆变换采样见配套文件 `ds-04b` 的随机数一章。

## 4.3 描述统计与抽样分布

### 4.3.1 一次点全：`describe` 与常用统计量

`ds-02` 的 `.describe()` 给的是透视表；`scipy` 的 `stats.describe` 给的是**统计量字典 + 正态性线索**：

```python
>>> x = np.array([2., 4., 4., 4., 5., 5., 7., 9.])
>>> d = stats.describe(x)
>>> d.nobs, d.minmax, round(float(d.mean), 4), round(float(d.variance), 4)
(8, (2.0, 9.0), 5.0, 4.5714)
>>> round(float(d.skewness), 4), round(float(d.kurtosis), 4)
(0.6562, -0.2188)
>>> np.median(x), stats.iqr(x), stats.trim_mean(x, 0.25)
(4.5, 1.5, 4.5)
```

注意 `describe` 的 `var` 用的是 **ddof=1**（$4.5714 = 32/7$），而 `skewness`/`kurtosis` 是**样本偏度与超额峰度**（正态时约 0）。`trim_mean(x, 0.25)` 表示"两端各去掉 25%"——这是 4.3.4 抗离群的主力。

### 4.3.2 ddof 口径对齐：三库三种默认

`ds-00` 0.3.5 handout 过"除以 $n$ 会系统性低估"，`ds-02` 提过 `nanmean` 的分母语义。这里给出**同一份数据的四种口径**，这是全书"数字对不上"的第一大来源：

```python
>>> np.std(x)                  # NumPy 默认 ddof=0（总体）
2.0
>>> np.std(x, ddof=1)          # 样本标准差
2.138089935299395
>>> pd.Series(x).std()         # pandas 默认 ddof=1
2.138089935299395
>>> statistics.stdev(x)        # 标准库也默认样本口径
2.138089935299395
>>> stats.sem(x)               # 标准误 = s/sqrt(n)
0.7559289460184544
>>> np.std(x, ddof=1) / np.sqrt(len(x))
0.7559289460184544
```

**口径速查表**（照抄即可）：

| 调用 | ddof | 含义 |
|------|------|------|
| `np.std(a)` / `np.var(a)` | 0 | 总体（描述这一批数据） |
| `np.std(a, ddof=1)` | 1 | 样本（估计总体波动） |
| `pd.Series(a).std()` / `.sem()` | 1 | pandas 一律样本口径 |
| `statistics.stdev(a)` | 1 | 标准库样本口径 |
| `stats.sem(a)` | 1（内部） | 均值的标准误 |
| `stats.describe(a).var` | 1 | 样本方差 |

用错口径的代价在这个例子里是 **6.46%** 的低估（2.0 对 2.13809）；样本越小时偏离越大（$n=8$ 时 $\sqrt{8/7}-1 = 6.9\%$）。**这不是"小数点后的事"**：它直接进入标准误、区间宽度与 t 统计量的分母。

> **⚠️ 陷阱**：`np.std` 与 `pd.Series.std` 的默认值**不同**（0 vs 1）。混用两者做同一份报告，会在"两组标准差"这类比较里凭空造出差异。纪律：**报告标准差时永远显式写 `ddof=1`**（或统一用 pandas 口径），不要依赖默认值。

### 4.3.3 标准误与抽样分布：CLT 的代码版

`ds-00` 0.4.2 用模拟证明了"指数分布的均值近似正态"。这里把收敛过程**量化**——看偏度与峰度随 $n$ 的下降：

| $n$ | 均值分布的均值 | 标准差 | 理论 SE $=1/\sqrt n$ | 偏度 | 超额峰度 |
|-----|--------------|--------|---------------------|------|---------|
| 1 | 1.0026 | 0.9985 | 1.0000 | +1.929 | +5.237 |
| 5 | 0.9968 | 0.4469 | 0.4472 | +0.900 | +1.090 |
| 40 | 1.0009 | 0.1582 | 0.1581 | +0.311 | +0.123 |
| 400 | 1.0004 | 0.0501 | 0.0500 | +0.063 | −0.022 |

```python
>>> for n in (1, 5, 40, 400):
...     rng = np.random.default_rng(100 + n)      # 每行一个独立种子，逐行可复现
...     means = rng.exponential(1.0, size=(20000, n)).mean(axis=1)
...     print("n=%-4d mean=%.4f sd=%.4f 理论SE=%.4f skew=%+.3f kurt=%+.3f"
...           % (n, means.mean(), means.std(ddof=1), 1/np.sqrt(n),
...              stats.skew(means), stats.kurtosis(means)))
n=1    mean=1.0026 sd=0.9985 理论SE=1.0000 skew=+1.929 kurt=+5.237
n=5    mean=0.9968 sd=0.4469 理论SE=0.4472 skew=+0.900 kurt=+1.090
n=40   mean=1.0009 sd=0.1582 理论SE=0.1581 skew=+0.311 kurt=+0.123
n=400  mean=1.0004 sd=0.0501 理论SE=0.0500 skew=+0.063 kurt=-0.022
```

（每格 20000 组重复；原始指数分布的理论偏度 2、超额峰度 6，实测 1.990 / 5.896，**不随 $n$ 改变**。）

三列数字给出 CLT 的完整信息：**中心对（1.0009 ≈ 1）、尺度对（0.1582 对理论 0.1581）、形状对（偏度从 1.93 掉到 0.31）**。$n=40$ 已经相当正态，$n=5$ 还明显右偏——这解释了为什么 4.5 的 $t$ 检验在 $n<30$ 且数据偏态时不可靠。

**SEM vs SD 的账**：

| $n$ | SD | SEM | 缩小倍数 |
|-----|----|----|---------|
| 10 | 1.000 | 0.316 | 3.2× |
| 100 | 1.000 | 0.100 | 10× |
| 1000 | 1.000 | 0.032 | 31.6× |
| 10000 | 1.000 | 0.010 | 100× |

**精度按 $\sqrt n$ 换**：想让区间窄一半，样本量要翻四倍。这条账是 4.5.8 功效计算的基础，也是"加样本"最容易被低估的代价。

### 4.3.4 稳定性 vs 抗离群：一个离群点的账

```python
>>> y = np.concatenate([x, [1000.0]])          # 8 个正常值 + 1 个离群点
>>> y.mean(), np.median(y), stats.trim_mean(y, 0.125)
(115.55555555555556, 5.0, 5.428571428571429)
>>> x.mean()
5.0
```

均值从 5.0 被拉到 115.6（**23 倍**），中位数只动了 0.5，截尾均值动 0.43。三个统计量的取舍：

| 统计量 | 抗离群 | 效率（正态时） | 什么时候用 |
|--------|--------|--------------|-----------|
| 均值 `mean` | 差 | 最高 | 分布对称、无污染，或要做线性运算 |
| 中位数 `median` | 最好 | 约 64% | 右偏数据（收入、停留时长）、有极端值 |
| 截尾均值 `trim_mean` | 好 | 高 | 既能抗离群又保留大部分效率（推荐默认） |

> **机制洞察**：`ds-00` 0.2.3 讲过 $L_2$ 与 $L_1$ 的几何差别——**均值最小化平方误差，中位数最小化绝对误差**。一个离群点的平方误差是 992016，它把均值"拽"过去才能降低总平方误差；而绝对误差只贡献 995，中位数不为所动。抗离群不是技巧，是范数选择的必然结果。

## 4.4 估计与置信区间

### 4.4.1 从点估计到区间估计

点估计回答"大概是多少"，区间回答"有多确定"。区间的一般构造（$t$ 区间）：

$$\bar x \pm t_{1-\alpha/2,\; n-1} \cdot \mathrm{SE}, \qquad \mathrm{SE} = \frac{s}{\sqrt n}$$

```python
>>> rng = np.random.default_rng(42)
>>> x = rng.normal(loc=100, scale=15, size=25)
>>> m, s, n = x.mean(), x.std(ddof=1), len(x)
>>> stats.t.interval(0.95, df=n-1, loc=m, scale=stats.sem(x))
(94.32329, 104.61504)
>>> tcrit = stats.t.ppf(0.975, df=n-1)
>>> (m - tcrit*s/np.sqrt(n), m + tcrit*s/np.sqrt(n))     # 手写一遍，确认理解
(94.32329, 104.61504)
>>> tcrit, stats.norm.ppf(0.975)                          # t 临界值 vs 正态临界值
(2.0638985616280205, 1.959963984540054)
```

要点：**小样本用 $t$ 不用正态**。$n=25$ 时 $t$ 临界值比 1.96 大 **5.3%**，用正态会让区间偏窄、第一类错误偏高。$n>100$ 之后两者差距小于 1%，可以互换（但没必要）。

### 4.4.2 比例的区间：三种算法在小样本下差别巨大

转化率这类指标不能套正态区间（Wald），因为比例的方差不独立于均值，且区间会越界：

| 样本 | 比例 | Wald（手工，不推荐） | Wilson | Wilson+连续性校正 | Clopper-Pearson（exact） |
|------|------|--------------------|--------|------------------|------------------------|
| 3/20 | 0.150 | **(-0.0065, 0.3065)** | (0.0524, 0.3604) | (0.0396, 0.3886) | (0.0321, 0.3789) |
| 30/100 | 0.300 | (0.2102, 0.3898) | (0.2189, 0.3958) | (0.2145, 0.4011) | (0.2124, 0.3998) |
| 300/1000 | 0.300 | (0.2716, 0.3284) | (0.2724, 0.3291) | (0.2719, 0.3296) | (0.2717, 0.3295) |

```python
>>> ci = stats.binomtest(3, 20).proportion_ci(0.95, method="wilson")   # 返回 ConfidenceInterval 对象
>>> round(float(ci.low), 4), round(float(ci.high), 4)
(0.0524, 0.3604)
>>> ci = stats.binomtest(3, 20).proportion_ci(0.95, method="exact")
>>> round(float(ci.low), 4), round(float(ci.high), 4)
(0.0321, 0.3789)
```

三条结论：

- **Wald 在小样本/极端比例下越界**（3/20 的下限 −0.0065，概率不可能为负）——这就是"不要用 $p \pm 1.96\sqrt{p(1-p)/n}$"的原因；
- **大样本时四者几乎重合**（300/1000 只差小数点后第三位），所以"用哪个"只在 $np<5$ 或样本很小时才要紧；
- **`proportion_ci` 只有 `exact`/`wilson`/`wilsoncc`**（版本注意④）。要 Wald 只能自己算，而它恰恰是最不该用的那个。**默认推荐 Wilson**：不越界、覆盖率高、计算简单。

### 4.4.3 bootstrap 区间：没有公式时的通用解

`ds-01` 1.13.4 给了重抽样原语，1.13.5 手工算出过 `[47.41, 47.56]`。这里用 `stats.bootstrap` 把它严格化——**它同时给区间、标准误和完整的重抽样分布**：

```python
>>> rng = np.random.default_rng(42)
>>> data = rng.exponential(scale=3.0, size=60)      # 右偏数据
>>> for meth in ("percentile", "basic", "BCa"):
...     r = stats.bootstrap((data,), np.mean, n_resamples=9999, method=meth,
...                         confidence_level=0.95, rng=np.random.default_rng(1))
...     print(meth, round(r.confidence_interval.low, 4), round(r.confidence_interval.high, 4))
percentile 1.9028 3.1205
basic 1.8180 3.0357
BCa 1.9448 3.1965
>>> stats.t.interval(0.95, len(data)-1, data.mean(), stats.sem(data))   # 解析对照
(1.84606, 3.09242)
```

三种方法的区别：

| 方法 | 原理 | 偏态/小样本表现 | 建议 |
|------|------|---------------|------|
| `percentile` | 直接取重抽样分布的 2.5%/97.5% 分位 | 对偏态有偏 | 快速看量级 |
| `basic` | 用"观测值 − 分位"反推（枢轴法） | 与 percentile 镜像 | 少用 |
| **`BCa`** | 校正偏差与偏度（默认） | 最好 | **默认选它** |

返回对象是 dataclass（仅取证），三个字段各有用途：

```python
>>> r = stats.bootstrap((data,), np.mean, n_resamples=9999, method="BCa",
...                     rng=np.random.default_rng(1))
>>> r.confidence_interval          # 区间本体（.low / .high）
>>> r.standard_error               # 0.3107，bootstrap 版标准误
>>> r.bootstrap_distribution.shape # (9999,) —— 重抽样分布，可直接画图
(9999,)
```

**bootstrap 的主场是"没有解析公式的统计量"**。均值有 $t$ 公式，中位数没有，相关系数的区间也不是随手可得：

```python
>>> r = stats.bootstrap((data,), np.median, n_resamples=9999, method="BCa",
...                     rng=np.random.default_rng(1))
>>> round(r.confidence_interval.low, 4), round(r.confidence_interval.high, 4)
(1.0631, 2.7036)
```

中位数的区间比均值宽得多（1.06–2.70 对 1.90–3.12），正好对应 4.3.4 的效率损失——**抗离群的代价是精度**。

### 4.4.4 覆盖率的实测：95% 到底是什么意思

"95% 置信区间"的正确读法是：**如果无限重复抽样并每次构造区间，约 95% 的区间会包含真值**。用模拟验证（真值 100，$n=25$，2000 次重复）：

| 方法 | 实测覆盖率 |
|------|-----------|
| 解析 $t$ 区间 | **95.5%** |
| bootstrap（percentile，999 次） | 93.5% |
| bootstrap（BCa，999 次） | 93.8% |

（蒙特卡洛误差约 ±0.5 个百分点。）

两个反直觉的结论：

1. **bootstrap 不是万能的**。$n=25$、分布对称时，解析 $t$ 区间覆盖率最准；percentile 与 BCa 都偏窄约 1.5 个百分点。原因是均值的 bootstrap 分布本身有偏，n 小时偏差补不回来。
2. **"95% 概率包含真值"是错的说法**（频率派语义下，真值是固定的，区间是随机的）。但工程上更该记住的是：**覆盖率是方法属性，不是单次结论的属性**——你手上这一个区间，要么包含要么不包含，95% 说的是产生它的**流程**。

> **⚠️ 陷阱**：**不要用 bootstrap 区间来判断"是否显著"**，除非你清楚它的口径。percentile 区间与检验的对偶性在大样本成立，小样本下会与解析检验打架（区间不含 0 但 p>0.05，或反之）。真要报"显著性"，用 4.5 的检验；bootstrap 负责报**精度**。

### 4.4.5 区间报告模板

一条能贴进任何报告的模板：

```
指标：实验组转化率
点估计：4.63%（463/10000）
区间：  [4.24%, 5.06%]（Wilson 95%）
对照：  3.60%（360/10000），[3.25%, 3.98%]
差值：  +1.03pp（+28.6% 相对），[+0.49pp, +1.58pp]（BCa 9999 次 bootstrap）
方法：  两独立比例，Wilson 区间与 z 检验（p = 0.00024）；n 各 10000
```

四个必须出现的元素：**点估计 + 区间 + 方法（含 n）+ 对照**。只写"提升了 28.6%"是描述统计；写上区间与方法才是统计结论。

## 4.5 假设检验：p 值的完整语义

### 4.5.1 检验的四个零件与 p 值的定义

一次检验由四样东西组成：**统计量**（把数据压成一个数）、**原假设 $H_0$**、**零分布**（$H_0$ 成立时统计量的分布）、**判定规则**（$p < \alpha$ 则拒绝 $H_0$）。

**p 值的定义**：在 $H_0$ 成立的前提下，观察到"当前这么极端或更极端"的统计量的概率。它最重要的性质可以直接模拟出来——**$H_0$ 为真时，p 值服从 $\mathrm{U}(0,1)$**：

```python
>>> rng = np.random.default_rng(0)
>>> ps = np.array([stats.ttest_ind(rng.normal(0,1,20), rng.normal(0,1,20)).pvalue
...                for _ in range(20000)])
>>> (ps < 0.05).mean(), ps.mean()
(0.0505, 0.5009)
>>> stats.kstest(ps, "uniform").pvalue
0.6916
```

三行输出把 p 值的全部语义讲完了：

- **$p<0.05$ 的比例正好是 5%**（0.0505）——所以"显著"这个词的默认含义就是"$\alpha=0.05$ 下拒绝 $H_0$"，它**不衡量效应大小**；
- **p 的均值是 0.5**，分布均匀——所以 $p=0.03$ 与 $p=0.30$ 在 $H_0$ 下的出现概率都是"可能的"，**p 值本身不是效应量的度量**；
- KS 检验不显著（p = 0.69）——均匀性本身就是零分布的定义。

> **机制洞察**：p 值不是"$H_0$ 为真的概率"，也不是"结论错误的概率"。它是 **"假设 $H_0$ 为真，看到这组数据的（尾部）概率"** 。方向不能反：$P(\text{数据}|H_0) \ne P(H_0|\text{数据})$——这正是 4.5.9 要反复强调的"报告纪律"的数学根源。

### 4.5.2 三兄弟与它们的前提

| 检验 | 场景 | 前提 |
|------|------|------|
| `ttest_1samp` | 一组数据 vs 已知常数 | 近似正态或 $n$ 大 |
| `ttest_ind` | 两组独立样本 | 近似正态 +（Student 版）方差齐性 |
| `ttest_rel` | 配对样本（同一个人前后测） | 差值近似正态 |

```python
>>> rng = np.random.default_rng(2)
>>> a = rng.normal(0, 1, 25); b = rng.normal(0.6, 1, 25)
>>> r = stats.ttest_ind(a, b)                   # 两组独立
>>> round(float(r.statistic), 4), round(float(r.pvalue), 5), float(r.df)
(-2.3432, 0.02331, 48.0)
>>> rng = np.random.default_rng(3)
>>> before = rng.normal(0, 1, 20); after = before + rng.normal(4.0, 1.0, 20)
>>> r = stats.ttest_rel(after, before)          # 配对
>>> round(float(r.statistic), 4), float(r.pvalue), float(r.df)
(16.3599, 1.184856167712727e-12, 19.0)
```

配对与独立的选择会改变结论的量级：同样的"提升"在配对设计里往往更显著，因为**它消掉了个体差异**。判断依据只有一条：**同一个人/同一个实验单元测了两次 → 配对**；两组不同的人 → 独立。

### 4.5.3 Welch vs Student：方差齐性不是小事

`ttest_ind` 默认 `equal_var=True`（Student），但**方差不同且样本量不等时，它的 $\alpha$ 根本不是 5%**。20000 次重复的实测：

| 样本量 | 标准差 | Student 第一类错误 | Welch 第一类错误 |
|--------|--------|------------------|----------------|
| (20, 20) | (1, 1) | 5.05% | 5.03% |
| (10, 50) | (1, 5) | **0.01%** | 5.00% |
| (10, 50) | (5, 1) | **35.84%** | 5.21% |
| (5, 100) | (1, 10) | **0.00%** | 4.83% |
| (5, 100) | (10, 1) | **66.63%** | 4.78% |

规律很清楚：**大方差的那组样本量更小时，Student 检验极度膨胀**（最坏到 66.63%，名义 5% 的 13 倍）；反之过度保守（0.01%，几乎检不出任何东西）。而 **Welch（`equal_var=False`）在所有组合下都稳在 5% 附近**。

> **⚠️ 陷阱**：**默认就用 Welch**。`scipy` 的默认是 Student（为了历史兼容），而 Welch 在方差齐时几乎不损失功效（第一行 5.03% vs 5.05%），在不齐时救命。写法：`stats.ttest_ind(a, b, equal_var=False)`。这条建议与 R 的 `t.test` 默认（Welch）相反于 scipy 默认，迁移代码时务必显式传参。

### 4.5.4 非参数族：能力与代价

当数据明显偏态或有离群点时，秩检验是主力：`mannwhitneyu`（两独立）、`wilcoxon`（配对）、`kruskal`（多组）、`ranksums`（大样本近似）。

**偏态数据下的功效对照**（指数分布，$n=30$/组，5000 次重复）：

| 均值偏移 | $t$ 检验功效 | Mann-Whitney 功效 |
|---------|------------|------------------|
| 0.0（$H_0$ 为真） | 5.2% | 5.0% |
| 0.3 | 22.3% | **40.5%** |
| 0.6 | 66.0% | **87.0%** |
| 1.0 | 95.7% | **99.6%** |

$H_0$ 下两者都守在 5%（第一类错误没坏），但在备择下 **Mann-Whitney 的功效高了近一倍**——因为 $t$ 检验被少数极端值放大的方差拖累，而秩检验只看排序。

**代价一：离群点的身份变了，结论就变了**。三种方法在"10% 的点被污染"（真实无差异，5000 次重复）下的第一类错误：

| 方法 | 第一类错误 |
|------|-----------|
| 普通 $t$ | 1.4% |
| $t$（`trim=0.1`） | 7.5% |
| Mann-Whitney | 7.9% |

这里的结论与"非参数更稳"的直觉相反，机制值得看穿：**污染点把 $t$ 检验的分母（合并方差）撑大，于是它变得极度保守（1.4%）**；而截尾均值在切掉污染点的同时**也切掉了低端正常值**，造成向上的偏移（7.5%）；秩检验则让 3 个极端点占据最高秩，同样带来偏移（7.9%）。

> **结论**：**离群点处理的第一步永远是判断它的身份**（录入错误？单位错？真实的极端个体？），而不是无脑换检验。删掉错误数据后回到 $t$ 检验，往往比"用一个抗离群的检验去适应脏数据"更正确。

### 4.5.5 多组比较与事后检验

三组及以上用单因素方差分析 `f_oneway`；显著之后必须做事后比较（否则又是多重比较问题）：

```python
>>> rng = np.random.default_rng(0)
>>> g = [rng.normal(mu, 1.0, 30) for mu in (0.0, 0.2, 0.9, 1.5)]
>>> [round(float(x.mean()), 3) for x in g]
[-0.121, 0.476, 1.075, 1.496]
>>> aov = stats.f_oneway(*g)
>>> round(aov.statistic, 3), aov.pvalue
(16.267, 6.86e-09)
>>> tk = stats.tukey_hsd(*g)
>>> np.round(tk.pvalue[np.triu_indices(4, 1)], 4)      # 6 个两两比较
array([0.0799, 0.    , 0.    , 0.0792, 0.0004, 0.3278])
>>> stats.dunnett(*g[1:], control=g[0]).pvalue          # 都跟第 1 组比
array([0.0459, 0.    , 0.    ])
```

要点：ANOVA 显著只说明"至少有一组不同"；**两两比较要用 `tukey_hsd`（控制 FWER）或 `dunnett`（只跟对照比，更省功效）**，而不是直接跑 6 次 t 检验。6 个 p 值按 `(0,1) (0,2) (0,3) (1,2) (1,3) (2,3)` 排列，最后一个 0.3278 说明**第 3、4 组之间没有差异**——ANOVA 显著并不等于每一对都显著。

### 4.5.6 列联表与卡方

两个分类变量的关系用 `chi2_contingency`（4.9 的 A/B 主指标就是它）：

```python
>>> tab = np.array([[360, 9640], [463, 9537]])
>>> chi2, p, dof, expected = stats.chi2_contingency(tab, correction=False)
>>> round(chi2, 3), p, dof
(13.444, 0.000246, 1)
>>> expected.min()          # 卡方前提：所有期望频数 >= 5
411.5
```

**前提只有一条但很硬**：所有格子期望频数 $\ge 5$（实测这里最小 411.5——两组样本量各 10000，远高于门槛）。小样本或稀疏表改用 `fisher_exact`（2×2 精确检验）。另外注意 `correction=True`（默认）会做 Yates 连续性校正，样本量大时与不校正几乎无差别，小样本时更保守——**报告里要写清用了哪个**。

### 4.5.7 多重比较：FWER 与 FDR

**问题有多大**：20 个独立检验、真值全为 $H_0$，重复 5000 次的实测——

| 策略 | 至少一次假阳性的比例 |
|------|-------------------|
| 不校正 | **63.7%**（理论 $1-0.95^{20} = 64.2\%$） |
| Bonferroni（$\alpha/m$） | 5.1% |
| Holm（逐步 Bonferroni） | 5.1% |

**不做校正就有一半以上的概率得到至少一个"显著"结果"**——这就是 p-hacking 的统计学引擎。

代价的对照（100 个检验、其中 20 个真有效应、30 样本/组、2000 次重复）：

| 策略 | 平均拒绝数 | 假阳性 | 真阳性（共 20） | 假发现比例 |
|------|-----------|--------|---------------|-----------|
| 不校正 | 23.9 | 4.02 | 19.9 | **0.17** |
| Bonferroni | 16.5 | 0.04 | 16.4 | 0.00 |
| **BH-FDR** | 20.3 | 0.87 | **19.5** | **0.04** |

- **Bonferroni/Holm 控制 FWER**（"一次都不错"），代价是漏检：20 个真效应只找到 16.4 个；
- **Benjamini-Hochberg 控制 FDR**（"错的比例不超过 5%"），在探索性研究里是更好的默认：找到 19.5 个真效应，假发现率 4%。

```python
>>> ps = np.array([0.001, 0.01, 0.02, 0.2, 0.5])
>>> np.round(stats.false_discovery_control(ps), 4)    # BH，输入原始 p，输出校正后 p
array([0.005 , 0.025 , 0.0333, 0.25  , 0.5   ])
```

选择口诀：**确证性结论（要上线、要发文）→ FWER（Holm/Tukey）；探索性筛选（找候选）→ FDR（BH）**。注意 `stats.multicomp` 已移除（版本注意①），事后两两比较用 `tukey_hsd`/`dunnett`，通用的多假设校正用 `false_discovery_control`。

### 4.5.8 功效与样本量：别再"跑完再说"

**功效（power）** $= 1-\beta$ = 备择假设为真时正确拒绝 $H_0$ 的概率。它由四件事决定：效应量、样本量、$\alpha$、数据波动。经典的 80% 功效意味着"真有差异时，五次里能抓到四次"。

SciPy 1.18 提供的是**模拟法**（版本注意②）：给它检验函数、两组数据的生成器、样本量和 $\alpha$，它直接把功效模拟出来：

```python
>>> rvs = [lambda size, rng: rng.normal(0, 1, size),
...        lambda size, rng: rng.normal(0.5, 1, size)]
>>> r = stats.power(stats.ttest_ind, rvs, n_observations=[30, 30], significance=0.05,
...                 n_resamples=3000, batch=1000, kwargs={"rng": np.random.default_rng(3)})
>>> round(r.power, 3)
0.461
```

对照自写模拟（0.479）与理论曲线，一致。三个必须注意的细节：

1. **默认 `significance=0.01`**，不是 0.05——不显式传参会得到偏低的功效，这是最容易踩的坑；
2. **随机源通过 `kwargs={"rng": ...}` 传**给 `rvs`，由它决定可复现性；
3. 它不接受 `rng=` 关键字（那是 `bootstrap`/`permutation_test` 的接口）。

**功效曲线**（自模拟 4000 次，$d=0.5$）：

| $n$/组 | 10 | 20 | 30 | 50 | 64 | 100 |
|--------|----|----|----|----|----|-----|
| 功效 | 0.181 | 0.335 | 0.476 | 0.699 | 0.795 | 0.938 |

**达到 80% 功效的最小 $n$ = 65/组**，与经典公式给出的 64 吻合。这就是"实验设计"该在跑数之前做的事：**先定 MDE，再定样本量**。

反过来看"显著 ≠ 重要"最直观的一张表——固定一个**微小**效应（真实均值差 0.75 分，标准差 15 分，$d = 0.05$）：

| $n$/组 | 25 | 100 | 400 | 1600 | 6400 |
|--------|----|-----|-----|------|------|
| 检出率 | 5.0% | 5.8% | 11.6% | 28.0% | **79.3%** |

同一个"0.75 分的差异"，$n=25$ 时几乎检不出，$n=6400$ 时接近必检出。**p 值是"效应大小 × 样本量"的函数**，所以永远要配着效应量一起报。

效应量速算（两独立组）：

```python
>>> pooled = np.sqrt(((n1-1)*s1**2 + (n2-1)*s2**2) / (n1 + n2 - 2))
>>> cohens_d = (m2 - m1) / pooled
```

经验尺子：$d \approx 0.2$ 小、$0.5$ 中、$0.8$ 大；比例的对应量是 Cohen's $h$（4.9 会给）。

### 4.5.9 报告纪律

七条，按重要性排序：

1. **先看图再检验**（`ds-03` 3.7 的容器总表选图）；
2. **报效应量 + 区间**，不只报 p；
3. **说清前提**：正态性、方差齐性、独立性、配对结构；
4. **说清多重性**：做了几个检验、怎么校正的；
5. **不做事后改假设**（单双侧、剔除规则、指标定义都要事先定）；
6. **区分统计显著与业务显著**（0.1pp 的转化率提升在 $n=10^6$ 时"显著"）；
7. **报样本量**（$n$ 决定一切精度）。

**随堂自测 4.5**

1. $H_0$ 为真时 p 值服从什么分布？用它解释"$p=0.04$ 不值得庆祝"。
2. 为什么建议默认用 Welch 而不是 Student？各举一个它救命的场景。
3. 20 个指标都不校正，至少一个假阳性的概率是多少？怎么算出来的？
4. 功效 80%、$d=0.5$、$\alpha=0.05$ 时大概需要多少样本/组？如果只想检出 $d=0.25$ 呢？

**本节交付**：检验选型表 + 多重比较与功效口径，进入 4.6–4.9 的全部分析。

## 4.6 相关与回归的第一层

### 4.6.1 三种相关系数：衡量的是三件不同的事

| 系数 | 衡量 | 前提 | 抗离群 | 单调非线性 |
|------|------|------|--------|-----------|
| `pearsonr` | **线性**关联强度 | 线性、近似正态、无极端值 | 差 | 看不出来 |
| `spearmanr` | **单调**关联强度 | 单调关系 | 好 | 完全看得出 |
| `kendalltau` | 一致对比例（秩序相关） | 单调关系 | 很好 | 完全看得出 |

```python
>>> rng = np.random.default_rng(7)
>>> x = rng.normal(0, 1, 60); y = 2.5*x + rng.normal(0, 1.5, 60)
>>> round(stats.pearsonr(x, y).statistic, 4), round(stats.spearmanr(x, y).statistic, 4), round(stats.kendalltau(x, y).statistic, 4)
(0.8766, 0.8558, 0.6689)
```

线性关系下三者都给出正相关（Kendall 的数值天然更小，因为它是"一致对比例"而非方差归一）。换成**单调非线性**：

```python
>>> z = np.exp(x)                       # 与 x 严格单调，但完全非线性
>>> round(stats.pearsonr(x, z).statistic, 4)
0.8398
>>> round(stats.spearmanr(x, z).statistic, 4), round(stats.kendalltau(x, z).statistic, 4)
(1.0, 1.0)
```

**Spearman/Kendall 精确等于 1**（$x$ 与 $\exp(x)$ 的顺序完全一致），而 Pearson 只有 0.84。再看一个离群点：

```python
>>> x2 = np.concatenate([x, [15.0]]); y2 = np.concatenate([y, [0.0]])
>>> round(stats.pearsonr(x2, y2).statistic, 4), round(stats.spearmanr(x2, y2).statistic, 4)
(0.3904, 0.8451)
```

Pearson 从 0.88 崩到 **0.39**，Spearman 几乎不动（0.8558 → 0.8451）。

> **⚠️ 陷阱**：**Pearson 小不等于没有关系**（可能是非线性的），**Spearman 大不等于线性**（不能拿它当回归的依据）。报告相关时写清用了哪个系数、为什么——先画散点图（`ds-03` 3.6）是唯一能防止"用错系数"的办法。

### 4.6.2 `linregress`：一元线性回归的最小完整集

```python
>>> lr = stats.linregress(x, y)
>>> list(lr._fields)
['slope', 'intercept', 'rvalue', 'pvalue', 'stderr']
>>> round(lr.slope, 4), round(lr.intercept, 4), round(lr.rvalue, 4), lr.pvalue, round(lr.stderr, 4)
(2.5886, -0.1067, 0.8766, 4.5e-20, 0.1866)
>>> round(lr.intercept_stderr, 4)
0.1691
```

五个字段各有用途：`slope`/`intercept` 是点估计，`stderr` 是**斜率的标准误**，`pvalue` 是"斜率 = 0"的检验，`rvalue` 就是 Pearson（所以 `rvalue**2` = $R^2$）。**斜率区间要自己算**（1.18 的 `LinregressResult` 没有 `confidence_interval` 方法）：

```python
>>> tcrit = stats.t.ppf(0.975, len(x) - 2)
>>> (round(lr.slope - tcrit*lr.stderr, 4), round(lr.slope + tcrit*lr.stderr, 4))
(2.215, 2.9621)
```

自由度是 $n-2$（估计了两个参数）——这是 4.3.2 之外第二个容易搞错的自由度来源。

### 4.6.3 稳健回归：一个离群点的斜率账

```python
>>> x2 = np.concatenate([x, [15.0]]); y2 = np.concatenate([y, [0.0]])
>>> ols = stats.linregress(x2, y2); ts = stats.theilslopes(y2, x2, 0.95)
>>> print("OLS %.4f (CI %.4f~%.4f)" % (ols.slope, ols.slope - tcrit*ols.stderr, ols.slope + tcrit*ols.stderr))
OLS 0.4758 (CI 0.1835~0.7681)
>>> print("Theil-Sen %.4f (CI %.4f~%.4f)" % (ts.slope, ts.low_slope, ts.high_slope))
Theil-Sen 2.5683 (CI 2.1514~2.9151)
>>> round(stats.siegelslopes(y2, x2).slope, 4)
2.5818
```

真值 2.5：OLS 被一个点拉成 **0.476**，Theil-Sen（所有点对斜率的中位数）稳在 **2.568**，Siegel（重复中位数法）2.582。这是 4.3.4"中位数抗离群"在回归上的翻版。

### 4.6.4 相关 ≠ 因果：辛普森悖论

构造：两组内部斜率都是 $-1$，但两组整体位置差很大，合并后斜率变正。

| 分组 | 斜率 | Pearson | $n$ | 组内均值 |
|------|------|---------|-----|---------|
| 合并全部 | **+0.171** | +0.3878（p = 0.00038） | 80 | — |
| 组 0 | −1.051 | −0.8280 | 40 | x̄=−0.40, ȳ=0.41 |
| 组 1 | −1.100 | −0.8236 | 40 | x̄=5.76, ȳ=2.07 |

**合并看是正相关且显著，分组看两组都是强负相关**。机制：分组变量（组别）同时影响 $x$ 与 $y$，是**混杂因子**。这不是罕见病——用户分层、地区、时间窗都可能制造同样的反转。

> **结论**：看到相关先问三个问题——**有没有第三个变量同时影响两者？要不要分层看？分层后符号会不会翻转？**（这就是"相关不代表因果"的可操作版本。）

### 4.6.5 相关矩阵的多重比较

一次算 99 个相关系数（全部真无关，seed=7 的 200×100 独立正态矩阵）的实测：

```
p<0.05 的个数            = 4      （期望约 5）
BH-FDR 校正后仍显著       = 0
```

## 4.7 分布拟合与正态性

### 4.7.1 正态性检验族：先看它们的脾气

四个常用的正态性检验，同一批数据的实测对照（seed=11）：

| 数据 | `shapiro` p | `normaltest` p | `kstest` p | Anderson-Darling $A^2$ / 5% 临界 |
|------|-------------|----------------|------------|--------------------------------|
| 标准正态 $n=50$ | 0.6728 | 0.5858 | 0.9614 | 0.213 / 0.740 |
| 标准正态 $n=5000$ | 0.1260 | 0.3442 | 0.6061 | 0.734 / 0.752 |
| 轻微右偏 $n=50$ | 7.03e−06 | 1.30e−07 | 0.0162 | 2.435 / 0.740 |
| 轻微右偏 $n=5000$ | 9.83e−28 | 2.05e−67 | 3.28e−10 | 24.707 / 0.752 |
| 指数 $n=200$ | 1.73e−13 | 2.69e−15 | 0.000284 | 8.808 / 0.749 |

三个要点：

1. **样本量决定灵敏度**。同一个"轻微右偏"，$n=50$ 与 $n=5000$ 的 p 值差 20 多个数量级。**大样本下几乎任何真实数据都会"非正态"**——这时该看的是**偏离的方向与幅度**（偏度、峰度、QQ 图），不是 p 值；
2. **`shapiro` 与 `normaltest` 结论一致**（都在检验偏度+峰度），`kstest` 对中等偏离不敏感（0.0162 对 7e−06）；
3. **Anderson-Darling 给的是统计量与临界值表**，不是 p 值——它更看重尾部（对尾部偏离敏感，正态性检验里通常最有力）。

### 4.7.2 Lilliefors 陷阱：用估计参数做 KS 检验会彻底失效

这是本章最值得记住的一个实测结论。KS 检验的原假设是"数据来自**完全指定**的分布"。如果参数是从同一批数据估出来的，零分布就变了：

```python
# 数据本来就是 N(0,1)，参数却用样本均值/标准差估计（n=50，5000 次重复）
H0 为真、名义 5% 下，kstest 的实际拒绝率 = 0.04%
观测 D 的 95 分位 = 0.1234
标准 KS 临界值(n=50, α=0.05) ≈ 0.1921
对照：参数完全已知（0,1）时拒绝率 = 5.38%（正常）
```

**名义 5%、实际 0.04%**——参数是照数据"裁剪"出来的，$D$ 被系统性压小，于是检验几乎永不拒绝。这被称为 **Lilliefors 问题**：需要 Lilliefors 校正表，或者干脆改用 `shapiro`/`normaltest`（它们的零分布已经把"参数估计"的代价算进去了）。

| 用途 | 正确做法 |
|------|---------|
| 检验"数据是否来自**已知**分布"（参数事先给定） | `kstest` ✓ |
| 检验"数据是否正态" | `shapiro` / `normaltest` / `anderson` ✓ |
| 检验"数据是否来自某族分布（参数待估）" | `stats.fit` + 模拟 p 值（4.7.4），**不要**用原始 `kstest` |

> **⚠️ 陷阱（版本相关）**：SciPy 1.18.1 里 **`kstest(x, "norm", args=(loc, scale))` 会直接抛 `TypeError`**（`ndtr() takes from 1 to 2 positional arguments but 3 were given`），而 `kstest(x, "norm")` 与其他分布的 `args` 都正常。稳妥写法是传冻结分布的 CDF：`stats.kstest(x, stats.norm(loc=m, scale=s).cdf)`。

### 4.7.3 `anderson` 的新 API

版本注意③的完整样子：

```python
>>> stats.anderson(x, dist="norm")                       # 旧写法
FutureWarning: As of SciPy 1.17, users must choose a p-value calculation
method by providing the `method` parameter. ... Beginning in 1.19.0, these
other attributes will no longer be available ...
>>> a = stats.anderson(x, dist="norm", method="interpolate")   # 新写法，无警告
>>> a.statistic, a.pvalue
(0.3197713795798336, 0.15)
```

**新代码一律写 `method=`**：`method="interpolate"` 从预计算表插值出 p 值；也可以传 `MonteCarloMethod` 实例用模拟法。旧属性 `.critical_values`/`.significance_level` 在 1.19 会消失——现在不迁移，将来会集中爆雷。

### 4.7.4 `stats.fit`：带约束的 MLE 拟合

```python
>>> data = rng.gamma(2.5, 1.7, 500)
>>> r = stats.fit(stats.gamma, data, bounds={"a": (1e-3, 10), "loc": (-5, 5), "scale": (1e-3, 10)})
>>> [f for f in ("params", "nllf", "success", "message") if hasattr(r, f)]
['params', 'nllf', 'success', 'message']
>>> {k: round(float(v), 4) for k, v in r.params._asdict().items()}
{'a': 2.3578, 'loc': -0.0652, 'scale': 1.8146}
```

真值是 $a=2.5$、$loc=0$、$scale=1.7$，$n=500$ 时估到 2.358/−0.065/1.815——量级正确，但 $a$ 与 $scale$ 高度相关，单看一个参数容易误判。四个必须知道的点：

1. **`bounds` 不是可选的礼貌参数，而且"不报错"不代表"拟合成功"**。实测（`ds-04b` S6.3）：对正态数据调用 `stats.fit(stats.norm, data)` **不给 bounds**，返回的是初值 `loc=0, scale=1`，`nllf = 4033.66`；而真 MLE 的 `nllf` 只有 713.54——**差了 5.7 倍，但 `success` 仍然是 `True`**。显式给无限 bounds 会直接抛 `ValueError`；有形状参数的分布（`gamma`/`t`/`beta`）连"不给"都会报错。结论：**给宽但有限的 bounds，并且事后永远检查 `nllf()`**；
2. **默认优化器是 `differential_evolution`**（全局优化，见第 5 章），因为似然面常有多个局部极大——这解释了为什么一次 `fit` 比一次 `describe` 慢几个数量级，也意味着**起点几乎不影响结果**（同一数据从 `a=1` 与 `a=9` 出发得到完全相同的解）；
3. **`nllf` 是方法不是属性**（版本细节）：`hasattr(r, "nllf")` 为真，但要写 `r.nllf()` 才拿到数值；
4. **拟合完之后不要再拿原分布做 KS 检验**（回到 4.7.2）：参数估计过的拟合优度必须用模拟零分布（`ds-04b` S6.6 给出校准骨架）。

| 数据 | QQ 点与理论直线的 $r$ |
|------|---------------------|
| 正态 | **0.9978** |

### 4.7.6 变换到正态：Box-Cox 与 Yeo-Johnson

```python
>>> skewed = rng.lognormal(0, 1, 500)
>>> stats.skew(skewed), stats.shapiro(skewed).pvalue
(3.561, 4e-30)
>>> bc, lam = stats.boxcox(skewed)
>>> round(lam, 4), round(stats.skew(bc), 3), round(stats.shapiro(bc).pvalue, 3)
(0.0059, -0.0, 0.924)
>>> yj, lam2 = stats.yeojohnson(skewed)
>>> round(lam2, 4), round(stats.skew(yj), 3), round(stats.shapiro(yj).pvalue, 4)
(-0.8718, 0.133, 6.45e-06)
```

- **Box-Cox 只能用于正值**（遇到非正值直接 `ValueError: Data must be positive.`），本例把偏度 3.56 打到 0.00、Shapiro p 从 4e−30 升到 0.924；
- **Yeo-Johnson 允许非正值**（它是 Box-Cox 的双参数推广），但在同一份数据上表现略差（偏度 0.133）——**没有免费的午餐，用之前两个都试**；
- **变换的目的是满足检验/建模的前提，不是"让数据好看"**。变换后要重新解释参数（斜率、均值都不再是原尺度），报告里必须写清用了什么变换、$\lambda$ 是多少。

## 4.8 重采样三件套：不靠公式的推断

`ds-00` 0.4.3 给了蒙特卡洛三步配方，`ds-01` 1.13.4 给了两个原语（有放回重抽、打乱标签）。本节把它们闭合。

### 4.8.1 `permutation_test`：三种重排，三种假设

`permutation_type` 决定了"打乱什么"，用错就会得到荒谬的结果：

| 类型 | 打乱什么 | 适用 | 统计量要求 |
|------|---------|------|-----------|
| `independent` | 组标签（把观测重新分配） | 两组独立比较 | 任意，常用均值差 |
| `samples` | 配对内部的符号/归属 | 配对/重复测量 | 定义在配对差值上 |
| `pairings` | 两变量的配对关系 | **相关/关联**检验 | 依赖配对，如相关系数 |

```python
>>> rng = np.random.default_rng(2)
>>> a = rng.normal(0, 1, 25); b = rng.normal(0.6, 1, 25)
>>> f = lambda x, y: x.mean() - y.mean()
>>> r = stats.permutation_test((a, b), f, permutation_type="independent",
...                            n_resamples=9999, rng=np.random.default_rng(1))
>>> round(r.pvalue, 4), round(stats.ttest_ind(a, b).pvalue, 4)
(0.0224, 0.0233)                          # 与解析 t 检验几乎一致
```

配对设计要用 `samples`（实现即符号翻转）：

```python
>>> rng = np.random.default_rng(4)
>>> before = rng.normal(0, 1, 20); after = before + rng.normal(4.0, 1.0, 20)
>>> r = stats.permutation_test((after, before), lambda x, y: (x - y).mean(),
...                            permutation_type="samples", n_resamples=9999,
...                            rng=np.random.default_rng(1))
>>> round(float(r.statistic), 4), float(r.pvalue)
(3.7944, 0.0002)
>>> stats.ttest_rel(after, before).pvalue
5.010741533618869e-13
```

注意这里的 **p 值下限**：9999 次重排能给出的最小非零 p 是 $1/10000 = 0.0001$，所以强效应下置换检验只能报到 0.0002，而解析 t 检验能给到 $10^{-13}$。**这是分辨率问题，不是矛盾**（见 4.8.5）。

**误用的样子**（同一份配对数据，错用 `pairings`）：

```python
>>> bad = stats.permutation_test((after, before), f, permutation_type="pairings",
...                              n_resamples=9999, rng=np.random.default_rng(1))
>>> float(bad.pvalue), len(np.unique(bad.null_distribution)), float(np.ptp(bad.null_distribution))
(1.0, 5, 2.6645352591003757e-15)
```

`p = 1.0`、零分布"有 5 个取值"但**极差只有 $2.7\times10^{-15}$**——它们其实是同一个数，差异只来自浮点求和顺序。原因很直白：**`pairings` 重排的是"配对关系"，而均值差不依赖配对关系**（每个样本内部的观测被重新配对，样本均值不变），所以所有重排都得到同一个统计量，p 自然等于 1。这条陷阱的价值在于：**看到 p 恰好等于 1 或 0，第一反应应该是"统计量在置换下不变/全变"，而不是"结果太极端"**。

### 4.8.2 `bootstrap`：给任意统计量配区间

4.4.3 已经用过。这里补充它的定位——**bootstrap 与置换检验是互补的**：

| | 置换检验 `permutation_test` | bootstrap |
|---|---|---|
| 打乱什么 | 标签/配对（**破坏关联**） | 有放回重抽（**模拟抽样**） |
| 回答的问题 | "这个关联是真的吗"（检验） | "这个估计有多准"（区间/SE） |
| 零假设 | 明确需要（可交换性） | 不需要 |
| 主要产出 | p 值 | 区间、标准误、分布 |

```python
>>> x = rng.normal(0, 1, 80); y = 0.7*x + rng.normal(0, 1, 80)
>>> r = stats.bootstrap((x, y), lambda u, v: stats.pearsonr(u, v).statistic,
...                     paired=True, n_resamples=9999, method="BCa",
...                     rng=np.random.default_rng(3), vectorized=False)
>>> round(stats.pearsonr(x, y).statistic, 4), (round(r.confidence_interval.low, 4), round(r.confidence_interval.high, 4))
(0.4881, (0.3204, 0.6472))
```

**多变量统计量要 `paired=True`**（两列按行配对重抽），否则两组会被独立重抽、破坏配对结构。

### 4.8.3 `monte_carlo_test`：自定义统计量的零分布

当统计量不是均值/相关系数这种"有现成检验"的东西（比如"样本方差""最大间隔""游程数"），用蒙特卡洛模拟零分布：

```python
>>> rng = np.random.default_rng(5)
>>> data = rng.normal(0, 1, 80)
>>> mc = stats.monte_carlo_test(data, stats.norm.rvs,
...                             lambda s, axis: np.var(s, axis=axis), n_resamples=2000)
>>> round(float(mc.pvalue), 4)
0.3168                    # 每次调用都会变：这个函数没有 rng 参数
>>> chi2 = (len(data) - 1) * np.var(data, ddof=1)      # 解析对照：正态下 (n-1)s² ~ χ²(n-1)
>>> round(float(2*min(stats.chi2(len(data)-1).cdf(chi2), stats.chi2(len(data)-1).sf(chi2))), 4)
0.2849
```

蒙特卡洛 p（0.3168）与解析 p（0.2849）在模拟误差内一致——**解析值每次相同，蒙特卡洛值每次都会变**。**注意版本注意⑤**：

```python
>>> stat = lambda s, axis: np.var(s, axis=axis)
>>> stats.monte_carlo_test(data, stats.norm.rvs, stat, rng=np.random.default_rng(0))
TypeError: monte_carlo_test() got an unexpected keyword argument 'rng'
>>> # 同一份数据连续调用两次（不给任何种子）
0.2829 / 0.3058                           # 不可复现
>>> # 只能靠全局种子复现（仅取证）
>>> np.random.seed(0); round(float(stats.monte_carlo_test(data, stats.norm.rvs, stat, n_resamples=2000).pvalue), 4)
0.3178
>>> np.random.seed(0); round(float(stats.monte_carlo_test(data, stats.norm.rvs, stat, n_resamples=2000).pvalue), 4)
0.3178
```

**`monte_carlo_test` 没有 `rng` 参数，默认不可复现**。这是全卷唯一需要动全局随机状态的地方——写进代码时必须加注释，否则半年后没人能重现那个 p 值。相比之下 `permutation_test`/`bootstrap` 都有 `rng=`，一律用 `default_rng`。

### 4.8.4 分工与性能账

**性能**（本机，$n=25$ 两组 / $n=80$ 单组）：

| 方法 | 耗时 |
|------|------|
| `ttest_ind`（解析） | 0.34 ms |
| `bootstrap`（9999 次） | 4.4 ms |
| `permutation_test`（999 次） | 6.0 ms |
| `permutation_test`（9999 次） | 58.3 ms |

**解析法快 10–170 倍**，所以选择顺序永远是：**有解析法就用解析法 → 需要自定义统计量或假设太弱时用重采样**。重采样的价值不是"更准"，而是**更少假设、更大适用范围**。

### 4.8.5 分辨率与随机波动：两个必须报的数字

**分辨率**：$B$ 次重排能给出的最小非零 p 值是 $1/(B+1)$。实测同一份数据换种子的波动：

```
999 次重排、20 个种子：p ∈ [0.0140, 0.0360]，跨度 0.0220
99999 次重排、5 个种子：p ∈ [0.0225, 0.0242]，跨度 0.0018
```

**结论**：报重采样 p 值时，如果它接近判定线（0.01–0.10），必须说明 `n_resamples`；否则"p = 0.048"这个数字本身可能只是随机波动。经验值：**判定线附近的比较，用 $\ge 10^5$ 次重排**（本机 9999 次 58 ms，$10^5$ 次不到 1 秒，代价可以忽略）。

**可交换性**：置换检验的唯一假设是"在 $H_0$ 下观测可交换"。方差齐性 + 样本量不等时它彻底失效：

| 样本量 | 标准差 | 置换检验第一类错误 |
|--------|--------|------------------|
| (20, 20) | (1, 1) | 4.13% ✓ |
| (10, 40) | (1, 4) | **0.00%** |
| (10, 40) | (4, 1) | **24.47%** |
| (5, 50) | (1, 10) | **0.00%** |

（$\alpha = 0.05$，1500 次重复。）与 4.5.3 的 Student $t$ 完全同构：**大方差组样本量小时膨胀，反之时保守**。这再次说明"非参数 = 无假设"是错觉——**它换了一组假设（可交换性），而且同样可以被违反**。

> **机制洞察**：重采样的本质是**用"重新随机"替代"解析推导"**。它把"统计量的分布长什么样"这个问题从数学搬到计算，代价是（a）分辨率受 $B$ 限制、（b）假设变了但没消失、（c）慢。三件事都写清楚了，它才是可靠的工具。

> **延伸阅读**：置换分布的精确性与 BCa 的推导见配套文件 `ds-04b`；`permutation_test`/`bootstrap` 的完整参数（`batch`、`vectorized`、`axis`）见 [scipy.stats 重采样文档](https://docs.scipy.org/doc/scipy/reference/stats.html#resampling-and-monte-carlo-methods)。

## 4.9 统计工作流与陷阱总表

### 4.9.1 八步流水线：一次 A/B 实验的全程

把本章全部零件串起来。数据集：每组 10000 用户，主指标转化率，三个次指标（人均收入、停留时长、点击率）。

```python
import numpy as np
from scipy import stats

rng = np.random.default_rng(2026)
n = 10_000
conv_a = rng.random(n) < 0.040
conv_b = rng.random(n) < 0.046
rev_a = np.where(conv_a, rng.lognormal(3.2, 0.8, n), 0.0)
rev_b = np.where(conv_b, rng.lognormal(3.2, 0.8, n), 0.0)
stay_a = rng.normal(120, 40, n); stay_b = rng.normal(121, 40, n)
click_a = rng.random(n) < 0.20;   click_b = rng.random(n) < 0.202
```

**第 1 步 定口径**：主指标 = 转化率；$\alpha = 0.05$ 双侧；事先声明做 4 个指标的多重比较校正。

**第 2 步 分流检查（SRM）**——样本量对不对是 A/B 的第一道闸：

```python
>>> stats.binomtest(n, 2*n, 0.5).pvalue
1.0        # 不显著 = 两组各 10000，分流正常
```

**第 3–4 步 主指标：点估计 + 区间 + 检验**：

```
A: 0.0360  Wilson CI (0.0325, 0.0398)
B: 0.0463  Wilson CI (0.0424, 0.0506)
绝对提升 = +0.0103  相对 = +28.6%  z = 3.668  p = 0.00024
差值 BCa 区间 = (+0.0049, +0.0158)   （不含 0）
```

数值细节：`se = sqrt(p_A(1-p_A)/n + p_B(1-p_B)/n) = 0.00281`，`z = diff/se = 3.668`，双侧 `p = 2*sf(3.668) = 0.00024`。与卡方检验一致（$\chi^2 = 13.444$，p = 0.000246），这是"比例 z 检验 = 2×2 卡方"的对偶关系。

**第 5 步 次指标**：人均收入右偏且有大量 0，用非参数——

```
Welch t p = 0.0020 | Mann-Whitney p = 0.0002 | 均值 1.192 vs 1.595
```

**第 6 步 效应量与功效**：`Cohen's h = 0.0520`（很小），但在 $n=10000$/组下功效 0.957——**这个实验是为"小效应"设计的大样本，检出是设计的结果，不是运气的恩赐**。

**第 7 步 多重比较**：

| 指标 | raw p | BH 校正 p |
|------|-------|----------|
| 转化率 | 0.00024 | 0.00049 ✓ |
| 人均收入 | 0.00022 | 0.00049 ✓ |
| 停留时长 | 0.07011 | 0.09349 ✗ |
| 点击率 | 0.71113 | 0.71113 ✗ |

**第 8 步 结论**：主指标 $+0.0103$（相对 $+28.6\%$），BH 校正后 2/4 个指标显著。停留时长（p = 0.07）**不报"有提升趋势"**——那是把"没检出"包装成结论。

### 4.9.3 可复现清单与断言化

**可复现清单**（每次分析交付前过一遍）：

1. 随机源：全部 `default_rng(seed)`；`monte_carlo_test` 处显式 `np.random.seed` 并注释；
2. 版本：记录 `scipy.__version__`、`numpy.__version__`（`stats` 的默认行为随版本变，本章已列六处）；
3. 口径：指标定义、ddof、$\alpha$、多重比较方法、剔除规则全部写进脚本；
4. 重采样参数：`n_resamples`、`method`、`alternative` 都要出现在报告里；
5. 区间方法：Wilson / $t$ / BCa 三选一，并写明 n。

**把口径写成断言**（承接 `ds-01` 1.17、`ds-02` 2.14、`ds-03` 3.15）：

```python
def check_ab(conv_a, conv_b, alpha=0.05, min_n=1000):
    assert conv_a.size == conv_b.size >= min_n, "分流比或样本量异常"
    srm_p = stats.binomtest(conv_b.size, conv_a.size + conv_b.size, 0.5).pvalue
    assert srm_p > 0.001, f"SRM 异常：p={srm_p:.4f}"
    ca, cb = conv_a.mean(), conv_b.mean()
    se = np.sqrt(ca*(1-ca)/conv_a.size + cb*(1-cb)/conv_b.size)
    assert se > 0, "标准误为零：检查指标是否退化"
    return dict(diff=cb-ca, z=(cb-ca)/se, p=2*stats.norm.sf(abs((cb-ca)/se)))
```

三条断言分别挡住三类事故：**分流/样本量异常、分流比失衡（SRM）、指标退化（全 0 或全 1）**。统计分析的"工程化"就体现在这里——**能断言的口径，才是能被信任的口径**。
